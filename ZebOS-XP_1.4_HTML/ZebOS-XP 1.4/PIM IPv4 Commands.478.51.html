Protocol Independent Multicasting Command Reference : CHAPTER 2 PIMv4 Commands : ip pim ssm
  
ip pim ssm
Use this command to configure Source Specific Multicast (SSM), and define the ) range of IP multicast addresses. The keyword default defines the SSM range as 232/8. To define the SSM range to be other than the default, define and access-list.
When an SSM range of IP multicast addresses is defined with the ip pim ssm command, the no (*,G) or (S,G,rpt) state is initiated for groups in the SSM range.
The messages corresponding to these states are no accepted or originated in the SSM range.
Use the no form of this command to disable the SSM range.
Command Syntax
ip pim ssm default
ip pim ssm range (<1-99>|WORD)
ip pim (vrf NAME|) ssm default
ip pim (vrf NAME|) ssm range (<1-99>|WORD)
no ip pim ssm
no ip pim (vrf NAME|) ssm
Parameters
vrf
The VPN routing/forwarding instance
NAME
Specify the name of the VPN routing/forwarding instance
default
This keyword defines the 232/8 group range for SSM
range
Define an access-list for group range to use for SSM
<1-99>
Range of values for a standard access-list
WORD
A named standard access list
Command Mode
Configure mode
Example
The following example shows how to configure SSM service for the IP address range defined by access list 10:
#configure terminal
(config)#access-list 10 permit 225.1.1.1
(config)#ip pim ssm range 4
