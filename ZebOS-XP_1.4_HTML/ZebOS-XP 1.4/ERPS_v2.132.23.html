g8032_api_erp_inst_set_rpl_role
This function sets the RPL (Ring Protection Link) role of the ring node.
This function implements the rpl role command.
Syntax
s_int32_t
g8032_api_erp_inst_set_rpl_role (u_int8_t is_conf,
struct g8032_erps_instance *inst,
enum g8032_instance_role role,
u_int8_t is_east)
Input Parameters
is_conf
Reserved for future use
inst
ERP instance
role
Role; one of these constants from the g8032_instance_role enum in onmd/cfm/g8032v2/g8032_erps.h:
G8032_INST_ROLE_NONE
 
Ring node does not have an RPL role
G8032_INST_ROLE_NONOWNER
 
Ring node does not own the RPL
G8032_INST_ROLE_OWNER
 
Ring node is the RPL owner
G8032_INST_ROLE_NEIGHBOUR
 
Ring node is neighbor to the RPL owner
G8032_INST_ROLE_NEXT_NEIGHBOUR
 
Ring node is neighbor to the neighbor of the RPL owner
is_east
Whether to assign the role to the east or west interface:
PAL_TRUE
Assign role to east interface
PAL_FALSE
Assign role to west interface
Output Parameters
None
Return Values
G8032_ERROR_NONE when the function succeeds
G8032_ERROR_ERPS_INST_NOT_FOUND when inst is NULL
