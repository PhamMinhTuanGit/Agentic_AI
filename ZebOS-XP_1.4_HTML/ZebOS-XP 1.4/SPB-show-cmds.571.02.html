Shortest Path Bridging Command Reference : CHAPTER 3 SPB Show Commands : show bridge spb
  
show bridge spb
Use this command to display the details of the SPB bridge. The output includes:
• B-MAC: the bridge MAC address
• Bridge_group_address: the address used as the B-DA (backbone destination address) for an incoming multicast frame
• System ID: unique identifier of a bridge in a given network
• Bridge_priority: the number that ranks this SPB bridge relative to others when breaking ties
• MCID: MST configuration identifier
• AUX-MCID: auxiliary MST configuration identifier
• SPSourceID: shortest path source ID; the number used as a part of each group address
• Agreement_digest_convention_id: the agreement rules being used (1-3)
Command Syntax
show bridge spb BRIDGE_NAME
Parameters
BRIDGE_NAME
Bridge identifier: <1-32> or backbone.
Command Mode
Privileged Exec mode
Example
#show bridge spb backbone
