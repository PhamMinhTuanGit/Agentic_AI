pal_kernel_ipv6_update
This function updates an entry in the kernel IPv6 forwarding table.
API Call
result_t pal_kernel_ipv6_update (struct prefix *p, struct rib *r, struct rib *s);
Input Parameters
p
Pointer to the prefix to update
r
Pointer to the current RIB entry
s
Pointer to the new RIB entry
Output Parameters
None
Result Value
Platform dependent
