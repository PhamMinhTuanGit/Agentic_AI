Label Distribution Protocol Developer Guide : CHAPTER 9 LDP API : ldp_api_set_hold_timer
  
ldp_api_set_hold_timer
This call sets the hold time for all entities.
Syntax
int
ldp_api_set_hold_timer (struct ldp *ldp,
u_int16_t hold_timer, u_char flag)
Input Parameters
ldp
LDP instance
hold_timer
Hold timer flag. Valid values are LDP_HOLD_TIME_SET (1) and LDP_HOLD_TIME_UNSET (0)
flag
Hold timer flag. Valid values are LDP_HOLD_TIME_SET (1) and LDP_HOLD_TIME_UNSET (0)
Output Parameters
None
Return Values
LDP_SUCCESS
LDP_ERROR
