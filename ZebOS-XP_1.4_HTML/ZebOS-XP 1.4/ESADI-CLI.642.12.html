show trill esadi-native-l2-table
Use this command to display the native layer 2 MAC table information for TRILL ESADI.
Command Syntax
show trill esadi-native-l2-table (vlan <1-4094>|)
Parameters
<1-4094>
Display VLAN identifier.
Command Mode
Exec mode and Privilege Exec mode
Examples
#show trill esadi-native-l2-table vlan 123
VLAN Confidence MACs
------------------------------------------------------------------------------
123 123
