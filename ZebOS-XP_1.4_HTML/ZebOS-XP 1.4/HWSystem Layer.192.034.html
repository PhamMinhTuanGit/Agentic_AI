Platform Integration Developer Guide : CHAPTER 3 Hardware Services Layer : HSL Callbacks : OS Callbacks
  
OS Callbacks
The following table displays the operating system callbacks.
 
Table 9:  
Callback
Description
os_fib_init
Initialize the OS FIB.
os_fib_deinit
De-initialize the OS FIB.
os_fib_dump
Show the OS FIB entries.
os_prefix_add
Add a prefix to the OS.
os_prefix_add_if
Add a local address to the OS.
os_prefix_delete
Delete a prefix from the OS.
os_prefix_delete_if
Delete a local address from the OS.
os_nh_add
Add a next-hop entry.
os_nh_delete
Delete a next-hop entry.
