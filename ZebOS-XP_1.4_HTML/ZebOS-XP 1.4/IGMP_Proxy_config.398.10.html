Multicast Configuration Guide : CHAPTER 8 IGMP Proxy Configuration : Enabling Unsolicited report interval : Validation
  
Validation
Here is the same configuration for IGMP Proxying router.
hostname Router1
!
interface eth0
!
interface eth1
ip igmp proxy-service
ip igmp proxy unsolicited-report-interval 20000
!
interface eth2
ip igmp mrouter-proxy eth1
!
interface lo
!
!
ip multicast-routing
!
