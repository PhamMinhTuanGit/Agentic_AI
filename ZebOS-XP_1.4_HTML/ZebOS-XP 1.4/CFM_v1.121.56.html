Carrier Ethernet Command Reference : Appendix A CFM Version 1 Commands : ethernet cfm throughput-measurement reception
  
ethernet cfm throughput-measurement reception
Use this command to enable throughput-measurement reception at the receiving MEP.
Command Syntax
ethernet cfm throughput-measurement reception mepid MEPID duration <1-10> domain DOMAIN_NAME (vlan VLAN_ID|) (bridge <1-32>|)
Parameters
mepid
Specify an integer that identifies the host MEP.
duration
Specify the maximum duration for waiting for TST frames before timing out <1-10>.
domain
Specify the name of the maintenance domain in ASCII format.
vlan
Specify an integer that identifies a VLAN.
bridge
Specify ID of a bridge in the range of <1-32>.
Command Mode
Exec mode and Privileged Exec mode
Example
#ethernet cfm throughput-measurement reception mepid 4 duration 5 domain 3 vlan 3 bridge 1
