Carrier Ethernet Command Reference : CHAPTER 2 Ethernet CFM Commands : dmm
  
dmm
Use this command to configure two-way delay measurement (DMM) for a MEP.
Command Syntax
dmm (unicast (rmpid MEPID)|multicast) duration DURATION ((interval (1 | 2 | 3 | 4))|)
Parameters
unicast
Specify the unicast delay measurement.
rmpid
Specify the MEPID of remote MEP.
multicast
Specify the multicast delay measurement.
duration
Specify an integer that sets the delay measurement duration <5-60>.
interval
Specify a DMM transmission interval.
1
Specify a DM Transmission interval <100 ms>.
2
Specify a DM Transmission interval <10 ms>.
3
Specify a DM Transmission interval <1 second>.
4
Specify a DM Transmission interval <10 seconds>.
Command Mode
Ethernet CFM MEP configuration mode
Example
(config-cfm-mep)#dmm multicast duration 12 interval 1
