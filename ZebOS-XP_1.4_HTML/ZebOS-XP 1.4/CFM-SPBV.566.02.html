This chapter uses these generic terms to refer to network devices:
• EB means Edge Bridge which can be a:
• Customer Edge Bridge (CEB)
• Provider Edge Bridge (PEB)
• Backbone Edge Bridge (BEB)
• CB means Core Bridge which can be a:
• Customer Core Bridge (CCB)
• Provider Core Bridge (PCB)
• Backbone Core Bridge (BCB)
