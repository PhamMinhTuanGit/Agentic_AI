nsm_mpls_ftn_add_msg_process
This function is a handler for all FTM add messages.
Syntax
s_int32_t
nsm_mpls_ftn_add_msg_process (struct nsm_master *nm,
struct ftn_add_data *data,
struct ftn_ret_data *ret_data,
mpls_ftn_type_t f_type,
bool_t config)
Input Parameters
*nm
Pointer to the NSM master structure
*data
FTN add data
*ret_data
FTN return data
f_type
FTN type
config
Configuration
Output Parameters
None
Return Value
PAL_TRUE when the function succeeds
PAL_FALSE when the function fails
