Unicast Configuration Guide : CHAPTER 5 OSPFv3 : Flood Reduction : R3
  
R3
 
R3#configure terminal
Enter configure mode.
R3(config)#int eth1
Enter interface mode.
R3(config-if)#ipv6 address 4000::51/64
Configure the IP address of the interface.
R3(config-if)#ipv6 router ospf area 0 tag 1
Configure the interface in an area assigned with the area ID (1) which uniquely identifies the routing process
R3(config-if)#exit
Exit interface mode.
R3(config)#router ipv6 ospf 1
Configure the routing process
R3(config-router)#router-id 3.3.3.3
Configure router-id to uniquely identify the router
R3(config-router)#ospfv3 flood-reduction
Configure flood reduction
R3(config-router)#end
Exit router mode.
