Network Services Module Command Reference : CHAPTER 5 Interface Commands : duplex
  
duplex
Use this command to set the duplex mode for each interface.
Use the no parameter to remove the duplex mode.
Command Syntax
duplex (half|full|auto)
no duplex
Parameter
half
Set the interface to half-duplex.
full
Set the interface to full-duplex.
auto
Set the interface to auto-negotiate.
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth0
(config-if)#duplex auto
 
(config-if)#no duplex
