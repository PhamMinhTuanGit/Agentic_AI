evb bridge tlv-mode
Use this command to set the TLV (type-length-value) transmission mode.
Command Syntax
evb bridge <1-32> tlv-mode (manual | auto)
Parameters
<1-32>
Bridge identifier
manual
Use the local configuration for EVB
auto
Determine the configuration by comparing the local and remote LLDP EVB objects
Command Mode
Configure mode
Examples
#configure terminal
(config)#evb bridge 1 tlv-mode manual
