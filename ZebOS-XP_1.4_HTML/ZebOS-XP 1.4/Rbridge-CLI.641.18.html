forward-delay
Use this command to set the TRIL forward delay for the specified instance
Use the no parameter with this command to remove the configuration,
Command Syntax
forward-delay <4-30>
no forward-delay <4-30>
Parameters
<4-30>
Specify the forward delay value <4-30> in seconds.
Command Mode
RBridge mode
Examples
Set one d-tree:
>enable
#configure terminal
(config)#bridge 1 protocol trill
(config)#rbridge trill 1
(config-br)#forward-delay 5
 
(config-br)#no forward-delay
