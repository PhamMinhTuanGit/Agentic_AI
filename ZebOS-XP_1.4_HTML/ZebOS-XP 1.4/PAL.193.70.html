pal_time_strf
This function converts the expanded time to string form.
Syntax
size_t
pal_time_strf (char *s,
size_t smax,
const char *fmt,
const struct pal_tm *tp)
Input Parameters
smax
Maximum length of string
*fmt
A pointer to the format to use
*tp
A pointer to the struct tm to use
Output Parameters
*s
A pointer to where to put the string.
Return Values
RESULT_OK if function succeeds
Error occurs if function fails
