ethernet cfm pbb traceroute cache
Use this command to enable traceroute cache for a bridge or provider backbone.
Use the no form of this command to disable the traceroute cache.
Command Syntax
ethernet cfm pbb traceroute cache (bridge <1-32>|backbone)
no ethernet cfm pbb traceroute cache (bridge <1-32>|backbone)
Parameters
bridge
Identify a bridge.
<1-32>
Bridge ID.
backbone
Identify the bridge as a backbone.
Command Mode
Configure mode
Examples
(config)#ethernet cfm pbb traceroute cache bridge 1
(config)#ethernet cfm pbb traceroute cache size 29 bridge 1
(config)#no ethernet cfm pbb traceroute cache size bridge 1
(config)#no ethernet cfm pbb traceroute cache bridge 1
