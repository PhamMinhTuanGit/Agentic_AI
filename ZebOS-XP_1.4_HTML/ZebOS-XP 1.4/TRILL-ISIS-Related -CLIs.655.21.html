trill_dtree_num_touse_set
This function sets the number of DTrees to be computed by the specified RBridge. It is called by the number-of-dtrees-to-use CLI command and is contained in the trill_api.c file.
Syntax
s_int32_t
trill_dtree_num_touse_set(u_int32_t vr_id, char *tag, s_int32_t dtree_num)
Input Parameters
vr_id
Specifies the virtual router identification.
*tag
Specifies the identification of the RBridge instance.
dtree_num
Specifies the DTree nickname to use: 1–8.
Output Parameters
None
Return Values
TRILL_API_SET_SUCCESS: Indicates the function call executed properly.
TRILL_API_SET_ERR_INSTANCE_NOT_EXIST: Indicates there is no active IS-IS instance for the specified tag.
TRILL_API_SET_ERR_VR_NOT_EXIST: Indicates there is no active instance of a virtual router.
