oam_api_lps_lockout
This function triggers a lockout event identified by protection-group name.
Syntax
s_int32_t
oam_api_lps_lockout (u_int32_t vr_id, char *grp_name_str)
Input Parameters
vr_id
VR instance ID
grp_name_str
The protection-group name
Output Parameters
None
Return Values
OAM_API_SET_ERROR_PSC_GRP_LOOKUP when the protection-group lookup fails
OAM_API_SET_ERROR_PRIMARY_ME_NOT_SET when the primary ME is not configured for protection-group
OAM_API_SET_ERROR_BACKUP_ME_NOT_SET when the backup ME is not configured for protection-group
OAM_API_LOCKOUT_ALREADY_EXISTS when the current state is already lockout
OAM_API_LPS_SET_ERROR when the function fails due to internal errors such as a memory failure
OAM_API_LPS_SET_SUCCESS when the function succeeds
