Multi-Protocol Label Switching Command Reference : CHAPTER 3 Differentiated Services Commands : show mpls diffserv class-to-exp
  
show mpls diffserv class-to-exp
Use this command to display the node level PHB-EXP mapping.
Command Syntax
show mpls diffserv class-to-exp
Parameters
None
Command Mode
Exec mode and Privileged Exec mode
Example
Following is a sample output of the show mpls diffserv class-to-exp command showing PHB-EXP mapping at the node level.
#show mpls diffserv class-to-exp
MPLS Differentiated Services CLASS to EXP mapping data:
CLASS DSCP_value EXP_value
be 000000 0
be 000000 2
af12 001100 3
