Network Services Module Command Reference : CHAPTER 6 Traffic Engineering Commands : description
  
description
Use this command to provide a TE Link-specific description.
Use the no option with this command to remove the description.
Command Syntax
description LINE
no description
Parameters
LINE
Text describing the specific interface.
Command Mode
TE Link mode
Examples
#configure terminal
(config)#te-link te1 local-link-id 172.1.1.1
(config-te)#description This is for Testing
