System Management Command Reference : CHAPTER 15 User Management : permit interface mgmt
  
permit interface mgmt
Use this command to permit selective access to management interfaces when general access is denied.
Use the no form of this command to remove this permission.
Command Syntax
permit interface mgmt <0-0>
no permit interface mgmt <0-0>
Parameters
<0-0>
Management interface number
Command Mode
Role interface mode
Example
#configure terminal
(config)#role name Dearborn
(config-role)#interface policy deny
(config-role-interface)#permit interface mgmt 0
