nsm_mpls_set_ftn_st_type
This function sets the storage type for this FTN.
Syntax
u_int32_t
nsm_mpls_set_ftn_st_type (struct nsm_master *nm,
u_int32_t ftn_ix, u_int32_t st_type)
Input Parameters
nm
NSM master
ftn_ix
Index to a conceptual row in the FTN table
st_type
Storage type for this FTN entry; only ST_VOLATILE defined in nsm/mpls/nsm_mpls_rib.h is permitted
Output Parameters
None
Return Values
NSM_API_SET_SUCCESS when the function succeeds
NSM_API_SET_ERROR when the function fails
