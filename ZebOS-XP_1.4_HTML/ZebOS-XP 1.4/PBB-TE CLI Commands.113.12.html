Carrier Ethernet Command Reference : CHAPTER 11 PBB-TE Provisioning Commands : type
  
type
Use this command to set the type of the local CBP (Customer Backbone Port) interface that is associated with this TESI (Traffic Engineering Service Instance).
Use the no form of the command to set the type to its default (static). You can specify a parameter for the no form, but it is ignored.
Command Syntax
type (dynamic|static)
no type (dynamic|static|)
Parameters
dynamic
Dynamic TESI.
static
Static TESI.
None
Command Mode
PBB-TE configure mode
Examples
The following is an example of this command.
#configure terminal
#(config)#pbb-te configure tesid 3
#(pbb-te-config)#type dynamic
