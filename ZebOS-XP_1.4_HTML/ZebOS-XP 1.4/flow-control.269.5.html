get_flow_control_statistics
This function retrieves the 802.2x flow control statistics from a port. This function uses the HAL API to get the flow control statistics.
Syntax
int
get_flow_control_statistics (struct interface *ifp,
enum smi_flow_control_dir *direction,
int *rxpause, int *txpause)
Input Parameters
ifp
Interface pointer.
direction
Indicates the direction of flow control. Possible values as defined in the lib/smi/client/smi_message.h file include the following:
SMI_FLOW_CONTROL_OFF
SMI_FLOW_CONTROL_SEND
SMI_FLOW_CONTROL_RECEIVE
SMI_FLOW_CONTROL_BOTH
SMI_FLOW_CONTROL_UNCONFIGURE
Output Parameters
rxpause
Receive pause statistics.
txpause
Transmit pause statistics.
Return Values
RESULT_OK when function succeeds.
RESULT_ERROR when function fails.
