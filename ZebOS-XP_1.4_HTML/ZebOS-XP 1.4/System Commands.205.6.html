Integrated Management Interface Command Reference : CHAPTER 5 System Commands : ip host
  
ip host
Use this command to define static hostname-to-address mappings in DNS. You can specify one or two mappings in a command.
Use the no parameter with this command remove a hostname-to-address mapping.
Command Syntax
ip host WORD A.B.C.D
ip host WORD A.B.C.D A.B.C.D
ip host WORD (X:X::X:X | A.B.C.D)
ip host WORD (X:X::X:X | A.B.C.D) (X:X::X:X | A.B.C.D)
no ip host WORD A.B.C.D
no ip host WORD A.B.C.D A.B.C.D
no ip host WORD (X:X::X:X | A.B.C.D)
no ip host WORD (X:X::X:X | A.B.C.D) (X:X::X:X | A.B.C.D)
Parameters
WORD
Hostname, such as company.com
A.B.C.D
IPv4 address of the host
X:X::X:X
IPv6 address of the host
Command Mode
Configure mode
Examples
#configure terminal
(config)#ip host company.com 192.0.2.1
