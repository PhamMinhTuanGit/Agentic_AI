Network Services Module Command Reference : CHAPTER 6 Traffic Engineering Commands : ip address
  
ip address
Use this command to set the IP address for an interface.
Use the no parameter with this command to remove the IP address from an interface.
Command Syntax
ip address A.B.C.D/M
no ip address (A.B.C.D/M |)
Parameters
A.B.C.D/M
Specify the IP address and prefix length of an interface.
Command Mode
Interface mode
Examples
(config)#interface eth0
(config-if)#ip address 10.10.10.50/24
