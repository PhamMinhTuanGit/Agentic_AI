ZebOS-XP Install Guide : Appendix A Build Configuration Options : RIP
  
RIP
 
Option flag
Description
--enable-pece-rip
Enable RIP as the CE/PE protocol to support VPN (Virtual Private Network)
--disable-pece-rip
Disable RIP as the CE/PE protocol (Default)
--enable-pece-ripng
Enable RIPNG as the CE/PE protocol to support VPN
--disable-pece-ripng
Disable RIPNG as the CE/PE protocol to support VPN (Default)
--enable-ripd
Build the RIP daemon (Default)
--disable-ripd
Do not build RIP daemon
--enable-ripngd
Build the RIPng daemon (Default)
--disable-ripngd
Do not build RIPng daemon
