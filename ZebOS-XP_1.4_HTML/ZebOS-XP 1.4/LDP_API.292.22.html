Label Distribution Protocol Developer Guide : CHAPTER 9 LDP API : ldp_api_set_entity_keepalive_timer
  
ldp_api_set_entity_keepalive_timer
This call sets the keepalive timer for the entity.
Syntax
int ldp_api_set_entity_keepalive_timer (struct ldp_entity *entity,
u_int16_t keepalive_timeout,
u_char timeout)
Input Parameters
*entity
LDP entity
keepalive_timeout
 
Value of the keepalive timer, the permitted range is (1 - 65535)
timeout
Keepalive timer flag. The valid values are LDP_KEEPALIVE_TIMEOUT_SET (1) and LDP_KEEPALIVE_TIMEOUT_UNSET(0)
Output Parameters
None
Return Values
LDP_ERR_INVALID_KEEPALIVE_TIMEOUT
LDP_SUCCESS
