Label Distribution Protocol Command Reference : CHAPTER 3 LDP Show Commands : show mpls ldp parameter
  
show mpls ldp parameter
Use this command to display LDP attributes assigned for this LSR.
Command Syntax
show mpls ldp parameter
Parameter
None
Command Mode
Exec mode and Privileged Exec mode
Example
