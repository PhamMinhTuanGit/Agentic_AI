Carrier Ethernet Command Reference : CHAPTER 10 Provider Backbone Bridging CFM Commands : mcc tx
  
mcc tx
Use this command to enable Maintenance Communication Channel (MCC) message transmission (tx) from a MEP.
Command Syntax
mcc tx multicast
mcc tx unicast rmepid RMEPID
Parameters
multicast
Send multicast MCC frames.
unicast
Send unicast MCC frames.
rmepid
Remote MEP ID.
Command Mode
Ethernet CFM PBB MEP configuration mode
Examples
(config-cfm-pbb-mep)#mcc tx unicast rmepid 2
(config-cfm-pbb-mep)#mcc tx multicast
