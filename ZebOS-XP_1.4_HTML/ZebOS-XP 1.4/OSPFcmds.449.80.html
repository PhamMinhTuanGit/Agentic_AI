Open Shortest Path First Command Reference : CHAPTER 2 OSPFv2 Commands : show ip ospf interface
  
show ip ospf interface
Use this command to display interface information for OSPF.
Command Syntax
show ip ospf interface (IFNAME|)
Parameters
IFNAME
Interface name.
Command Mode
Privileged Exec mode and Exec mode
Example
