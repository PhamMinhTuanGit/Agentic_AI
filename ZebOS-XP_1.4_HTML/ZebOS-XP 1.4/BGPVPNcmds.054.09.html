Border Gateway Protocol Command Reference : CHAPTER 4 BGP Virtual Private Network Commands : debug bgp mpls
  
debug bgp mpls
Use this command to enable the display of MPLS related information.
Use the no parameter with this command to disable this function.
Note: This command is available only when vrf option is enabled.
Command Syntax
debug bgp mpls
no debug bgp mpls
Parameters
None
Default
Disabled
Command Mode
Privileged Exec mode
Examples
debug bgp mpls
