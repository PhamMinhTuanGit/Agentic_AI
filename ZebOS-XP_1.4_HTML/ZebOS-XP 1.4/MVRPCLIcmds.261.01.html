CHAPTER 12 MVRP Commands
This chapter contains the Multiple VLAN Registration Protocol (MVRP) commands. MVRP uses the Multicast Registration Protocol (MRP) attribute declaration and propagation features to dynamically establish and update VLAN information, for example, which VLAN has active members, and through which ports can those members be reached.
This chapter provides a description, syntax, and examples of the MVRP commands. It includes the following commands:
• clear mvrp
• set mvrp applicant
• set mvrp disable
• set mvrp dynamic-vlan-creation
• set mvrp enable
• set mvrp pointtopoint
• set mvrp registration
• set mvrp timer
• set port mvrp
• show mvrp configuration
• show mvrp machine
• show mvrp statistics
• show mvrp timer
