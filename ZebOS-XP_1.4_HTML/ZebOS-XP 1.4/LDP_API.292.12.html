ldp_api_entity_lookup_by_index
This function returns the entity based on the LDP index.
Syntax
struct ldp_entity *
ldp_api_entity_lookup_by_index (struct ldp *ldp, struct ldp_id *id,
u_int32_t *index)
Input Parameters
ldp
LDP instance
*id
LDP ID
*index
LDP index
Output Parameters
None
Return Values
LDP entity or NULL
