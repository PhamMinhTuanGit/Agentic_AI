RSVP-TE Command Reference : CHAPTER 3 Fast Reroute Commands : traffic
  
traffic
Use this command to designate the traffic type for this RSVP Bypass Trunk.
Use the no parameter with this command to remove the configured traffic type.
Command Syntax
traffic (guaranteed|controlled-load)
no traffic
Parameters
controlled-load
 
Controlled loaded traffic
guaranteed
Guaranteed traffic
Command Mode
Bypass mode
Default
Controlled load is the default.
Example
#configure terminal
(config)#rsvp-bypass b1
(config-bypass)#traffic guaranteed
 
(config)#rsvp-bypass b1
(config-bypass)#no traffic
