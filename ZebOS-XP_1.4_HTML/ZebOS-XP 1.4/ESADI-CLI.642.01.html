CHAPTER 3 ESADI Commands
This chapter provides information about the ESADI (End System Address Distribution Information) commands. These commands are used when configuring a routing bridge and are found in the RBridge mode. This chapter includes the following commands:
• esadi confidence
• esadi csnp-timer
• esadi disable
• esadi enable
• esadi instance
• esadi l2-learning
• esadi lsp-gen-interval
• esadi priority

• show trill esadi-lsp
• show trill esadi-native-l2-table
• show trill esadi-remote-l2-table
• show trill esadi-statistics
