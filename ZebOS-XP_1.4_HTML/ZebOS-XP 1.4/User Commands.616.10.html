System Management Command Reference : CHAPTER 15 User Management : permit vlan
  
permit vlan
Use this command to permit selective access to a VLAN when general access is denied.
Use the no form of this command to remove this permission.
Command Syntax
permit vlan <1-4093>
no permit vlan <1-4093>
Parameters
<1-4093>
VLAN number
Command Mode
Role VLAN mode
Example
#configure terminal
(config)#role name Dearborn
(config-role)#vlan policy deny
(config-role-vlan)#permit vlan 302
