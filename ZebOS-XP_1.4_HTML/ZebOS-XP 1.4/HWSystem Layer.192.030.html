Forwarding Database Callbacks
The following table displays the forwarding database callbacks.
 
Table 5:  
Callbacks
Description
add_fdb
Add a MAC entry to forwarding database (FDB)
delete_fdb
Delete a MAC entry from FDB
get_uni_fdb
Get dynamic unicast MAC entries from FDB
flush_port_fdb
Flush FDB for specific port
flush_fdb_by_mac
Delete specific MAC from FDB
