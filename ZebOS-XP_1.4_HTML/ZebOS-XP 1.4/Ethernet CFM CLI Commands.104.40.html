Carrier Ethernet Command Reference : CHAPTER 2 Ethernet CFM Commands : mcc tx
  
mcc tx
Use this command to enable transmission of Maintenance Communication Channel (MCC) frames from the host MEP to a specified unicast address or a default multicast address for the maintenance entity group (MEG) level.
Command Syntax
mcc tx (unicast rmepid RMEPID| multicast)
Parameters
unicast
Specify to send unicast MCC frames.
rmepid
Specify an integer that identifies the remote MEP for unicast frames.
multicast
Specify to send multicast MCC frames.
Command Mode
Ethernet CFM MEP configuration mode
Example
(config-cfm-mep)#mcc tx unicast rmepid 7
(config-cfm-mep)#mcc tx multicast
