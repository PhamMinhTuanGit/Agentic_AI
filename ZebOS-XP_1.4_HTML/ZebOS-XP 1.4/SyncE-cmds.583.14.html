Synchronous Ethernet Command Reference : CHAPTER 2 SyncE Configuration Commands : synchronization option
  
synchronization option
Use this command to set the synchronization option for the internal clock that is locked in frequency to an incoming signal.
Command Syntax
synchronization option (1 | 2 (gen1 | gen2) | 3)
Parameters
1
Networks optimized for the 2048 kbit/s hierarchy
2
Networks optimized for the 1544 kbit/s hierarchy that includes the rates 1544 kbit/s, 6312 kbit/s, and 44 736 kbit/s
gen1
First generation (7 quality level set)
gen2
Second generation (9 quality level set)
3
Networks optimized for the 1544 kbit/s hierarchy that includes the rates 1544 kbit/s, 6312 kbit/s, 33 064 kbit/s, 44 736 kbit/s, and 97 728 kbit/s
Default
The default value is 1.
Command Mode
Configure Synchronous Ethernet mode
Example
(config)#synce
(config-synce)#synchronization option 2 gen1
