trill_forward_delay_nsm_notification
This function sends a delay notification to NSM.
Syntax
s_int32_t
trill_forward_delay_nsm_notification (struct trill *top, u_int16_t fwd_delay,
u_int16_t nickname, u_int16_t vlan)
Input Parameters
*top
Specifies the pointer to the TRILL instance.
fwd_delay
Forward delay.
nickname
Specifies the nickname for the message.
vlan
Specifies the pointer to the VLAN.
Output Parameters
None
Return value
TRILL_API_SET_ERR_NO_NSM_CILENT
TRILL_API_SET_SUCCESS
