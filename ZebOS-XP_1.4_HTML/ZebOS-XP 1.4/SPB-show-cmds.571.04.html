show isis-spb fdb
Use this command to display the ISIS-SPB forwarding database.
Command Syntax
show isis-spb fdb (unicast|multicast|)
Parameters
unicast
ISIS-SPB unicast forwarding database.
multicast
ISIS-SPB multicast forwarding database.
Command Mode
Privileged Exec mode
Example
#show isis-spb lsp fdb
