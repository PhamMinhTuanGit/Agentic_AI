trill-isis lsp-interval
Use this command to configure the LSP interval for an interface.
Use the no parameter with this command to reset the configuration to the default value.
Command Syntax
trill-isis lsp-interval <1-4294967295>
no trill-isis lsp-interval
Parameters
<1-4294967295>
Specifies the duration of the LSP in milliseconds
Command Mode
Interface mode
Default
33 milliseconds.
Examples
>enable
#configure terminal
(config)#interface eth1
(config-if)#trill-isis lsp-interval 3343
 
(config-if)#no trill-isis lsp-interval
