Integrated Management Interface Command Reference : CHAPTER 2 Common IMI Commands : show process
  
show process
Use this command to display information about ZebOS-XP daemon processes.
Command Syntax
show process
Parameters
None
Command Mode
Exec modes
Example
This is a sample show output of the show process command displaying information of a currently running process.
#show process
PID NAME TIME FD
1 nsm 00:56:29 7
2 ripd 00:56:29 11
3 ripngd 00:56:29 12
4 ospfd 00:56:29 9
5 ospf6d 00:56:29 10
6 bgpd 00:56:29 14
9 isisd 00:56:29 8
#
