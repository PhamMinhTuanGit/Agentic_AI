Carrier Ethernet Command Reference : CHAPTER 2 Ethernet CFM Commands : vsm tx
  
vsm tx
Use this command to configure the vendor-specific VSM OAM functionality between a host and a destination MEP in an administrative domain. ZebOS-XP handles the message part of the frame alone; in other words, ZebOS-XP can identify the frame, but does not handle the payload.
Note: Interoperability of vendor-specific OAM is not expected when using equipment from different vendors.
Command Syntax
vsm tx unicast rmepid RMEPID
Parameters
rmepid
Specify the ID of the remote MEP.
Command Mode
Ethernet CFM MEP configuration mode
Examples
(config-cfm-mep)#vsm tx unicast rmepid 8
