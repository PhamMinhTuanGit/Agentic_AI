max-lsp-lifetime
Use this command to set the maximum LSP lifetime. You must set max-lsp-lifetime greater than lsp-refresh-interval.
Use the no parameter to set the lifetime to the default.
Command Syntax
max-lsp-lifetime <350-65535>
no max-lsp-lifetime
Parameters
<350-65535>
Specify an maximum LSP lifetime in seconds.
Default
By default, max-lsp-lifetime is set to 1200 seconds.
Command Mode
Router mode
Examples
#configure terminal
(config)#router isis bb
(config-router)#max-lsp-lifetime 1500
 
(config)#router isis bb
(config-router)#no max-lsp-lifetime
