Integrated Management Interface Command Reference : CHAPTER 2 Common IMI Commands : line vty
  
line vty
Use the line vty command to move or change to VTY mode. This command is used to connect to NSM or a protocol daemons. This configuration is necessary for any session. This configuration should be in the daemon's config file before starting the daemon.
Use the no parameter to disable this command.
Command Syntax
line vty <0-871> (<0-871>|)
no line vty <0-871> (<0-871>|)
Parameters
<0-871>
Specify the first line number.
<0-871>
Specify the last line number.
Command Mode
Configure mode
Example
The following example shows the use of the line command to enter the Line command mode (note the change in the prompt).
#configure terminal
(config)#line vty 9
(config-line)#
