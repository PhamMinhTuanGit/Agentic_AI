RSVP-TE Command Reference : CHAPTER 3 Fast Reroute Commands : fast-reroute bandwidth
  
fast-reroute bandwidth
Use this command to configure bandwidth to reserve for fast reroute on a P2MP LSP.
Note: This command is only applicable to primary P2MP LSPs.
Use the no parameter with this command to remove the reserved bandwidth.
Command Syntax
fast-reroute bandwidth BANDWIDTH
no fast-reroute bandwidth
Parameters
BANDWIDTH
Set a bandwidth in the range of 1 to 10000000000 in bits per second. Usable units include kilobits (k), megabits (m), and gigabits (g).
Command Mode
P2MP LSP mode
Examples
#configure terminal
(config)#rsvp-trunk T1 ipv4 p2mp
(config-p2mp-trunk)#primary-lsp
(config-p2mp-lsp)#fast-reroute protection facility
(config-p2mp-lsp)#
 
(config-p2mp-lsp)#no fast-reroute protection facility
