Layer 2 Command Reference : CHAPTER 13 VLAN and Private VLAN Commands : show vlan auto
  
show vlan auto
Use this command to display information for VLANs that were auto-configured.
Command Syntax
show vlan auto
show vlan auto bridge <1-32>
Parameters
bridge
Displays the bridge group ID.
Command Mode
Exec mode and Privileged Exec mode
Example
The following is a sample output from this command when using the all parameter.
#show vlan auto
 
Bridge VLAN ID Name State Member ports
(u)-Untagged, (t)-Tagged
