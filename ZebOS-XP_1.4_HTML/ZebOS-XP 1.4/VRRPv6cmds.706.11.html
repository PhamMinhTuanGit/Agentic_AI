Virtual Router Redundancy Protocol Command Reference : CHAPTER 3 VRRP v6 Commands : virtual-ipv6
  
virtual-ipv6
Use this command to set the virtual IPv6 address for the VRRP session. The virtual IPv6 address is the IPv6 address of the virtual router that end-hosts set as their default gateway.
VRRP Owner of the Virtual IP address only responds to the packets destined to the Virtual IP address (for example, ICMP packets destined to the Virtual IP address).
Use the no parameter with this command to disable this feature.
Syntax Description
virtual-ipv6 X:X::X:X owner
no virtual-ipv6
Parameters
X:X::X:X
Specify the virtual IP address of the interface that participates in virtual routing
Note: The virtual-ip address should be the IPv6 link-local address of the interface.
owner
Specify the IP address as the owner.
Command Mode
Router mode
Example
The example below shows how to configure a router as VRRP Master and Owner:
#configure terminal
(config)#router ipv6 vrrp 1 eth0
(config-router)#virtual-ipv6 fe80::202:b3ff:fed5:983e owner
The example below removes the virtual IP address assignment.
#configure terminal
(config)#router ipv6 vrrp 1 eth0
(config-router)#no virtual-ipv6
