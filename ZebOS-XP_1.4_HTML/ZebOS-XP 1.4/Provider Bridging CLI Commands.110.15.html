Carrier Ethernet Command Reference : CHAPTER 8 Provider Bridging Commands : switchport mode
  
switchport mode
Use this command to set the switching characteristics of the Layer 2 interface.
Command Syntax
switchport mode (access|hybrid|trunk|provider-network|customer-network)
Parameters
access
Access.
hybrid
Hybrid.
trunk
Trunk.
provider-network
 
Provider network.
customer-network
 
Customer network.
Command Mode
Interface mode
Example
#configure terminal
(config)#interface eth0
(config-if)#switchport mode provider-network
