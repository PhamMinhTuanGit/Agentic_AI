Ethernet Local Management Interface Command Reference : CHAPTER 2 ELMI Commands : show ethernet lmi evc detail EVC ID
  
show ethernet lmi evc detail EVC ID
Use this command to display detailed status for a configured EVC ID string. Typically, this command is executed on the UNI-C.
Use this command to display detailed status for configured EVCs. This command is executed on the UNI-C.
Command Syntax
show ethernet lmi evc detail EVC_ID (bridge <1-32>)
show ethernet lmi evc detail EVC_ID interface IFNAME
Parameters
bridge
Indicates the bridge parameter.
<1-32>
Displays the actual bridge-group ID.
interface
Indicates the interface parameter.
IFNAME
Displays the actual interface information (for example, Eth1 or Eth2).
Command Modes
Executive Mode and Privileged Executive Mode
