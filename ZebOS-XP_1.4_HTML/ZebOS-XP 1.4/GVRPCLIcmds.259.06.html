set gvrp dynamic-vlan-creation
Use this command to enable or disable dynamic VLAN creation for the default bridge instance.
Command Syntax
set gvrp dynamic-vlan-creation enable bridge BRIDGE_NAME
set gvrp dynamic-vlan-creation disable bridge BRIDGE_NAME
Parameters
enable
Enables dynamic VLAN creation for the default bridge instance.
disable
Disables dynamic VLAN creation for the default bridge instance.
BRIDGE_NAME
Bridge identifier.
Command Mode
Configure mode
Examples
#configure terminal
(config)#set gvrp dynamic-vlan-creation enable bridge 2
(config)#set gvrp dynamic-vlan-creation disable bridge 2
