Network Services Module Command Reference : CHAPTER 4 Common Router-map Mode Commands : set local-preference
  
set local-preference
Use this command to set the BGP local preference path attribute.
Use the no parameter with this command to disable this function.
Command Syntax
set local-preference <0-4294967295>
no set local-preference (<0-4294967295>|)
Parameters
<0-4294967295>
Specify the tag value for destination routing protocol.
Default
Disabled
Command Mode
Route-map mode
Example
#configure terminal
(config)#route-map rmap1 permit 3
(config-route-map)#set local-preference 12
