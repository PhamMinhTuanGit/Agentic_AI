Open Shortest Path First Command Reference : CHAPTER 2 OSPFv2 Commands : ip router ospf multi-area
  
ip router ospf multi-area
Use this command to enable multi-area adjacency on point-to-point network. Multi-area adjacency establishes adjacency between the Area Border Routers (ABRs). The interface of the ABR where this command is configured, shall be associated with multiple areas.
Use the no parameter to disable multi-area adjacency on the given interface on point-to-point network.
Command Syntax
ip router ospf <0-65535> multi-area (A.B.C.D|<0-4294967295>)
no ip router ospf <0-65535> multi-area (A.B.C.D|<0-4294967295>)
Parameters
<0-65535>
OSPF process ID.
A.B.C.D
OSPF area ID in IP address format.
<0-4294967295>
OSPF area ID as a decimal value.
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth1
(config-if)#ip router ospf 0 multi-area 1
 
(config-if)# no ip router ospf 0 multi-area 1
