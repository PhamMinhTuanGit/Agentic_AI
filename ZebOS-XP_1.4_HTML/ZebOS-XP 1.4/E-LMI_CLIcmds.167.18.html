Ethernet Local Management Interface Command Reference : CHAPTER 2 ELMI Commands : show ethernet lmi parameters
  
show ethernet lmi parameters
Use this command to display ELMI parameters for selected interface. This CLI can be executed at the UNI-C and the UNI-N.
Command Syntax
show ethernet lmi parameters interface IFNAME
Parameters
interface
Indicates the interface parameter.
IFNAME
Displays the actual interface information (for example, Eth1 or Eth2).
Command Modes
Executive Mode and Privileged Executive Mode
Examples
#show ethernet lmi parameters interface eth1
 
E-LMI Parameters for interface eth1
Ether LMI Link Status Up
Mode CE
T391 10
N391 360
N393 4
#
