pbb_snmp_write_Cnp_table
This function writes a entry in the Customer Network Port (CNP) table.
Syntax
int
pbb_snmp_write_Cnp_table (int action,
u_char * var_val,
u_char var_val_type,
size_t var_val_len,
u_char * statP, oid * name,
size_t name_len,
struct variable *v, u_int32_t vr_id)
Input Parameters
var_val
Value to be set in the snmpset request
var_val_type
Type of the value to be set
var_val_length
Size of the value to be set
name
OID name
size
OID length
variable
SNMP variable structure
Output Parameters
None
Return Value
Integer value that denotes whether the function succeeded or failed
