Multi-Protocol Label Switching Command Reference : CHAPTER 9 MPLS-TP LPS Commands : reversion-mode
  
reversion-mode
Use this command to configure the protection switching mode of operation.
Command Syntax
reversion-mode (revertive|non-revertive)
Parameters
revertive
Revertive mode of operation
non-revertive
Non-revertive mode of operation
Command Mode
Protection group mode
Examples
#configure terminal
(config)#mpls-tp lps protection-group abc
(config-pg)# reversion-mode revertive
