Layer 2 Command Reference : CHAPTER 9 GMRP Commands : set gmrp disable
  
set gmrp disable
Use this command to disable GMRP globally on a switch for the default bridge. This command does not disable GMRP in all ports of the bridge.
Command Syntax
set gmrp disable bridge BRIDGE_NAME
set gmrp disable bridge BRIDGE_NAME vlan VLANID
Parameters
BRIDGE_NAME
Bridge identifier.
VLANID
VLAN identifier <1-4094>.
Default
GMRP is disabled by default
Command Mode
Configure mode
Example
#configure terminal
(config)#set gmrp disable bridge 2 vlan 2
