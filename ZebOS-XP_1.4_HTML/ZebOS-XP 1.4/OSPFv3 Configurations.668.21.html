Unicast Configuration Guide : CHAPTER 5 OSPFv3 : Cost : R4
  
R4
 
(config)# router ipv6 ospf
Create an OSPFv3 routing instance.
(config-router)# router-id 10.10.14.14
Specify a Router ID (10.10.14.14) for the OSPFv3 routing process.
(config-router)# exit
Exit Router mode, and return to Configure mode.
(config)# interface eth0
Specify the interface (eth0)to configure, and enter Interface mode.
(config-if)# ipv6 router ospf area 0
Enable OSPFv3 routing on an interface, and assign the Area ID (0).
(config-if)# exit
Exit interface mode.
(config)# interface eth1
Specify the interface (eth1)to configure, and enter Interface mode.
(config-if)# ipv6 router ospf area 0
Enable OSPFv3 routing on an interface, and assign the Area ID (0).
