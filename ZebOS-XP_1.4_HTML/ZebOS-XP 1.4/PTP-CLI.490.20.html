Precision Time Protocol Command Reference : CHAPTER 2 Precision Time Protocol Commands : show debugging ptp
  
show debugging ptp
Use this command to display PTP debugging settings.
Command Syntax
show debugging ptp
Parameters
None
Command Mode
Exec mode and Configure mode
Examples
The following example displays PTP debugging settings.
#debug ptp all
#show debugging ptp
PTP debugging status:
PTP timer debugging is on
PTP protocol debugging is on
PTP transmitting packet debugging is on
PTP receiving packet debugging is on
PTP event debugging is on
