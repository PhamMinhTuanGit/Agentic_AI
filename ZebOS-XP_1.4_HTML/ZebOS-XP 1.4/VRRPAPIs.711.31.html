pal_kernel_virtual_ipv6_delete
This function deletes a virtual IPv6 address from the specified interface.
Syntax
result_t pal_kernel_virtual_ipv6_delete (struct lib_globals *lib_node, struct pal_in4_addr *vipv6, struct interface *ifp, bool_t owner, u_int8_t vrid);
Input Parameters
lib_node
Global variables
vipv6
Virtual IPv6 address
ifp
The interface
owner
Owner status of this address
vrid
VRRPv6 virtual router ID
Output Parameters
None
Return Values
RESULT_OK when the deletion succeeds
EVRRP_MAC_UNSET when the virtual IP address does not exist
