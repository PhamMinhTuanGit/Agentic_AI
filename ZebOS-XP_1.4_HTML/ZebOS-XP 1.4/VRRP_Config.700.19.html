Virtual Router Redundancy Protocol Configuration Guide : CHAPTER 1 VRRP Configuration : Two Backup Routers : Disabling the Master/Owner
  
Disabling the Master/Owner
 
#configure terminal
Enter the Configure mode.
(config)#router vrrp 1 eth0
Create a VRRP instance for interface eth0.
(config-router)#disable
Disable the VRRP session.
