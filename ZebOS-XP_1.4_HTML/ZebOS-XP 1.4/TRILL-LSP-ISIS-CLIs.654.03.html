trill_ignore_lsp_errors_unset
This function configures the TRILL to not ignore all LSP errors, which are pointed out by the checksum field. It is called by the no ignore-lsp-errors CLI command and is contained in the trill_api.c file.
Syntax
s_int32_t trill_ignore_lsp_errors_unset (u_int32_t vr_id, char *tag);
Input Parameters
vr_id
Specifies the identification of the virtual router.
*tag
Specifies the identification of the RBridge instance.
Output Parameters
None
Return Values
TRILL_API_SET_SUCCESS: Indicates the function call executed properly.
TRILL_API_SET_ERR_INSTANCE_NOT_EXIST: Indicates there is no active IS-IS instance for the specified tag.
TRILL_API_SET_ERR_VR_NOT_EXIST: Indicates there is no active instance of a virtual router.
