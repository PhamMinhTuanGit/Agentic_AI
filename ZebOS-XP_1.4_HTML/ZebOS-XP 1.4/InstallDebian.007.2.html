ZebOS-XP Install Guide : Appendix C Install and Build Debian 8 : Prerequisites
  
Prerequisites
• DVD ISO images for Debian GNU/Linux 8.2 (Jessie) for one of these processor architectures:
• 64 bit (amd64): Required for one processor or SMP for 64 bit
• 32 bit (i386): Required for one processor or SMP for 32 bit
Download these from https://www.debian.org/CD/http-ftp.
• ZebOS-XP tar ball (ZebOS.tar.gz) delivered by IP Infusion Inc.
