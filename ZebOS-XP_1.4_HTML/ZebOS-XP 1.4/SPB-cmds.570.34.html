Shortest Path Bridging Command Reference : CHAPTER 2 SPB Configuration Commands : spb enable
  
spb enable
Use this command to enable or disable SPB on an interface.
Command Syntax
spb enable
spb disable
Parameters
enable
Enable SPB on the interface.
disable
Disable SPB on the interface.
Command Mode
Interface mode
Example
#config terminal
(config)#interface eth1
(config-if)#spb enable
