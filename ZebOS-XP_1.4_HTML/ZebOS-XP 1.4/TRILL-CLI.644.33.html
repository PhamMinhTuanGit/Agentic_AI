show trill statistics
Use this command to display TRILL statistics information, include control and status information.
Command Syntax
show trill statistics <1-32>
Parameters
instance
ID Specifies the TRILL instance identification
Command Mode
Exec mode and Privilege Exec mode
Examples
#show trill statistics 1
*************************TRILL Statistics************************
-----------------------------------------------------------------
TrillVersion 1
NumPorts 0
ForwardDelay 15sec
UniMultipathEnable Disabled
MultiMultipathEnable Disabled
NicknameNumber 8
AcceptEncapNonadj 0
#show trill statistics 30
Error: Not configured
#
