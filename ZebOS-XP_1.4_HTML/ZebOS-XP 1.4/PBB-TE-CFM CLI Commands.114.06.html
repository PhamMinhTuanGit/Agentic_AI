Carrier Ethernet Command Reference : CHAPTER 12 PBB-TE CFM Commands : clear ethernet cfm pbb-te traceroute-cache
  
clear ethernet cfm pbb-te traceroute-cache
Use this command to clear the traceroute-cache entries on a bridge.
Command Syntax
clear ethernet cfm pbb-te traceroute-cache (bridge <1-32> | backbone)
Parameter
bridge
Specify a bridge group name.
<1-32>
Specify a bridge ID.
backbone
Identifies the bridge as a backbone.
Command Mode
Exec Mode and Privileged Exec Mode
Example
>clear ethernet cfm pbb-te traceroute-cache bridge 1
