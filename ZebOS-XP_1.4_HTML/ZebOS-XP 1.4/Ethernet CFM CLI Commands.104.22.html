Carrier Ethernet Command Reference : CHAPTER 2 Ethernet CFM Commands : ethernet cfm debug
  
ethernet cfm debug
Use this command to set the debugging functions for CFM.
Use the no form of this command to disable CFM debugging.
Command Syntax
ethernet cfm debug (event|rx|tx|loopback|traceroute)
no ethernet cfm debug (event|rx|tx|loopback|traceroute)
Parameters
event
Enable or disable event debugging.
loopback
Enable or disable loopback debugging.
rx
Enable or disable RX debugging.
traceroute
Enable or disable traceroute debugging.
tx
Enable or disable TX debugging.
Command Mode
Exec mode and Privileged Exec mode
Example
#ethernet cfm debug traceroute
