trill_access_port_unset
This function resets the access port; the port is no longer an access port. It is called by the no trill access-port CLI command and is contained in the trill_api.c file.
Syntax
s_int32_t
trill_access_port_unset (u_int32_t vr_id, char *name);
Input Parameters
vr_id
Specifies the identification of the virtual router.
*name
Specifies the name of the interface.
Output Parameters
None
Return Values
TRILL_API_SET_SUCCESS: Indicates the function call executed properly.
TRILL_API_SET_ERR_IF_PARAM_NOT_CONFIGURED: Indicates the configuration parameters for this interface do not exist.
TRILL_API_SET_ERR_IF_NOT_EXIST: Indicates the specified interface is not present.
TRILL_API_SET_ERR_VR_NOT_EXIST: Indicates there is no active instance of a virtual router.
