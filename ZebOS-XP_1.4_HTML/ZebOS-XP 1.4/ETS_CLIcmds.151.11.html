enhanced-transmission-selection (interface)
Use this command to enable the ETS feature of DCB on an interface.
Use the no from of this command to disable the ETS at an interface.
Command Syntax
enhanced-transmission-selection mode (on|auto)
no enhanced-transmission-selection
Parameters
auto
Select auto to negotiate ETS capabilities.
on
Select on to force enable ETS.
Default
Default is Auto.
Command Mode
Interface mode
Examples
(config)#interface eth1
(config-if)#enhanced-transmission-selection mode on
 
(config)#interface eth1
(config-if)#no enhanced-transmission-selection
