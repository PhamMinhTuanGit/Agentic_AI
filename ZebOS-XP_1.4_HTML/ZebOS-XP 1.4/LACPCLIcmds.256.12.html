Layer 2 Command Reference : CHAPTER 7 Link Aggregation Control Protocol Commands : show etherchannel
  
show etherchannel
Use this command to display information about link aggregation groups.
Command Syntax
show etherchannel
show etherchannel <1-65535>
show etherchannel detail
show etherchannel load-balance
show etherchannel summary
Parameters
<1-65535>
Specify channel-group number.
detail
Specify detailed etherchannel information.
load-balance
Specify load balancing.
summary
Specify Etherchannel summary information.
Command Mode
Exec mode and Privileged Exec mode
Example
#show etherchannel detail
% Aggregator po1 1000003
% Mac address: 00:a0:bd:69:00:05
% Admin Key: 0001 - Oper Key 0001
% Receive link count: 1 - Transmit link count: 0
% Individual: 0 - Ready: 1
% Partner LAG- 0x8000,00-6a-3e-e7-00-03
% Link: fe3 (5003) sync: 1
% Link: fe4 (5004) sync: 1
#
