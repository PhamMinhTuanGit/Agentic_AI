System Management Command Reference : CHAPTER 7 Network Time Protocol : feature ntp
  
feature ntp
Use this command to enable NTP.
Use the no form of this command to disable NTP.
Command Syntax
feature ntp
ntp enable
no feature ntp
no ntp enable
Parameters
None
Command Mode
Configure mode
Examples
#configure terminal
(config)#feature ntp
 
(config)#no feature ntp
