Network Services Module Command Reference : CHAPTER 5 Interface Commands : show interface brief
  
show interface brief
Use this command to display status of both L2 and L3 (ALL) interfaces
Command Syntax
show interface brief <IFNAME|>
Parameters
brief
Brief summary of IP status and configuration.
IFNAME
Display the name of the interface.
Command Mode
Exec mode and Privileged Exec mode
Example
tr3-1#show interface brief
