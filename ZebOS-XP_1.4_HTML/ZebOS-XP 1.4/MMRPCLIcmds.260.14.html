Layer 2 Command Reference : CHAPTER 11 MMRP Commands : show mmrp timer
  
show mmrp timer
Use this command to display MMRP timer values associated with an interface.
Command Syntax
show mmrp timer IF_NAME
Parameters
IFNAME
Displays the name of the port.
Command Mode
Exec and Privileged Exec mode
Example
The following sample output from this command displays all MMRP timer values associated with the interface eth2.
#show mmrp timer eth2
Timer Timer Value (centiseconds)
