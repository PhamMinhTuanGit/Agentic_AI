hal_ipv6_mc_pim_init
This function starts PIM routing for the specified FIB ID.
Syntax
int
hal_ipv6_mc_pim_init (int fib);
Input Parameters
fib
FIB ID
Output Parameters
None
Return Value
HAL_IP_FIB_NOT_EXIST
< 0 when function fails
HAL_SUCCESS when function succeeds
