Carrier Ethernet Command Reference : CHAPTER 12 PBB-TE CFM Commands : mep pbb-te crosscheck
  
mep pbb-te crosscheck
Use this command to configure a remote MEP (Maintenance End Point).
Use the no form of the command to remove a MAC address from a remote CBP (Customer Backbone Port).
Command Syntax
mep pbb-te crosscheck mpid MEPID te-sid TE_SID (mac MAC|)
no mep pbb-te crosscheck mpid MEPID te-sid TE_SID (mac MAC|)
Parameters
mpid
Remote MEP.
MEPID
Configure remote MEP ID <1-8191>.
te-sid
Associate to TE-SID.
TE_SID
TE-SID <1-42949675>.
mac
Configure the remote MAC.
MAC
Remote MAC address in HHHH.HHHH.HHHH format.
Command Mode
Ethernet CFM PBB-TE mode
Examples
#configure terminal
(config)#ethernet cfm pbb-te domain-name type character-string name abc level 3 mip-creation default bridge backbone
(config-ether-cfm-pbb-te)#mep pbb-te crosscheck mpid 60 te-sid 20 mac 05.1111.1212
