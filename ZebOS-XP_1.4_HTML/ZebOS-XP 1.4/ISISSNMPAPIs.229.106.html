isis_get_circ_3way_enabled
This call gets the status of this circuit enabled 3Way handshake.
Syntax
int isis_get_circ_3way_enabled (u_int32_t vr_id, u_int32_t instance, u_int32_t circindex, u_int32_t *ret);
Input Parameters
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
circindex
IS-IS circuit index.
Output Parameters
ret
Status of the circuit enabled 3Way handshake.
1
isisTruthValueTrue
2
isisTruthValueFalse (default)
Return Values
ISIS_API_GET_SUCCESS for supported circuit index found in the specified instance.
ISIS_API_GET_ERROR for supported circuit index not found in the specified instance.
