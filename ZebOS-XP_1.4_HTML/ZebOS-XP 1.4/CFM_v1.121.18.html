Carrier Ethernet Command Reference : Appendix A CFM Version 1 Commands : ethernet cfm mep
  
ethernet cfm mep
Use this command to create a MEP and set it to the Up or Down state. When no primary VID is entered, the MEP uses the primary VID of the maintenance association.
Note: To create a link-level MEP, do not enter a VID in the command line.
Use the no form of this command to remove the MEP.
Command Syntax
ethernet cfm mep (down|up) mpid MEPID active (true | false) domain DOMAIN_NAME (vlan VLANID|)(local-vid VID|)(uni-mep|) (bridge <1-32>|)
no ethernet cfm mep (down|up) mpid MEPID domain DOMAIN_NAME (vlan VLANID|)
(local-vid VID|)(bridge <1-32>|)
Parameters
down
Specify the MEP as a down MEP.
up
Specify the MEP as an up MEP.
mpid
Enter the mepid ranging from <1-8191>
active
Specify the administrative state of the MEP.
true
Specify the state of the MEP to active.
false
Specify the state of the MEP to inactive.
domain
Specify the name of the maintenance domain in ASCII format.
bridge
Specify the ID of a bridge in the range of <1-32>.
local-vid
Specify the ID of the local VLAN.
uni-mep
Enter the UNI-MEG MEP to intimate the UNI type.
vlan
Specify the ID of a VLAN.
Command Mode
Interface mode
Example
(config)#interface eth1
(config-if)#ethernet cfm mep down mpid 23 active true domain abc vlan 3 bridge 1
(config-if)#ethernet cfm mep down mpid 23 active true domain abc vlan 3 local-vid 4 bridge 1
(config-if)#ethernet cfm mep down mpid 23 active true domain abc bridge 1
(config-if)#no ethernet cfm mep down mpid 23 domain abc vlan 3 bridge 1
(config-if)#no ethernet cfm mep down mpid 23 domain abc bridge 1
