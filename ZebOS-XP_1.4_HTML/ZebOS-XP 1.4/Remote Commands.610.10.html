System Management Command Reference : CHAPTER 9 Remote Management : copy ftp (startup-config|running-config)
  
copy ftp (startup-config|running-config)
Use this command to copy the start up configuration or running configuration from an FTP server to the local device.
Command Syntax
copy ftp FTP-URL (startup-config|running-config)
Parameters
FTP-URL
Configuration source: ftp:[//[username@]server][/path]
startup-config
Copy start-up configuration
running-config
Copy running configuration
Command Mode
Privileged Exec mode
Examples
#copy ftp ftp://ftp.mysite.com running-config
