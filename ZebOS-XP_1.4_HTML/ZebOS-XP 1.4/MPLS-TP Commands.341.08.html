Multi-Protocol Label Switching Command Reference : CHAPTER 7 MPLS-TP Commands : mpls-tp provider-interface
  
mpls-tp provider-interface
Use this command to configure an interface as a MPLS-TP provider interface; this allows MPLS-TP tunnels to be configured over the specified interface.
• Set up a data link in data-control mode
• Enable label switching (platform label space) on the physical interface
Use the no parameter with this command to remove a provider interface.
Note: Removing a provider interface requires that no MPLS-TP tunnels are set up over the affected interface.
Command Syntax
mpls-tp provider-interface A.B.C.D
no mpls-tp provider-interface
Parameters
A.B.C.D
Set local link identifier in IPv4 address format
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth1
(config-if)#mpls-tp provider-interface 20.1.1.1
 
(config-if)#no mpls-tp provider-interface
