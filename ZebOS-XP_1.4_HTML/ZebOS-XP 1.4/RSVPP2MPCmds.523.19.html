RSVP-TE Command Reference : CHAPTER 7 Point-to-Multipoint Commands : rsvp-trunk
  
rsvp-trunk
Use this command to set up an P2MP trunk for RSVP LSP. Upon successful execution of this command, the mode is changed from RSVP P2MP mode to P2MP Trunk mode for subsequent configuration of trunk properties.
Command Syntax
rsvp-trunk TRUNKNAME (ipv4 p2mp|ipv6 p2mp)
rsvp-trunk TRUNKNAME (ipv4|ipv6)
Parameters
TRUNKNAME
Name to use for the P2MP trunk
ipv4
IPv4 address family trunk
p2mp
P2MP-enabled trunk
ipv6
IPv6 address family trunk
p2mp
P2MP-enabled trunk
Command Mode
RSVP P2MP mode
Examples
(config)#rsvp-trunk T1 ipv4 p2mp
(config-p2mp-trunk)#
