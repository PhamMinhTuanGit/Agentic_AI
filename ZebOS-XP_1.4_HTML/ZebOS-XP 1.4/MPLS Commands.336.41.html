Multi-Protocol Label Switching Command Reference : CHAPTER 2 MPLS Commands : show mpls
  
show mpls
Use this command to display MPLS data.
Command Syntax
show mpls
Parameters
None
Command Mode
Exec mode and Privileged Exec mode
Examples
