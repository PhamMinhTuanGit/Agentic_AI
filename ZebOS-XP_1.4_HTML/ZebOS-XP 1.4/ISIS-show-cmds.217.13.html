Intermediate System to Intermediate System Command Reference : CHAPTER 3 IS-IS Show Commands : show isis counter
  
show isis counter
Use this command to display the IS-IS system counter entry MIBs.
Command Syntax
show isis counter
Parameters
None
Command Mode
Exec mode, Privileged exec mode
Example
