Multicast Configuration Guide : CHAPTER 8 IGMP Proxy Configuration : Enabling Proxy downstream interface : Validation
  
Validation
Here is the same configuration for IGMP Proxying router.
hostname Router1
!
interface eth0
!
interface eth1
ip igmp proxy-service
!
interface eth2
ip igmp mrouter-proxy eth1
!
interface lo
!
!
ip multicast-routing
!
