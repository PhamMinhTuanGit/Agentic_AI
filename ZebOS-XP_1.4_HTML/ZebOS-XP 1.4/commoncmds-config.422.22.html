Network Services Module Command Reference : CHAPTER 3 Common Configure Mode Commands : router-id
  
router-id
Use this command to add a router identifier for this system.
Use the no form of this command to disable this function.
Command Syntax
router-id A.B.C.D
no router-id (A.B.C.D|)
Parameters
A.B.C.D
Specifies the router identifier in IP address format for this system.
Command Mode
Configure mode
Examples
#configure terminal
(config)#router-id 123.12.3.123
(config)#
