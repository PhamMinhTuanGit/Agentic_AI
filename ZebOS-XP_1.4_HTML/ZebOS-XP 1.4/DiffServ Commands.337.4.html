Multi-Protocol Label Switching Command Reference : CHAPTER 3 Differentiated Services Commands : show mpls diffserv
  
show mpls diffserv
Use this command to display Diffserv configuration information.
Command Syntax
show mpls diffserv
Parameters
None
Command Mode
Privileged Exec mode and Exec mode
Example
The DiffServ configuration information displayed by this command includes:
• All configurable Diffserv classes that can be used as PHB/PSC.
• PHB/PSC supported by this node.
• Node level PHB-EXP mapping.
Following is a sample output of the show mpls diffserv command showing DiffServ configuration information.
