oam_api_lps_hold_off_timer_set
This function sets the HOLD-OFF timer value of the protection-group identified by protection-group name.
Syntax
s_int32_t
oam_api_lps_hold_off_timer_set (u_int32_t vr_id, char *grp_name_str,
u_int32_t hold_off_timer)
Input Parameters
vr_id
VR instance ID
grp_name_str
The protection-group name
hold_off_time
Timer value in seconds; input range is <0-720>
Output Parameters
None
Return Values
OAM_API_SET_ERR_INVALID_HOLD_OFF_TIMER_VALUE when the hold-off-timer value is invalid
OAM_API_SET_ERROR_PSC_GRP_LOOKUP when the protection-group lookup fails
OAM_API_LPS_SET_SUCCESS when the function succeeds
