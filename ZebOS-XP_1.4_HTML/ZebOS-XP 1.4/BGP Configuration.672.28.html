BGP Authentication
BGP authentication allows users to receive selected routing information, enhancing security of their network traffic. When BGP authentication is enabled on a router, the router verifies routing packets it receives by exchanging a password that is configured on both the sending and receiving routers.
In this example, both R1 and R2 have ipi as the password. Configure the same password on all routers that are to communicate using BGP in a network
Figure 9-82: BGP Authentication
R1
 
#configure terminal
Enter Configure mode.
(config)#router bgp 200
Define the routing process. The number 200 specifies the AS number of R1.
(config-router)#neighbor 10.10.10.11 remote-as 200
Define BGP neighbors, and establish a TCP session. 10.10.10.11 is the IP address of the neighbor (R2), and 200 is the neighbor’s AS number.
(config-router)#neighbor 10.10.10.11 password 1 ipi
Specify the encryption type and the password.
