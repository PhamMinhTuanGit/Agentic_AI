CHAPTER 9 Provider Backbone Bridging Commands
This chapter describes the Provider Backbone Bridging (PBB) commands. Provider Backbone Bridging enables a provider organization to build 802.1ah-compliant Ethernet backbone networks by interconnecting 802.1ad Provider Bridging aggregate networks.
Note: Provider Backbone Bridging is not supported for ZebIC releases.

• bridge-group path-cost
• bridge-group priority
• bridge-group spanning-tree
• bridge-group vlan

• bridge-group vlan priority
