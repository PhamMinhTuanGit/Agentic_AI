Multi-Protocol Label Switching Command Reference : CHAPTER 8 MPLS-TP OAM Commands : mep-id
  
mep-id
Use this command to configure an ITUT Maintenance Entity Group End Point (MEP). This command changes to ITUT MP mode.
Use the no parameter with this command to remove an ITUT MEP.
Command Syntax
mep-id <1-8191>
no mep-id <1-8191>
Parameters
<1-8191>
MEP identifier.
Command Mode
ITUT MEG configuration mode
Examples
#configure terminal
(config)#itut meg new12 level 1
(config-itut-meg)#mep-id 12
(config-itut-mp)#
