Network Services Module Command Reference : CHAPTER 10 Internet Protocol Security Commands : crypto map local-address
  
crypto map local-address
Use this command to specify an interface to be used by the crypto map for IPSec traffic.
Use the no form of the command to remove this command from the configuration.
Command Syntax
crypto map [MAP-NAME] local-address [INTERFACE-ID]
no crypto map [MAP-NAME] local-address
Parameters
MAP-NAME
The name that identifies the crypto map set.
INTERFACE-ID
Specify an interface that should be used by the router to send traffic to peers.
Command mode
Configure mode
Example
ZebOS(config)#crypto map MAP1 local-address p7p1
