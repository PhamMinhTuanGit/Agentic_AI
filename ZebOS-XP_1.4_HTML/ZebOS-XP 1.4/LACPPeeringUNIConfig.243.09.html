DOT1.X Tunneling in UNI Configuration
Topology
UNI can be configured to tunnel the layer 2 protocol DOT1.X. When DOT1.X is present, a tunneling xsupplicant on one side of a provider network is authenticated by RADIUS server, which is in other side of the provider network. The customer-edge port (UNI) of the Provider Network is configured to tunnel DOT1.X packets.
