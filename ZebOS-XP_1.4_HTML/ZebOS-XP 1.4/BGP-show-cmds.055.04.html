Border Gateway Protocol Command Reference : CHAPTER 5 BGP Show Commands : show bgp A.B.C.D/M
  
show bgp A.B.C.D/M
Use this command to display BGP route information for a network prefix.
Command Syntax
show bgp ipv4 (unicast|multicast) A.B.C.D/M
show ip bgp A.B.C.D/M
show ip bgp ipv4 (unicast|multicast) A.B.C.D/M
Parameters
ipv4
IPv4 routes
unicast
Unicast prefixes
multicast
Multicast prefixes
A.B.C.D/M
IP prefix (network/length), for example, 35.0.0.0/8
Command Mode
Privileged Exec and Exec mode
Examples
#show bgp ipv4 unicast 35.0.0.1/8
