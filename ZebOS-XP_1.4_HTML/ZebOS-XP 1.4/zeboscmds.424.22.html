Network Services Module Command Reference : CHAPTER 5 Interface Commands : ipv6 address
  
ipv6 address
Use this command to set the IPv6 address of an interface.
Use the no form of this command to disable this function.
Command Syntax
ipv6 address X:X::X:X/M
ipv6 address X:X::X:X/M anycast
no ipv6 address X:X::X:X/M
Parameters
X:X::X:X/M
Specify the IP destination prefix and a mask length <0-128>.
anycast
Specify the anycast flag.
Command Mode
Interface mode
Example
#configure terminal
(config)#interface eth0
(config-if)#ipv6 address 3ffe:506::1/64
