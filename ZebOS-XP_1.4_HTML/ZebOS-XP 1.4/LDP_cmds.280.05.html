Label Distribution Protocol Command Reference : CHAPTER 2 LDP Commands : clear ldp session
  
clear ldp session
Use this command to clear a session established with a specified peer, or to clear all sessions for the current LSR.
Command Syntax
clear ldp session (A.B.C.D|*)
clear ldp session (X:X::X:X|*)
Parameters
*
Specify to clear all sessions.
A.B.C.D
Specify to clear IPv4 address of the peer.
X:X::X:X
Specify to clear IPv6 address of the peer.
Command Mode
Privileged Exec mode
Example
#clear ldp session 123.123.123.33
#clear ldp session 3ffe::7
