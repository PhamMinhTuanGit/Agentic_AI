Carrier Ethernet Command Reference : CHAPTER 10 Provider Backbone Bridging CFM Commands : ais status
  
ais status
Use this command to enable or disable Alarm Indicator Signaling (AIS).
Command Syntax
ais status (enable | disable) unicast RMEP_MAC level <0-7>
ais status (enable | disable) multicast level <0-7>
Parameters
disable
Specify to disable AIS
enable
Specify to enable AIS
multicast
Configure multicast AIS.
unicast
Configure unicast AIS.
RMEP_MAC
Enter the remote MEP MAC address in HHHH.HHHH.HHHH format
level
Indicate a level at which to send the AIS frames
Command Mode
Ethernet CFM PBB MEP configuration mode
Examples
(config-cfm-pbb-mep)#ais status enable multicast level 1
(config-cfm-pbb-mep)#ais status enable unicast 1111.1111.1111 level 1
