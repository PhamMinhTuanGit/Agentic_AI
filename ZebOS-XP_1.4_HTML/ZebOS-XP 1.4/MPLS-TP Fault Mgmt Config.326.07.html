Multi-Protocol Label Switching Configuration Guide : CHAPTER 30 MPLS-TP Fault Management Configuration : Bidirectional Tunnel Configuration : PE2 (NSM)
  
PE2 (NSM)
 
#configure terminal
Enter configure mode.
(config)#mpls-tp global-id 400 node-id 4.4.4.4
Configure global ID as 400 and node ID 4.4.4.4.
(config)#interface eth1
Enter interface mode.
(config-if)#mpls-tp provider-interface 10.1.1.1
Configure interface eth1 as provider interface and interface local ID as 10.1.1.1.
(config)#mpls-tp tunnel 1 source 100 1.1.1.1 destination 400 4.4.4.4
Configure Tunnel with Tunnel ID 1 originating from this node PE1 (global ID 100 and node ID 1.1.1.) to destination at PE2 node (global ID 400 and node ID 4.4.4.4/
(config-tnl)#tunnel-name tnl1
Configure tunnel with name tnl1.
(config-tnl)#tunnel-mode bidirectional
Configure tunnel mode as bidirectional.
(config-bidir-tnl)#forward-path ilm-entry 1003 eth1 pop
Configure ILM entry for POP the label for forward path at egress.
(config-bidir-tnl)#reverse-path nhlfe-entry 2001 eth1
Configure NHFLE entry for PUSH the label for reverse path at egress.
