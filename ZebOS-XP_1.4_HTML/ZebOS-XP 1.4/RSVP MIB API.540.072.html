rsvp_snmp_get_next_tn_resource_storagetype
This function gets the storage type of the next tunnel.
Syntax
u_int32_t
rsvp_snmp_get_next_tn_resource_storagetype (int *rs_ix, u_int32_t *ret)
Input Parameters
rs_ix
Resource table index
Output Parameters
rs_ix
Next resource table index
ret
This constant from rsvpd/rsvp_snmp.h:
RSVP_SNMP_ST_TYPE_VOLATILE
 
Return Value
RSVP_API_GET_SUCCESS when the function succeeds
RSVP_API_GET_ERROR when the resource table is not found
