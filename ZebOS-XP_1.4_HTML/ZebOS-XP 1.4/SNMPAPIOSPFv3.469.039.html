ospf6_get_if_status
This function gets the status of whether OSPFv3 is configured on the given interface.
Syntax
int
ospf6_get_if_status (char *tag, int ifindex, int instid, int *ret);
Input Parameters
tag
OSPFv3 process tag
ifindex
Interface index
instid
Instance identifier
Output Parameters
ret
Row status of the interface:
ROW_STATUS_ACTIVE
 
Row is active
ROW_STATUS_NONEXISTENT
 
Row is nonexistent
Return Values
OSPF6_API_GET_ERROR when the function fails
OSPF6_API_GET_SUCCESS when the function succeeds
