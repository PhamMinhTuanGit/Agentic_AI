Multi-Protocol Label Switching Command Reference : CHAPTER 2 MPLS Commands : mpls ms-pw
  
mpls ms-pw
Use this command to configure the PW Switching Point description string for every multi-segment pseudowire (MS-PW) of switching provider edge (S-PE) TLV.
Use the no parameter with this command to disable this type of configuration.
Command Syntax
mpls ms-pw MS-PW S-PE-DESCR
no mpls ms-pw MS-PW S-PE-DESCR
Parameters
MS-PW
String that identifies the multi-segment pseudowire object
S-PE-DESCR
String that describes the switching provider edge object
Command Mode
Configure mode
Examples
#configure terminal
(config)#mpls ms-pw new 123
 
(config)#no mpls ms-pw new 123
