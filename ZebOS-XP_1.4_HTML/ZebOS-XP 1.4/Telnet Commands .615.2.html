System Management Command Reference : CHAPTER 14 Telnet : debug telnet server
  
debug telnet server
Use this command to display telnet debugging information.
Use the no form of this command to stop displaying telnet debugging information.
Command Syntax
debug telnet server
debug telnet server (emergencies|alerts|critical|errors|warnings |notifications|informational|debugging)
no debug debug telnet server
Parameters
server
Server
client
Client
emergencies
Emergencies
alerts
Alerts
critical
Critical
errors
Errors
warnings
Warnings
notifications
Notifications
informational
Informational
debugging
Debugging
Command Mode
Executive mode and configure mode
Examples
#debug telnet server
