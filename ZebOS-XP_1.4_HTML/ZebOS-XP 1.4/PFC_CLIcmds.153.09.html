Data Center Bridging Command Reference : CHAPTER 4 Priority-based Flow Control Commands : show priority-flow-control details
  
show priority-flow-control details
Use this command to display the PFC details for a specified interface or bridge. If you do not specify a bridge or interface, this commands shows statistics for the default bridge.
Command Syntax
show priority-flow-control details ((interface IFNAME)|(bridge <1-32>))
Parameters
IFNAME
Name of the input or output interface.
<1-32>
Specify a bridge ID.
Command Mode
Exec mode
Example
#show priority-flow-control details interface eth1
bridge : 2
priority flow control : on
interface : eth1
