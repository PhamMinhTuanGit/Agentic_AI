Bidirectional Forwarding Detection Developer Guide : CHAPTER 14 BFD MIB Support : APIs : bfd_notification_set
  
bfd_notification_set
This function sets the notification traps.
Syntax
s_int32_t
bfd_notification_set (u_int32_t vr_id, u_int32_t set)
Input Parameters
vr_id
Virtual router ID
set
Value to be set
Output Parameters
None
Return Values
BFD_FAILURE when the function fails
BFD_SUCCESS when the function succeeds
