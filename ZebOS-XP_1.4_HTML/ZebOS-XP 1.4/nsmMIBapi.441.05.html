Network Services Module Developer Guide : CHAPTER 8 MIB-II API : SNMP APIs : nsm_get_sys_desc
  
nsm_get_sys_desc
This function gets the full name and version identification of the system.
Syntax
int
nsm_get_sys_desc (char *sysDesc)
Input Parameters
None
Output Parameters
sysDesc
System description
Return values
NSM_SUCCESS when the function succeeds
NSM_ERR_UNAME_FAILED when the function fails
