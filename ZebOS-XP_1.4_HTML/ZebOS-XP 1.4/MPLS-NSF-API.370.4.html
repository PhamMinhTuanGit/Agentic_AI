Multi-Protocol Label Switching Developer Guide : CHAPTER 23 MPLS Non-stop Forwarding API : API : nsm_gmpls_ftn_del_msg_process
  
nsm_gmpls_ftn_del_msg_process
This function is a handler for FTN delete messages.
Syntax
s_int32_t
nsm_gmpls_ftn_del_msg_process (struct nsm_master *nm,
u_int32_t vrf_id,
struct fec_gen_entry *fec,
u_int32_t ftn_ix)
Input Parameters
*nm
Pointer to the NSM master structure
vrf_id
Virtual routing/forwarding instance ID
*fec
Forwarding equivalency class
ftn_ix
FTN table index
Output Parameters
None
Return Value
PAL_TRUE when the function succeeds
PAL_FALSE when the function fails
