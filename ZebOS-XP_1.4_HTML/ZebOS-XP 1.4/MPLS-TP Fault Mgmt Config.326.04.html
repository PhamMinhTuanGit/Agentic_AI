Multi-Protocol Label Switching Configuration Guide : CHAPTER 30 MPLS-TP Fault Management Configuration : Bidirectional Tunnel Configuration
  
Bidirectional Tunnel Configuration
PE1 (NSM)
 
#configure terminal
Enter configure mode.
(config)#mpls-tp global-id 100 node-id 1.1.1.1
Configure global ID as 100 and node ID as 1.1.1.1 on PE1 node.
(config)#interface eth1
Enter interface mode.
(config-if)#mpls-tp provider-interface 10.1.1.1
Configure eth1 as provider interface and interface local ID as 10.1.1.1.
(config)#mpls-tp tunnel 1 source 100 1.1.1.1 destination 400 4.4.4.4
Configure Tunnel with Tunnel ID 1 originating from this node PE1 (global ID 100 and node ID 1.1.1.1) to destination at PE2 node (global ID 400 and node ID 4.4.4.4).
(config-tnl)#tunnel-name tnl1
Configure tunnel name.
(config-tnl)#tunnel-mode bidirectional
Configure mode of tunnel as bidirectional.
(config-bidir-tnl)#forward-path nhlfe-entry 1001 eth1
Configure NHLFE entry for PUSH the label at ingress for the forward path.
(config-bidir-tnl)#reverse-path ilm-entry 2003 eth1 pop
Configure ILM-entry for POP the label at ingress for the reverse path.
