Carrier Ethernet Command Reference : CHAPTER 2 Ethernet CFM Commands : ethernet cfm vid
  
ethernet cfm vid
Use this command to configure a default VLAN priority for a bridge. This priority is used when onmd receives a CVLAN frame (maintenance VID) sent out of the PNP with the SVLAN. You can also configure a priority for the SVLAN on the bridge. This priority is carried in the SVLAN header going out of the PNP.
Similarly, SVLAN frames received by onmd are relayed out of CEP on the default VID of the PEP. The software forwarder itself forwards double-tagged frames if they are without a C-TAG.
Command Syntax
ethernet cfm vid <2-4094> priority <0-7> (bridge <1-32>|)
Parameters
vid
Specify the VLAN.
<2-4094>
Specify the VLAN ID.
priority
Default priority for CFM frames to relay
<0-7>
Default priority for CFM frames to relay
bridge
Specify a bridge.
<1-32>
Specify a bridge ID.
Command Mode
Configure mode
Examples
#config terminal
(config)#ethernet cfm vid 3 priority 4 bridge 1
 
#configure terminal
(config)#ethernet cfm vid 7 priority 2
