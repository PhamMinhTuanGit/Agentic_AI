evb bridge cdcp svid-pool-range
Use this command to set the lowest and highest S-VIDs (Service VLAN identifiers) for assignment by CDCP (S-Channel Discovery and Configuration Protocol).
Command Syntax
evb bridge <1-32> cdcp svid-pool-range <2-4094> <2-4094>
Parameters
<1-32>
Bridge identifier
<2-4094>
Lowest and highest S-VIDs
Command Mode
Configure mode
Examples
#configure terminal
(config)#evb bridge 14 cdcp svid-pool-range 256 512
