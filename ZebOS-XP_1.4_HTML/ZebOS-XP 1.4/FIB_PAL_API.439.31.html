pal_kernel_ipv4_del
This function removes an existing entry from the kernel IPv4 forwarding table.
API call
result_t pal_kernel_ipv4_del (struct prefix *p, struct rib *r);
Input Parameters
p
Pointer to the prefix
r
Pointer to the RIB entry
Output Parameters
None
Result Value
Platform dependent
