Carrier Ethernet Command Reference : CHAPTER 7 MEF-ENNI Commands : show ethernet enni evc
  
show ethernet enni evc
Use this command to show the Operational virtual connector (OVC) identification for an OVC or interface.
Command Syntax
show ethernet enni ovc attributes (interface IF_NAME | ovc-id OVC_ID (bridge <1-32>|))
Parameters
interface
Specify the interface.
IF_NAME
Specify the interface name.
evc-id
Display the EVC ID for the attributes needed to be displayed
EVC_ID
Specify the EVC ID.
bridge
Specify a bridge.
<1-32>
Specify a bridge ID.
Command Mode
Executive mode
Example
#show ethernet uni evc attributes ovc-id new bridge 1
