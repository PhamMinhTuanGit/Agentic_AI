Layer 2 Command Reference : CHAPTER 10 GVRP Commands : set gvrp disable
  
set gvrp disable
Use this command to disable (reset) GVRP globally on a switch for the default bridge instance. This command does not disable GVRP in all ports of a bridge.
Command Syntax
set gvrp disable bridge BRIDGE_NAME
Parameters
BRIDGE_NAME
Bridge identifier.
Command Mode
Configure mode
Examples
#configure terminal
(config)#set gvrp disable bridge 12
