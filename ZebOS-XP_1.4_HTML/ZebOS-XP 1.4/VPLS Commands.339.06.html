Multi-Protocol Label Switching Command Reference : CHAPTER 5 Virtual Private LAN Service Commands : learning disable
  
learning disable
Use this command to configure MAC address learning for a VPLS instance.
Use the no parameter with this command to disable the MAC address learning.
Command Syntax
learning disable
no learning disable
Parameters
None
Command Mode
VPLS Signaling mode
Example
# configure terminal
(config)#mpls vpls test 100
(config-vpls)#signaling bgp
(config-vpls-sig)#ve-id 2
(config-vpls-sig)#exit-signaling
