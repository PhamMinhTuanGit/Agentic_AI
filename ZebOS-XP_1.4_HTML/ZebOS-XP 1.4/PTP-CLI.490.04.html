Precision Time Protocol Command Reference : CHAPTER 2 Precision Time Protocol Commands : clock-port
  
clock-port
Use this command to enable PTP on an interface. This command also changes the command mode to PTP clock port configure mode.
Note: Before you give this command, you must have previously created a clock with the ptp clock command.
Use the no ptp port command to disable PTP on an interface.
Command Syntax
clock-port (transport ((udp (v4|v6)) | ethernet)|)
no ptp port
Parameters
transport
Transport type:
UDP
UDP:
v4
IPv4 addresses.
v6
IPv6 addresses.
ethernet
Ethernet.
Command Mode
Interface mode
Examples
The following example enables PTP for the eth0 interface:
>ena
#conf term
Enter configuration commands, one per line. End with CNTL/Z.
(config)#interface eth0
(config-if)#clock-port
(config-clk-port)#
The following example disables PTP for the interface.
(config-if)#no ptp port
