Multi-Protocol Label Switching Command Reference : CHAPTER 7 MPLS-TP Commands : mpls-tp ring tunnel
  
mpls-tp ring tunnel
Use this command to define an MPLS-TP ring tunnel.
• Use this command to change the command mode to Tunnel mode.
• Use the no parameter with this command to remove a configured MPLS-TP ring tunnel.
Note: The tunnel role can only be transit.
Command Syntax
mpls-tp ring-tunnel
Parameters
<1.65535>
Tunnel ID value.
Command Mode
Configure Mode
Examples
#configure terminal
(config)# mpls-tp ring-tunnel 1
(config)#
 
(config)#no mpls-tp ring-tunnel
