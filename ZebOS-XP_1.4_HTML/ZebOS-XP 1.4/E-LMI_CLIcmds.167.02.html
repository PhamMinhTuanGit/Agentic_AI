Ethernet Local Management Interface Command Reference : CHAPTER 2 ELMI Commands : clear ethernet lmi statistics
  
clear ethernet lmi statistics
Use this command to clear ELMI statistics of all bridge interfaces on which ELMI is enabled.
Command Syntax
clear ethernet lmi statistics (bridge <1-32>|)
clear ethernet lmi statistics interface IFNAME
Parameters
bridge
Use this parameter to enter the bridge-group ID used for bridging <1-32>.
IFNAME
Use this parameter as the interface name on an EVC (Ethernet Virtual Connection). For example, eth1 or eth2.
Command Modes
Executive Mode and Privileged Executive Mode
Examples
#clear ethernet lmi statistics
#clear ethernet lmi statistics bridge 1
#clear ethernet lmi statistics interface eth1
