trill_process_mul_tracert_request
This function checks parameters as per a given flow chart and calls trill_channel_echo_reply_send() or trill_channel_mul_hopcnt_err_send() (refer to trill_channel_echo_reply_send and trill_channel_mul_hopcnt_err_send, respectively).
Syntax
u_int32_t
trill_process_mul_tracert_request (struct trill_channel_packet *dpkt,
struct trill_interface *isi,
u_int32_t seq_num, u_int16_t instance_id)
Input Parameters
*dpk
Received channel data packet.
*isi
Pointer to the interface on which a frame was received.
seq_num
Specifies the pointer to the sequence number.
instance_id
Instance ID.
Output Parameters
None
Return value
TRILL_CHANNEL_FAIL
TRILL_CHANNEL_SUCCESS
