Carrier Ethernet Command Reference : CHAPTER 5 Link Layer Discovery Protocol v2 Commands : lldp debug
  
lldp debug
Use this command to set the debugging functions for LLDP.
Use the no form of this command to turn off LLDP debugging functions
Command Syntax
lldp debug (event|rx|tx|message)
no lldp debug (event|rx|tx|message)
Parameters
event
Enable or disable event debugging
message
Enable or disable NSM message debugging
rx
Enable or disable RX debugging
tx
Enable or disable TX debugging
Command Mode
Exec mode and Privileged Exec mode
Examples
#lldp debug event
#lldp debug messages
