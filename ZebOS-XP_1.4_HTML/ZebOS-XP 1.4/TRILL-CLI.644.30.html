show trill nicknamedatabase
Use this command to view RBridge nicknames, associated hostname, priority of use and the VLAN forwarder flag.
Command Syntax
show trill nicknamedatabase
Parameters
None
Command Mode
Exec mode and Privilege Exec mode
Example
#show trill nicknamedatabase
