rbridge-mping
Use this command to send a number of echo requests to target nicknames based on count value and VLAN ID of a distribution tree.
Command Syntax
rbridge-mping dtree NAME (|LINE)
Parameters
NAME
DTree name in hexadecimal range <0x0001 - 0xFFC0>.
LINE
Fields for traceroute options, including one of the following:
-v
VLAN ID <1- 4094>. Default VLAN is 1.
-c
Retry count value in seconds <1- 65535>. Default value is 4 seconds.
-I
Ping interval in seconds <1 - 65535>. Default value is 3 seconds.
-t
Ping timeout value in seconds <1 - 65535>. Default value is 10 seconds.
-d
Dtree nicknames in hexadecimal. Range <0x0001 - 0xFFC0>
Command Mode
Enable and Privilege Enable mode
Examples
>enable
#rbridge-mtraceroute dtree 1111 -v 2 -c 5 -i 4 -t 15 -d 1212 1313
