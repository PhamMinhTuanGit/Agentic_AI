Multi-Protocol Label Switching Developer Guide : CHAPTER 18 Static VPLS API : Functions : nsm_vpls_vc_fib_entry_add_process
  
nsm_vpls_vc_fib_entry_add_process
This call is used to add a VPLS mesh or spoke VC static FIB entry.
Syntax
nsm_vpls_vc_fib_entry_add_process(u_int32_t vr_id,
char* vpls_id_str,u_int8_t vc_style,
char *egress,char* in_lbl,
char* out_if, char* out_lbl)
Input Parameters
vr_id
VR identifier
vpls_id_str
VPLS identifier
vc_style
Set VC style as mesh or spoke
egress
Peer address
in_lbl
Incoming label
out_if
Provider-facing interface
out_lbl
Outgoing label
Output Parameters
none
