Integrated Management Interface Command Reference : CHAPTER 2 Common IMI Commands : terminal length
  
terminal length
Use the terminal length command to display the number of lines on a screen. Enter a value between 0 and 512 lines. Enter zero for no pausing.
Use the no option to unset the number of lines on a screen.
Command Syntax
terminal length <0-511>
terminal no length <0-511>
Parameters
<0-511>
Enter the number of lines on screen (0 for no pausing)
Command Mode
Exec mode and Privileged Exec mode
Examples
>enable
#terminal length 0
