Multi-Protocol Label Switching Command Reference : CHAPTER 5 Virtual Private LAN Service Commands : show vpls NAME mac-address
  
show vpls NAME mac-address
Use this command to display retrieved VPLS learning mac-addresses per VPLS-instance on MPLS enabled node.
Command Syntax
show vpls NAME mac-address
Parameters
NAME
Specify the name of the VPLS instance
mac-addresses
Specify the MAC-address
Command Mode
Exec modes
Examples
#show vpls v1 mac-address
MAC address Learned from Age-out
0000.002a.0104 1 300
0000.002a.0105 1 300
