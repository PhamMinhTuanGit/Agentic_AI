Multi-Protocol Label Switching Configuration Guide : CHAPTER 25 MPLS-TP MEG Configuration : Configuring MEGs Using IETF Identifiers : Data Link Service
  
Data Link Service
P1 (OAM)
 
#configure terminal
Enter configure mode.
(config)#ietf meg meg-5
Configure the MEG name as meg-5.
(config-ietf-meg)#service type datalink
Configure the service type as data link.
(config-ietf-meg)#me me-5 datalink
Configure the ME name as me-5.
(config-ietf-me)#service datalink eth3
Associate data link eth3 with the ME.
