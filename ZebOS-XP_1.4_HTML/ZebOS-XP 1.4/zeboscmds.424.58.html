Network Services Module Command Reference : CHAPTER 5 Interface Commands : show running-config interface ipv6
  
show running-config interface ipv6
Use this command to show the running system status and configuration for a specified IPv6 protocol.
Command Syntax
show running-config interface IFNAME ipv6 ospf
show running-config interface IFNAME ipv6 pim
show running-config interface IFNAME ipv6 rip
Parameters
ospf
Display Open Shortest Path First (OSPF) for IPv6 information.
pim
Display Protocol Independent Multicast (PIM) for IPv6 information.
rip
Display Routing Information Protocol (RIP) for IPv6 information.
Command Mode
Privileged Exec mode
Example
#show running-config interface eth1 ipv6 ospf
!
interface eth1
switchport
