Unicast Configuration Guide : CHAPTER 6 IS-IS IPv4 : Overload Bit : R4
  
R4
 
# configure terminal
Enter Configure mode.
(config)# router bgp 100
Create a BGP routing instance (100).
(config-router)# neighbor 1.1.1.1 remote-as 1
Specify the neighbor’s IP address (1.1.1.1) and the ASN value of the neighbor (1).
(config-router)# exit
Exit Router mode and return to Configure mode.
(config)# router isis 1
Create an IS-IS routing instance (1).
(config-router)# net 49.0001.0000.0000.0004.00
Define the NET address.
(config-router)# exit
Exit Router mode and return to Configure mode.
(config)# interface eth1
Specify the interface (eth1)to configure and enter Interface mode.
(config-if)# ip router isis 1
Enable IS-IS routing on interface eth1 (connected to R3).
(config-if)# exit
Exit Interface mode and return to Configure mode.
(config)# interface eth2
Specify the interface (eth2)to configure and enter Interface mode.
(config-if)# ip router isis 1
Enable IS-IS routing on interface eth2 (connected to R2).
