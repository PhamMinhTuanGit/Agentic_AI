Multicast Configuration Guide : CHAPTER 4 Multicast Virtual Routing Configuration : Enable PIM on a VR : Bind Interfaces to VR1 and VR2
  
Bind Interfaces to VR1 and VR2
 
#configure terminal
Enter Configure mode.
(config)#interface eth1
Enter the Interface mode for eth1.
(config-if)#virtual-router forwarding VR1
Bind interface eth1 to VR1.
(config-if)#exit
Exit Interface mode and return to Configure mode.
(config)#interface eth2
Enter the Interface mode for eth2.
(config-if)#virtual-router forwarding VR1
Bind interface eth2 to VR1.
(config-if)#exit
Exit Interface mode and return to Configure mode.
(config)#interface eth3
Enter the Interface mode for eth3.
(config-if)#virtual-router forwarding VR2
Bind interface eth3 to VR2.
(config-if)#exit
Exit Interface mode and return to Configure mode.
(config)#interface eth4
Enter the Interface mode for eth4.
(config-if)#virtual-router forwarding VR2
Bind interface eth4 to VR2.
(config-if)#end
Exit the Interface mode and return to Configure mode.
