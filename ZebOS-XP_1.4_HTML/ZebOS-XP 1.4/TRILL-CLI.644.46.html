Transparent Interconnection of Lots of Links Command Reference : CHAPTER 5 TRILL Commands : trill max-neighbor
  
trill max-neighbor
Use this command to configure the maximum number of neighbors on a broadcast link.
Use the no parameter with this command to reset this configuration to the default setting.
Command Syntax
trill max-neighbor (<0-500>| )
no trill max-neighbor
Parameters
<0-500>
Specify a maximum number of neighbors on a broadcast link in a decimal range of 0 to 500.
Command Mode
Interface mode
Default
Zero (0) neighbors
Examples
>enable
#configure terminal
(config)#interface eth1
(config-if)#trill max-neighbor 123
 
(config-if)#no trill max-neighbor
