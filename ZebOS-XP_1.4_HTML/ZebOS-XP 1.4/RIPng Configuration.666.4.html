Unicast Configuration Guide : CHAPTER 3 RIPng : R2
  
R2
 
#configure terminal
Enter Configure mode.
(config)#interface eth1
Specify the interface (eth1)to configure, and enter Interface mode.
(config-if)#ipv6 router rip
Enable RIPng routing on interface eth1.
(config-if)#exit
Exit Interface mode, and enter Configure mode.
(config)#interface eth2
Specify the interface (eth2)to configure, and enter Interface mode.
(config-if)#ipv6 router rip
Enable RIPng routing on interface eth2.
(config-if)#exit
Exit Interface mode, and enter Configure mode.
(config)#router ipv6 rip
Define a RIPng routing process, and enter Router mode.
