Layer 2 Command Reference : CHAPTER 4 Spanning Tree Protocol Commands : user-priority
  
user-priority
Use this command to set the default user priority associated with the interface.
Use the no parameter to unset the default user priority associated with the interface.
Command Syntax
user-priority <0-7>
no user-priority
Parameters
<0-7>
Set the user priority value.
Command Mode
Interface mode
Example
#configure terminal
(config)#interface eth1
(config-if)#user-priority 3
 
(config-if)#no user-priority
