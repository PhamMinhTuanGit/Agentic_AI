Configuring a Hybrid Switch Router
When a port changes from a switched port to a routed port, an Interface Delete message is sent to the Layer 2 protocols and an Interface Add message is sent to the Layer 3 protocols. The following figure shows the port, eth0, changing from a switched port to routed port:
Figure 2-1: Switched Port to Routed Port
When a port changes from a routed port to a switched port, an Interface Delete message is sent to the Layer 3 protocols and an Interface Add message is sent to the Layer 2 protocols. In this case, all properties of the Layer 3 interfaces are deleted: for instance, this interface is deleted from all Layer 3 management, all routes pointing to this interface are invalidated, and IP addresses are deleted.
