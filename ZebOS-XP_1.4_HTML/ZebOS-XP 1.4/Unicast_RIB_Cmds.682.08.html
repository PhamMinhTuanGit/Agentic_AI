Unicast Routing Information Base Command Reference : CHAPTER 2 Unicast RIB Commands : ip vrf
  
ip vrf
This command creates a VRF (Virtual Routing and Forwarding) RIB (Routing Information Base), assigns a VRF identifier, and switches to VRF mode.
Use the no parameter with command to remove a VRF RIB.
Command Syntax
ip vrf WORD
no ip vrf WORD
Parameter
WORD
VRF identifier
Command Mode
Configure mode
Example
#configure terminal
(config)#ip vrf IPI
(config-vrf)#
