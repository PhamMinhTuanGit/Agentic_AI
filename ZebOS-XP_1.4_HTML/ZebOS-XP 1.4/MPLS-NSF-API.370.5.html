nsm_gmpls_ilm_del_msg_process

Syntax
s_int32_t
nsm_gmpls_ilm_del_msg_process(struct nsm_master *nm,
struct ilm_add_gen_data *data)
Input Parameters
*nm
Pointer to the NSM master structure
data
ILM generated data
Output Parameters
None
Return Value
PAL_TRUE when the function succeeds
PAL_FALSE when the function fails
