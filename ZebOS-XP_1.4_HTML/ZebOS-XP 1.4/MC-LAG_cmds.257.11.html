Layer 2 Command Reference : CHAPTER 8 Multi-Chassis Link Aggregation Commands : portal-name
  
portal-name
Use this command to set the name of the portal.
Use the no form of this command to remove the portal name.
Command Syntax
portal-name WORD
no portal-name
Parameters
WORD
Portal name; maximum 15 characters
Command Mode
MLAG mode
Example
#config terminal
(config)#mlag configuration 1
(config-mlag)#portal-name ipi-mlag-1
