Multi-Protocol Label Switching Command Reference : CHAPTER 7 MPLS-TP Commands : show mpls-tp tunnel
  
show mpls-tp tunnel
Use this command to view the operational status of the Tunnel, its LSP and the LSP components (NHLFE or ILM).
Command Syntax
show mpls-tp tunnel
show mpls-tp tunnel NAME
Parameters
NAME
Identify the tunnel name with maximum 16 characters
Command Mode
Exec mode
Examples
#show mpls-tp tunnel Unidirect_tnl
