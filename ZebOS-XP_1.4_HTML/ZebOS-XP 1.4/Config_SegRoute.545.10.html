Segment Routing Configuration Guide : CHAPTER 2 Configuring Segment Routing : Configure Static Segment Routing : R1
  
R1
 
R1#configure terminal
Enter configure mode.
R1(config)#int eth1
Enter interface mode.
R1(config-if)#ip address 10.1.1.1/24
Configure the IP address of the interface.
R1(config-if)#exit
Exit interface mode.
R1#configure terminal
Enter configure mode.
R1(config)#segment-routing mpls
Enable MPLS-based segment routing.
R1(config)#segment-routing-static 20.1.1.0/24 10.1.1.2 eth1 1024001
Configure the prefix SID for the static route with the nexthop address and outgoing interface.
R1(config)#exit
Exit configure mode.
