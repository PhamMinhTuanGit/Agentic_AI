(cvlan | svlan) VLAN_ID oep-id
Use this command to create the entries in the oep-mapping table.
Command Syntax
(cvlan | svlan) VLAN_ID oep-id OEP_ID 
no (cvlan | svlan) VLAN_ID
no oep-id OEP_ID
Parameters
VLAN_ID
Specify the VLAN_ID
 
ovc-id
Specify the OVC ID for the SVLAN
Command Mode
OEP_MAP_MODE
Example
#configure terminal
(config)#interface eth1
