Layer 2 Command Reference : CHAPTER 9 GMRP Commands : show debugging gmrp
  
show debugging gmrp
Use this command to display the status of the debugging of the GMRP system.
To modify the lines displayed, use the | (output modifier token). To save the output to a file, use the > (output redirection token).
Command Syntax
show debugging gmrp
Parameters
None
Command Mode
Exec and Privileged Exec mode
Examples
#show debugging gmrp
GMRP debugging status:
GMRP Timer debugging is on
