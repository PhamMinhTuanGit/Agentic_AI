Network Services Module Developer Guide : CHAPTER 5 Internet Protocol Security API : Command API : ipsec_peer_ipv6_address_unset
  
ipsec_peer_ipv6_address_unset
This function unset the IPv6 peer address
Syntax
s_int32_t
ipsec_peer_ipv6_address_unset (struct ipsec_crypto_map *crypto_map,
struct pal_in6_addr addr)
Input Parameters
crypto_map
Cryptographic map, used to setup IPsec SA.
addr
IPv6 address.
Output Parameters
None
Return Values
IPSEC_API_SUCCESS when the function is successful.
IPSEC_API_ERROR when there is an error.
