Appendix A Build Configuration Options
The tables in this appendix show the ZebOS-XP configuration options that you set to configure the build environment. Each option is listed by protocol or service group. Examples of protocols are BGP or RIP; examples of service groups are Layer 2 or Multicast.
Note: The notation “Default” means that this is the default setting for the option.The default settings are specified in the configure.ac script and apply the most common feature set of ZebOS-XP.
