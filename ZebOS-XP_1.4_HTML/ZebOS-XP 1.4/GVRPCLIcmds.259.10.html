Layer 2 Command Reference : CHAPTER 10 GVRP Commands : set port gvrp
  
set port gvrp
Use this command to enable or disable GVRP on a port or all ports in a bridge.
Command Syntax
set port gvrp enable (IF_NAME|all)
set port gvrp disable (IF_NAME|all)
Parameters
enable
Enables GVRP on a switch.
disable
Disables GVRP on a switch.
all
All ports added to recently configured bridge.
IF_NAME
Specify the name of the interface.
Command Mode
Configure mode
Examples
#configure terminal
(config)#set port gvrp enable eth0
 
#configure terminal
(config)#set port gvrp enable all
