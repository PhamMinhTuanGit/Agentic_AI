var_dot1agCfmMepTable
This function is called when an external network management system queries an SNMP variable in the ieee8021CfmMib table.
Syntax
#include "onmd/cfm/cfm_ieee8021CfmMib.h"
unsigned char *
var_dot1agCfmMepTable(struct variable *vp, oid * name,
size_t *length, int exact,
size_t *var_len, WriteMethod ** write_method,
u_int32_t vr_id)
Input Parameters
vp
Pointer to SNMP variable structure
name
Pointer to the variable name (OID)
length
Number of elements (sub-ids) in the name
exact
Whether this request is a GET (exact match: PAL_TRUE) or a GETNEXT (PAL_FALSE)
vr_id
Unused
Output Parameters
var_len
Length of the variable that was read
write_method
Pointer to a pointer to the SET function (WriteMethod) for the variable
Return Value
A pointer to the value of the variable when the function succeeds
Zero (0) or NULL when the function fails
