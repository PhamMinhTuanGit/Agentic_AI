Shortest Path Bridging Command Reference : CHAPTER 2 SPB Configuration Commands : isis-spb system-id
  
isis-spb system-id
Use this command to set a network-wide unique identifier for the ISIS-SPB process.
Use the no form of this command to set the system identifier to its default value (zero).
Command Syntax
isis-spb system-id SYSTEM_ID
no isis-spb system-id
Parameters
SYSTEM_ID
Specify the system identifier in XX.XX.XX.XX.XX.XX format with 6 hexadecimal numbers separated by periods.
Default
By default, the system identifier is zero (0).
Command Mode
ISIS-SPB mode
Examples
(isis-spb-config)#isis-spb system-id 01.23.45.67.89.ab
 
(isis-spb-config)#no isis-spb system-id
