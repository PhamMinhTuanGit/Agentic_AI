Multi-Protocol Label Switching Command Reference : CHAPTER 11 SAToP Commands : show tdm satop-statistics
  
show tdm satop-statistics
Use this command to displays statistics for both the CE-bound IWF and PSN-bound IWFs.
Command Syntax
show tdm satop-statistics (ce-bound|psn-bound) interface IFNAME
Parameters
ce-bound
Show packet details for CE-bound.
psn-bound
Show the packet details for PSN-bound.
interface
Display the interface name.
IFNAME
Give the actual interface name.
Command Mode
Exec mode and Privileged Exec mode
Example
#show tdm satop-statistics ce-bound interface tdm
interface tdm 2
