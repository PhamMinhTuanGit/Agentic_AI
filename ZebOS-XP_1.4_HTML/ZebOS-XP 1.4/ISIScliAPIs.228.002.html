Intermediate System to Intermediate System Developer Guide : CHAPTER 9 IS-IS Command API : Command Line Interface APIs
  
Command Line Interface APIs
These two files contain the command line interface (CLI) and the application programming interface to it:
Module Name
Description
isis_api.c
Contains the functions that actually do the work of the commands in API format.
isis_cli.c
Contains the command definitions for the CLI that call the API functions.
