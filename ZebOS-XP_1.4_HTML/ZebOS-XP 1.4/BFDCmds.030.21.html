Bidirectional Forwarding Detection Command Reference : CHAPTER 2 Bidirectional Forwarding Commands : show bfd session
  
show bfd session
Use this command to display all BFD sessions.
Command Syntax
show bfd session (detail|)
Parameters
detail
Display session details.
Command Mode
Exec mode and Privilege Exec mode
Example
The example below displays the command syntax and sample output from the command using the detail parameter.
