Label Distribution Protocol Developer Guide : CHAPTER 9 LDP API : ldp_api_if_set_keepalive_timer
  
ldp_api_if_set_keepalive_timer
This call sets the keepalive timeout value for the LDP interface.
Syntax
int
ldp_api_if_set_keepalive_timer (u_int16_t keepalive_timeout,
struct interface* ifp,
u_char if_timeout)
Input Parameters
ifp
Interface pointer
keepalive_timeout
 
Keepalive timeout
if_timeout
Keepalive interval flag. The permitted values are LDP_IF_KEEPALIVE_TIMEOUT_SET(1) and LDP_IF_KEEPALIVE_TIMEOUT_SET(0).
Output Parameters
None
Return Values
LDP_SUCCESS
LDP_ERROR
