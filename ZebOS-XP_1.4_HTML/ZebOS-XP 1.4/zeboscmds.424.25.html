Network Services Module Command Reference : CHAPTER 5 Interface Commands : ipv6 nd link-mtu
  
ipv6 nd link-mtu
Use this command to set an advertised MTU option.
Use the no option with the command to reset the MTU option to the default statute.
Command Syntax
ipv6 nd link-mtu (<1280-65535>)
no ipv6 nd link-mtu
Parameters
<1280-65535>
Set a link MTU value within this range.
Command Mode
Interface mode
Example
#configure terminal
(config)#interface eth0
(config-if)#ipv6 nd link-mtu 1600
(config-if)#no ipv6 nd link-mtu
