RSVP-TE Command Reference : CHAPTER 8 Show Commands : show rsvp p2mp-session NAME
  
show rsvp p2mp-session NAME
Use these commands to display information about RSVP P2MP sessions for a trunk, LSP and sub-LSP.
Command Syntax
show rsvp p2mp-session NAME
show rsvp p2mp-session NAME primary-lsp
show rsvp p2mp-session NAME primary-lsp destination A.B.C.D
show rsvp p2mp-session NAME secondary-lsp
show rsvp p2mp-session NAME secondary-lsp destination A.B.C.D
Parameters
NAME
Trunk name
Command Mode
Privileged Exec and Exec modes
Examples
The example below shows output for a named trunk and primary LSP.
