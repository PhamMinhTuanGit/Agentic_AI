trill_get_rbridgebase_port_p2phellos
This call gets the status of port, to know whether IS-IS P2P Hellos is supported or not.
Syntax
int
trill_get_rbridgebase_port_p2phellos (u_int32_t vr_id, u_int32_t instance,
u_int32_t baseport, u_int32_t *ret)
Input Parameters
vr_id
An integer that contains the TRILL VR identifier.
instance
An integer that contains the TRILL instance ID.
baseport
Port number for which this entry contains RBridge management information.
Output Parameters
ret
Pointer to the status of port, to support IS-IS P2P hellos.
0
False
1
True
Return Value
TRILL_API_GET_SUCCESS for valid Instance ID and Port Number.
TRILL_API_GET_ERROR for valid Instance ID and Port Number not found.
