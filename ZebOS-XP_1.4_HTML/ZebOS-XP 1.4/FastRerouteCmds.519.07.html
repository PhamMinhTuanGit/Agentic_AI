RSVP-TE Command Reference : CHAPTER 3 Fast Reroute Commands : cspf-retry-timer
  
cspf-retry-timer
Use this command to specify the time between each retry that CSPF might carry out for a request received from RSVP.
Note: This command helps identify attributes of the FRR backup LSP for the facility-backup protection method only.
Use the no parameter with this command to remove the CSPF retry timer.
Command Syntax
cspf-retry-timer <1-600>
no cspf-retry-timer
Parameter
<1-600>
Timeout between successive retries, in seconds
Default
By default, no retry-timer configuration is defined for CSPF calculations, so the timer is set to 0.
Command Mode
Bypass mode
Example
#configure terminal
(config)#rsvp-bypass T1
(config-bypass)#cspf-retry-timer 45
 
(config)#rsvp-bypass T1
(config-bypass)#no cspf-retry-timer
