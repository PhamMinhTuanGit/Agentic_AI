Unicast Configuration Guide : CHAPTER 6 IS-IS IPv4 : Route Leaking : R2
  
R2
 
# configure terminal
Enter Configure mode.
(config)# router isis 1
Create an IS-IS routing instance for area 49 (1).
(config-router)# redistribute isis level-2 into level-1
Redistribute routes learned from level 2 into level 1 (route leaking).
(config-router)# end
Exit Router mode.
In the example, route, i ia 3.3.3.0/24 [115/30] via 15.1.1.32, eth2, 00:00:02, is the L2 route leaked by the L1/L2 router into the L1 router.
