trill_bridge_vlan_add
This function adds a VLAN information to the specified bridge. It is contained in the trilld.c file.
Syntax
s_int32_t
trill_bridge_vlan_add (char *bridge_name, u_int16_t vid, char *vlan_name, u_int8_t flags)
Input Parameters
*bridge_name
Specifies the name of the bridge.
vid
Specifies the VLAN ID to add: 1-4094.
*vlan_name
Specifies the VLAN name.
flags
Specifies the VLAN state, including:
suspended
(TRILL_VLAN_SUSPEND).
active
(TRILL_VLAN_ACTIVE).
configured
(TRILL_VLAN_INSTANCE_CONFIGURED).
Output Parameters
None
Return Values
RESULT_OK: Indicates the function call executed properly.
RESULT_ERROR: Indicates an error occurred; operation not performed.
