Virtual Router Redundancy Protocol Command Reference : CHAPTER 2 VRRP Commands : show running-config router vrrp
  
show running-config router vrrp
Use this command to show the running configuration for VRRP.
Command Syntax
show running-config router vrrp
Parameters
None
Command Mode
Exec mode and Privileged Exec mode
Example
The example below shows the running configuration of VRRP. Virtual Router is configured as Master and Owner of IP address.
#show running-config router vrrp
!
router vrrp 1 eth0
virtual-ip 39.0.0.24 master
circuit-failover eth1 30
advertisement-interval 6
preempt-mode false
enable
!
