Integrated Management Interface Command Reference : CHAPTER 2 Common IMI Commands : history
  
history
Use this command to set the maximum number of commands that are stored in the command history
Use the no parameter to remove the set configuration.
Command Syntax
history max <0-2147483647>
no history max
Parameters
max
Specify the maximum value.
<0-2147483647>
Specify the number of commands.
Command Mode
Line mode
Examples
#configure terminal
(config)#line vty 12 77
(config-line)#history max 123
 
(config-line)#no history max
