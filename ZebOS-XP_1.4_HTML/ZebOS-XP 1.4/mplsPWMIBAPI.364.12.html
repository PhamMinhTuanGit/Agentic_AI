nsm_mpls_set_pw_cw_prfrnce
This function sets the control word preference for a virtual circuit.
Syntax
#include "nsm/mpls/nsm_mpls_vc_snmp.h"
u_int32_t
nsm_mpls_set_pw_cw_prfrnce (struct nsm_master *nm,
u_int32_t pw_ix, u_int32_t cw);
Input Parameters
nm
Pointer to the NSM master structure
pw_ix
Index to the virtual circuit table
cw
Control word preference
Output Parameters
None
Return Value
NSM_API_SET_ERROR when the PW index is not valid
NSM_API_SET_SUCCESS when the function succeeds
