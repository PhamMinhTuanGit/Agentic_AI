isis_get_next_sys_stat_spf_runs
This call gets the number of times we ran SPF at the next level.
Syntax
int isis_get_sys_stat_spf_runs (u_int32_t vr_id, u_int32_t instance, u_int32_t level, u_int32_t *ret);
Input Parameter
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
level
IS-IS level index, that is, 1 for level 1 IS or 2 for level 2 IS.
Output Parameter
ret
Number of times SPF ran at the next level.
Return Value
ISIS_API_GET_SUCCESS for the next IS level index found in the specified instance.
ISIS_API_GET_ERROR for the next IS level index not found in the specified instance.
