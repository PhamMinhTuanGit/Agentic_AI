Border Gateway Protocol Command Reference : CHAPTER 5 BGP Show Commands : show bgp neighbors routes
  
show bgp neighbors routes
Use this command to display all accepted routes learned from neighbors.
Command Syntax
show bgp neighbors (A.B.C.D|X:X::X:X) routes
show bgp (ipv4|ipv6) (unicast|multicast|) neighbors (A.B.C.D|X:X::X:X) routes
show ip bgp neighbors (A.B.C.D|X:X::X:X) routes
show ip bgp ipv4 (unicast|multicast) neighbors (A.B.C.D|X:X::X:X) routes
Parameters
A.B.C.D
IPv4 address
X:X::X:X
IPv6 address
ipv4
IPv4 addresses
ipv6
IPv6 addresses
unicast
Unicast prefixes
multicast
Multicast prefixes
Command Mode
Privileged Exec mode and Exec mode
Example
The following output displays detailed information about the neighbor.
