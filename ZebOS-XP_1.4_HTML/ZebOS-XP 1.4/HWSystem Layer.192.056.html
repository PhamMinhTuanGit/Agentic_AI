hsl_ifmgr_lookup_by_name
This function finds an interface by name.
Note: The interface reference count must be decremented after calling this function.
Syntax
struct hsl_if *
hsl_ifmgr_lookup_by_name (char *name)
Input Parameters
name
Interface name
Output Parameters
None
Return Values
