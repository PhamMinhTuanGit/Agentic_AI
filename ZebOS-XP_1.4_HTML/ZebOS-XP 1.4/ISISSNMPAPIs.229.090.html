isis_set_circ_type
This call sets the type of the circuit. only broadcast and point-to-point type circuits are supported.
Syntax
int isis_set_circ_type (u_int32_t vr_id, u_int32_t instance, u_int32_t circindex, u_int32_t val);
Input Parameters
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
circindex
IS-IS circuit index.
val
Type of the specified circuit.
Output Parameters
None
Return Value
ISIS_API_SET_SUCCESS for set complete.
ISIS_API_SET_ERROR for supported circuit index not found in the specified instance.
