Multi-Protocol Label Switching Command Reference : CHAPTER 8 MPLS-TP OAM Commands : mpls-tp (1dm | 2dm)
  
mpls-tp (1dm | 2dm)
Use this command to start ITUT one-way or two-way delay measurement messages.
Command Syntax
mpls-tp (1dm | 2dm)(meg-name UMC mep-id <1-8191>) ({duration <5-60> | interval <1-4>| test <0-4294967295> | data <1-1400>}|)
Parameters
1dm
One-way delay measurement
2dm
Two-way delay measurement
UMC
Unique MEG code: 1-5 characters, excluding a forward slash (/).
<1-8191>
Maintenance Entity Group End Point (MEP) identifier
<5-60>
Duration of the session in seconds
<1-4>
Interval between delay measurement packets:
1
1 second
2
10 seconds
3
60 seconds
4
600 seconds
<0-4294967295>
 
Test identifier.
<1-1400>
Number of bytes to send.
Command Mode
Exec mode
Examples
#mpls-tp 1dm meg-name new mep-id 123 duration 5 interval 1 data 123 test 12345678
Initiating delay measurement on MEG: new, Duration 5 seconds
