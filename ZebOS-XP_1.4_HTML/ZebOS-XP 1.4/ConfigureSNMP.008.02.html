Obtain and Install SNMP
If you do not already have SNMP installed, follow these steps.
1. Download the SNMP software from www.net-snmp.org Web site.
2. Install and configure the software by following the instructions in the INSTALL file that comes with the software.
3. Proceed to one of the following sections to configure SNMP with either the SMUX or the AgentX protocol.
Note: You cannot configure SNMP with both SMUX and AgentX. One or the other must be used.
