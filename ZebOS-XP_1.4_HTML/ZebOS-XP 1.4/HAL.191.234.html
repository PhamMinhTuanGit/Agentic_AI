Platform Integration Developer Guide : CHAPTER 2 Hardware Abstraction Layer : MPLS API : hal_mpls_qos_release
  
hal_mpls_qos_release
This function releases MPLS QoS resources after tear down of the LSP.
Syntax
int
hal_mpls_qos_release (struct hal_mpls_qos *qos)
Input Parameters
qos
QoS-related parameter of the MPLS QoS resources.
Output Parameters
None
Return Value
HAL_MPLS_QOS_RELEASE_ERR when function fails
HAL_SUCCESS when function succeeds
