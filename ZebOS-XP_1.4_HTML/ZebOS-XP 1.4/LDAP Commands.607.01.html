CHAPTER 6 Lightweight Directory Access Protocol
This chapter describes Lightweight Directory Access Protocol (LDAP) commands.
LDAP is an protocol for accessing and maintaining distributed directory information services over an IP network. LDAP is specified is in RFC 4511.
For ZebOS-XP, LDAP is used for authentication.
This chapter contains these commands:
• clear ldap-server statistics
• debug ldap
• feature ldap
• ldap-server deadtime
• ldap-server host
• ldap-server port
• ldap-server timeout
• show debug ldap
• show ldap-server
• show running-config ldap
