Unicast Routing Information Base Command Reference : CHAPTER 2 Unicast RIB Commands : debug rib
  
debug rib
Use this command to debug the ribd process.
Use the no form of this command or the undebug command to stop debugging.
Note: High-availability and kernel events are not supported in ZebIC releases.
