Layer 2 Command Reference : CHAPTER 8 Multi-Chassis Link Aggregation Commands : portal-system-number
  
portal-system-number
Use this command to set the portal system number that uniquely identifies the system in the portal.
Command Syntax
portal-system-number <1-3>
Parameters
<1-3>
Portal system number
Command Mode
MLAG mode
Example
#config terminal
(config)#mlag configuration 1
(config-mlag)#portal-system-number 1
