Unicast Configuration Guide : CHAPTER 4 OSPF : Multiple OSPF Instances : Enable OSPF on an Interface
  
Enable OSPF on an Interface
R1 and R2 are two routers in Area 0 connecting to network 2.2.2.0/24.
R1
 
(config)#int eth1
Specify the interface on which OSPF is to be enabled.
(config-if)#no shutdown
Activate the interface.
(config-if)#exit
Exit interface mode.
(config)#router ospf 10
Configure an OSPF instance with an instance ID of 10.
(config-router)#router-id 5.5.5.5
Configure the router ID to use on this instance.
(config-router)#network 2.2.2.0/24 area 0
Advertise the network with the area ID.
R2
 
(config)#int eth1
Specify the interface on which OSPF is to be enabled.
(config-if)#no shutdown
Activate the interface.
(config-if)#exit
Exit interface mode.
(config)#router ospf 10
Configure an OSPF instance with an instance ID of 10.
(config-router)#router-id 6.6.6.6
Configure the router ID to use on this instance.
(config-router)#network 2.2.2.0/24 area 0
Advertise the network with the area ID.
