Protocol Independent Multicasting Command Reference : CHAPTER 2 PIMv4 Commands : ip pim bind ecmp-bundle
  
ip pim bind ecmp-bundle
Use this command to bind interfaces to an ECMP Bundles.
Use the no option with this command to unbind the interfaces from an ECMP Bundles.
Command Syntax
ip pim bind ecmp-bundle WORD
no ip pim bind ecmp-bundle WORD
Parameter
WORD
ECMP bundle name
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth1
(config-if)#ip pim bind ecmp-bundle ebund1
 
(config-if)#no ip pim bind ecmp-bundle ebund1
