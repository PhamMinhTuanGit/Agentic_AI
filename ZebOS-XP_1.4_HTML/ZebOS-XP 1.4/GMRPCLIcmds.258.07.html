Layer 2 Command Reference : CHAPTER 9 GMRP Commands : set gmrp fwdall
  
set gmrp fwdall
Use this command to set the GMRP forward all option for an interface.
Command Syntax
set gmrp fwdall disable IF_NAME
set gmrp fwdall enable IF_NAME
Parameters
disable
Disables GMRP on a switch.
enable
Enables GMRP on a switch.
IF_NAME
The identity of the interface
Default
If this command is not used, the default setting is GMRP disabled.
Command Mode
Configure mode
Example
To enable GMRP forwarding on a switch for a particular interface:
#configure terminal
(config)#set gmrp fwdall enable eth1
