RSVP-TE Command Reference : CHAPTER 8 Show Commands : show rsvp statistics
  
show rsvp statistics
Use this command to display the counts for various messages exchanged by the daemon. This displays the list of packet types, the number of sent packets and the number of received packets.
Command Syntax
show rsvp statistics
Parameters
None
Command Mode
Exec and Privileged Exec modes
Example
Following is a sample output from the command displaying the number of messages exchanged by the RSVP daemon.
#show rsvp statistics
PacketType Total
Sent Received
Path 185 0
PathErr 0 11
PathTear 39 0
Resv FF 0 88
Resv WF 0 0
Resv SE 0 0
Resv Err 0 0
ResvTear 0 0
ResvConf 0 0
Hello 0 0
#
