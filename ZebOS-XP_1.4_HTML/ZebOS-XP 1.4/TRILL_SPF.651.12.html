trill_echo_request_send
This function creates an echo request packet and gets the nexthop info to transmit the frame to the egress rbridge. It is contained in the file trill_oam.c:
Syntax
int
trill_echo_request_receive (struct cli *cli,struct trill *top,
u_int16_t egress_nickname, u_int16_t hop_count,
u_int8_t flag, u_int16_t count)
Input Parameters
*cli
Specifies the instance of the CLI structure.
*top
Specifies the pointer to the TRILL instance.
egress_nickname
Egress nickname to which ping echo request to be sent.
hop_count
Hop count to be set for the request frame.
flag
Flag to indicate whether request is send for ping or traceroute.
count
Number of echo request frame to be sent at a time.
Output Parameters
None
Return Values
TRILL_CHANNEL_RESULT_OK
TRILL_CHANNEL_FAIL
