Carrier Ethernet Command Reference : CHAPTER 9 Provider Backbone Bridging Commands : bridge-group vlan
  
bridge-group vlan
Use this command to set an interface as a rapid per-VLAN spanning tree instance.
Use the no form of this command to remove the interface from this instance.
Command Syntax
bridge-group <1-32> vlan <2-4094>
no bridge-group <1-32> vlan <2-4094>
Parameters
bridge-group
Specify the bridge group.
<1-32>
Specify the bridge group ID.
vlan
Specify the VLAN.
<2-4094>
Set the VLAN identifier
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth0
(config-if)#bridge-group 1 vlan 55
 
(config)#interface eth0
(config-if)#no bridge-group 1 vlan 55
