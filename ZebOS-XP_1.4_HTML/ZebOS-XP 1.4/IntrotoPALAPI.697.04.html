ipi_vr_add_callback
This function sets the callbacks to virtual router based on the vr_callback_type. The vr_callback_type are defined in /lib/lib.h.
Syntax
void
ipi_vr_add_callback (struct lib_globals *zg, enum vr_callback_type type,
int (*func) (struct ipi_vr *))
Input Parameters
zg
library global structure
type
VR API callback types:
VR_CALLBACK_ADD
Sets the VR add callback function
VR_CALLBACK_DELETE
 
 
 
 
 
 
 
 
Sets the VR delete callback function
VR_CALLBACK_CLOSE
 
Sets the VR close callback function
VR_CALLBACK_UNBIND
 
Sets the VR unbind callback function
VR_CALLBACK_CONFIG_READ
 
Sets the configuration read callback function
VR_CALLBACK_ADD_UNCHG
 
 
Sets the add unchanged callback function
VR_CALLBACK_MAX
 
Represents the MAX value
function pointer
 
Pointer to a function to call when one of the events that corresponds to a vr_callback_type takes place
Output Parameters
None
Return Value
RESULT_OK when the function succeeds
