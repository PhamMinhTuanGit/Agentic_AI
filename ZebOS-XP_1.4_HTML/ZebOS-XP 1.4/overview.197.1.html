Hybrid Switch Router Configuration Guide : CHAPTER 1 Overview
  
CHAPTER 1 Overview
A ZebOS-XP Hybrid Switch Router offers Layer 3 forwarding found in routers with the high-speed performance associated with traditional Layer 2 switches. The following are some advantages of Hybrid Switch Routers:
• Reduced system cost and infrastructure. Traditionally you would require a separate box for switching and a separate box for routing.
• Off-loading IP traffic from backbone routers thus making them more efficient for firewalls and WAN connectivity.
• Simplified network design and maintenance.
