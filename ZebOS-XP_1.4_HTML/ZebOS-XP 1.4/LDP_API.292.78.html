Label Distribution Protocol Developer Guide : CHAPTER 9 LDP API : ldp_api_clear_advert_list
  
ldp_api_clear_advert_list
This call clears the advertise list.
Syntax
int
ldp_api_clear_advert_list (struct cli *cli,
struct ldp_adv_list_master *master,
char *prefix_acl, char *peer_acl)
Input Parameters
cli
Pointer to the CLI structure
master
Master data structure
prefix_acl
Prefix access control list name
peer_acl
Peer access control list name
Output Parameters
None
Return Values
CLI_SUCCESS if clear was successful
CLI_ERROR if clear was not successful
