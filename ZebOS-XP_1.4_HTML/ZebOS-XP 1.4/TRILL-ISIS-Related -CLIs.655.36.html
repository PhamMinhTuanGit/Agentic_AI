trill_port_vlan_delete_event
This function removes the specified VLAN from a port.
Syntax
s_int32_t
trill_port_vlan_delete_event (u_int32_t vr_id, char *name, u_int32_t ifindex,
u_int32_t vid)
Input Parameters
vr_id
Specifies the identification of the virtual router.
*name
Specifies the name of the bridge.
ifindex
Specifies the interface index.
vid
Specifies the VLAN identification.
Output Parameters
None
Return Values
RESULT_ERROR: Indicates an error occurred; operation not performed.
