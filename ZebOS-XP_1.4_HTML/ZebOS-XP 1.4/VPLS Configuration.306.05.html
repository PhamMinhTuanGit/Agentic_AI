PE4 - RSVP-TE
Note: For a DiffServ-enabled build, DiffServ configuration is required.
 
(config)#router rsvp
Enter Router mode.
(config-router)#exit
Exit Router mode.
(config)#interface eth1
Enter interface mode.
(config-if)#enable-rsvp
Enable RSVP-TE on the specified interface (eth1).
(config-if)#exit
Exit interface mode.
(config)#interface eth2
Enter interface mode.
(config-if)#enable-rsvp
Enable RSVP-TE on the specified interface (eth2).
(config-if)#exit
Exit interface mode.
