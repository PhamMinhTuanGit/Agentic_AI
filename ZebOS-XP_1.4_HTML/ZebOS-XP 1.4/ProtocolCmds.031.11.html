Bidirectional Forwarding Detection Command Reference : CHAPTER 3 Protocol Commands for BFD : neighbor fall-over bfd (RIP)
  
neighbor fall-over bfd (RIP)
Use this command to enable the BFD option on an IPv4 RIP peer.
Use the no form of the command to disable the BFD option on an IPv4 RIP peer.
Command Syntax
neighbor A.B.C.D fall-over bfd
no neighbor A.B.C.D fall-over bfd
Parameters
A.B.C.D
Peer address in an IPv4 format
Command Mode
Router mode
Example
(config)#router rip
(config-router)#neighbor 10.10.2.9 fall-over bfd
