hal_ipv6_mc_get_sg_count
This function gets the various counters per (S, G) entry.
Syntax
int
hal_ipv6_mc_get_sg_count (struct hal_in6_addr *source,
struct hal_in6_addr *group,
u_int32_t iif_vif,
u_int32_t *pktcnt,
u_int32_t *bytecnt,
u_int32_t *wrong_vif)
Input Parameters
source
Source address
group
Group address
iif_vif
Incoming VIF
pktcnt
Packet count
bytecnt
Byte count
wrong_vif
Wrong VIFs
Output Parameters
None
Return Value
< 0 when function fails
HAL_SUCCESS when function succeeds
