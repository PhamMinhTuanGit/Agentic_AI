System Management Command Reference : CHAPTER 4 Dynamic Host Configuration Protocol Relay : ip dhcp relay information option
  
ip dhcp relay information option
Use this command to enable the device to insert and remove option-82 information on DHCP packets forwarded by the relay agent.
Use the no form of this command to disable inserting and removing option-82 information.
Command Syntax
ip dhcp relay information option
no ip dhcp relay information option
Parameters
None
Command Mode
Configure mode
Examples
#configure terminal
(config)#ip dhcp relay information option
 
#configure terminal
(config)#no ip dhcp relay information option
