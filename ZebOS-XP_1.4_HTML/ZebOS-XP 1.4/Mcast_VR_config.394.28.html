Multicast Configuration Guide : CHAPTER 4 Multicast Virtual Routing Configuration : Enable PIM-SMv6 on a VR : Configure RP on VR2
  
Configure RP on VR2
 
#login virtual-router VR2
From Global Configuration mode, run this command to jump to Configure mode on VR2.
#configure terminal
Enter Configure mode.
(config)#ipv6 pim rp-address 3ffe:10:10:11::11
Configure the RP address.
(config)#end
Exit the Configure mode.
