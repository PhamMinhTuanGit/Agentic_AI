show mpls-tp rps protection-group summary
Use this command to display summary information about all the configured MPLS-TP RPS protection groups.
Command Syntax
show mpls-tp rps protection-group summary
Parameters
None
Command Mode
Exec mode
Examples
#show mpls-tp rps protection-group summary
