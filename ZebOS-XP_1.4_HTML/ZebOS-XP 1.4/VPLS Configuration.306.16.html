Set Up LSPs
PE4
 
#configure terminal
Enter Configure mode.
(config)#rsvp-trunk T41
Create RSVP trunk T41 and enter Trunk mode.
(config-trunk)#to 192.168.0.1
Specify the IPv4 egress (destination point) for the LSP.
(config-trunk)#exit
Exit Trunk mode.
(config)#rsvp-trunk T42
Create RSVP trunk T42, and enter Trunk mode.
(config-trunk)#to 192.168.0.2
