Delete VLAN Interfaces
Use the vconfig utility to delete VLAN interfaces.
To remove the eth1.10 interface on R1:
[root]#vconfig rem eth1.10
Removed VLAN -:eth1.10:-
Now, if you use the ifconfig command to try to display information about the eth1.10 interface:
[root]#ifconfig eth1.10
eth1.10: error fetching interface information: Device not found
This shows that VLAN interfaces were successfully removed.
Using ZebOS-XP commands, when you try to configure this interface, a message is displayed, showing that the interface does not exist:
#configure terminal
Enter configuration commands, one per line. End with CNTL/Z.
(config)#interface eth1.10
% No such interface
