System Management Command Reference : CHAPTER 10 Secure Shell : ssh key
  
ssh key
Use this command to create a SSH server key.
Use the no form of this command remove a SSH server key. The no ssh key form (with no other parameters) deletes both RSA and DSA keys.
You can only give this command when the SSH server is disabled. See the feature ssh command.
Command Syntax
ssh key (rsa)
ssh key (rsa) length <768-2048>
ssh key (rsa) length <768-2048> (force)
ssh key (rsa) (force)
ssh key (dsa)
ssh key (dsa) (force)
no ssh key
no ssh key (dsa)
no ssh key (rsa)
Parameters
dsa
Digital System Algorithm (DSA) SSH key
rsa
Rivest, Shamir, and Adelman (RSA) public-key cryptography SSH server key
force
Forces the replacement of an SSH key
length
Number of bits to use when creating the SSH server key; this parameter is only valid for RSA keys (DSA keys have a default length of 1024)
<768-2048>
Range of number of bits
Command Mode
Configure mode
Examples
#configure terminal
(config)#ssh key dsa
