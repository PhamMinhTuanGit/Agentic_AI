lldp tlv-select ieee-8023-org-specific
Use this command to select the set of ieee-8023-org-specific TLV to be included in the LLDP frames.
Use the no parameter to disable the selected ieee-8023-org-specific TLV.
Command Syntax
lldp tlv-select ieee-8023-org-specific {mac-phy| power-via-mdi | link-agg| max-mtu- size}
no lldp tlv-select ieee-8023-org-specific {mac-phy| power-via-mdi | link-agg| max- mtu-size}
Parameters
mac-phy
VLAN ID Of the provider edge port <2-4094>.
power-via-mdi
Power-via-MDI (only when PoE feature is available)
link-agg
link-aggregation VLAN
max-mtu-size
max-mtu-size TLV
Default Value
None
Command Mode
LLDP Agent mode
Examples
#configure terminal
(config)#interface eth0
(config-if)lldp-agent
(lldp-agent)#lldp tlv-select ieee-8023-org-specific mac-phy
(lldp-agent)#exit
