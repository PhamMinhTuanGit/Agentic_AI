Carrier Ethernet Command Reference : CHAPTER 5 Link Layer Discovery Protocol v2 Commands : clear lldp counters
  
clear lldp counters
Use this command to clear the LLDP statistics on all the interfaces.
Command Syntax
clear lldp counters
Parameters
counters
Reset the LLDP traffic counters to zero.
Command Mode
Exec Mode
Examples
#clear lldp counters
