nsm_all_vlan_show
This function shows the VLAN characteristics for VLANs on a bridge.
Syntax
void
nsm_all_vlan_show (struct cli *cli, char *brname,
int type, nsm_vid_t vid)
Input Parameters
cli
CLI pointer.
brname
Bridge name.
type
Type of VLANs.
vid
VLAN ID to be configured.
Output Parameters
None
Return Values
None
