Network Services Module Command Reference : CHAPTER 5 Interface Commands : ipv6 neighbor
  
ipv6 neighbor
Use this command to add an IPv6 neighbor entry.
Use the no form of this command to an IPv6 neighbor entry.
Command Syntax
ipv6 neighbor X:X::X:X IFNAME MAC
no ipv6 neighbor X:X::X:X IFNAME
Parameters
X:X::X:X
Specify the neighbor’s IPv6 address.
IFNAME
Specify the name of the interface.
MAC
Specify the MAC hardware address <HHHH.HHHH.HHHH>.
Command Mode
Configure mode
Examples
#configure terminal
(config)#ipv6 neighbor 2000::3 eth1 0010.1842.3dc1
(config)#no ipv6 neighbor 2000::3 eth1
