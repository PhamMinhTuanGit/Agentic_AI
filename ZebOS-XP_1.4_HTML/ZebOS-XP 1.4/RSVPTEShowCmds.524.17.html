RSVP-TE Command Reference : CHAPTER 8 Show Commands : show rsvp path
  
show rsvp path
Use this command to display the configured rsvp paths and their configured hops. Specify the pathname to show hops related to a specific path. If no pathname is specified all the rsvp paths are displayed.
Command Syntax
show rsvp path
show rsvp path PATHNAME
Parameter
PATHNAME
The name of a specific path.
Command Mode
Exec mode and Privileged Exec mode
Example
Following are sample outputs from this command, with and without a PATHNAME (PRI) specified.
#show rsvp path
Path name: PRI, id: 1
10.10.11.51 strict
10.10.12.50 strict
10.10.13.51 strict
 
Path name: SEC, id: 2
10.10.10.51 strict
 
Path name: loop, id: 3
10.10.11.51 strict
10.10.12.50 strict
10.10.13.51 strict
10.10.14.50 strict
#
 
#show rsvp path PRI
Path name: PRI, id: 1
10.10.11.51 strict
10.10.12.50 strict
10.10.13.51 strict
#
