trill disable-port
Use this command to designate a port as disabled for an interface.
Use the no parameter with this command to reset the configuration to the default value.
Command Syntax
trill disable-port enable
no trill disable-port
Parameters
enable
Specify a port as disabled.
Command Mode
Interface mode
Default
Port is enabled by default.
Examples
>enable
#configure terminal
(config)#interface eth1
(config-if)#trill designated-vlan 101
(config-if)#trill designated-vlan
