Multicast Routing Information Base Command Reference : CHAPTER 3 L3 IGMP Multicast Commands : ip igmp offlink
  
ip igmp offlink
Use this command to configure off-link for IGMP.
Use the no parameter with this command to remove this configuration.
Command Syntax
ip igmp offlink
no ip igmp offlink
Parameter
None
Command Mode
Interface mode
Example
#configure terminal
(config)#interface eth1
(config-if)#ip igmp offlink
 
(config-if)#no ip igmp offlink
