Carrier Ethernet Command Reference : CHAPTER 12 PBB-TE CFM Commands : show ethernet cfm pbb-te errors
  
show ethernet cfm pbb-te errors
Use this command to display errors in the PBB-TE domain for a backbone bridge.
Command Syntax
show ethernet cfm pbb-te errors domain-name DOMAIN_NAME bridge backbone
Parameters
domain-name
The name of the maintenance domain.
DOMAIN_NAME
The name of the maintenance domain.
Command Mode
Exec mode
Examples
#show ethernet cfm pbb-te errors domain-name ipi bridge backbone
