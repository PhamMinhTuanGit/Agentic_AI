trill_get_rbridge_dtree_priority
This call gets the distribution tree root priority for this Rbridge.
Syntax
int
trill_get_rbridge_dtree_priority (u_int32_t vr_id, u_int32_t instance,
u_int32_t *ret)
Input Parameters
vr_id
An integer that contains the TRILL VR identifier.
instance
An integer that contains the TRILL instance ID.
Output Parameters
ret
Pointer to the distribution tree root priority.
Return Value
TRILL_API_SET_SUCCESS for valid Instance ID.
TRILL_API_GET_ERROR for valid Instance ID not found.
