Ethernet Local Management Interface Command Reference : CHAPTER 2 ELMI Commands : ethernet lmi n391
  
ethernet lmi n391
Use this command to configure a status counter at the UNI-C.
Use the no parameter to set the value to its default values.
Note: A polling counter is applicable only for UNI-C, even though it is visible at UNI-N.
Command Syntax
ethernet lmi n391 <1-65000>
no ethernet lmi n391
Parameters
<1-65000>
This parameter configures a polling counter at the UNI-C.
Command Mode
Interface mode
Default
Default is 360.
Examples
#configure terminal
(config)#interface eth1
(config-if)#ethernet lmi n391 12345
