Layer 2 Command Reference : CHAPTER 5 RPVST+ Commands : show spanning-tree interface
  
show spanning-tree interface
Use this command to display spanning-tree information for an interface.
Command Syntax
show spanning-tree interface IFNAME
Parameter
IFNAME
Displays the interface name.
Command Mode
Exec mode and Privileged Exec mode
Example
