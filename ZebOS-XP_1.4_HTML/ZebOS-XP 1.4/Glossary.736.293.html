Glossary : Terms : packet
  
packet
A protocol data unit (PDU) at Layer 3 (L3) of the Open Systems Interconnection (OSI) Reference Model. A packet contains source and destination addresses, user data, and control information such as the length of the packet, the header checksum, and flags indicating whether the packet has been fragmented. The user data in a packet is often referred to as the payload. The actual format of a packet depends on the protocol that creates the packet.
A packet sent through a connectionless protocol such as User Datagram Protocol (UDP) is sometimes called a datagram.
See also frame, packet switching.
