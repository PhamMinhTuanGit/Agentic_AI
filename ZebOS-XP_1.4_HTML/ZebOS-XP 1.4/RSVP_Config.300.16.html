Fast Reroute Configuration
The Fast Reroute (FRR) configuration is a MPLS resiliency technology that provides fast traffic recovery when there is a link or router failure on mission critical services. Whenever a link or node fails, FRR is able to recover impacted traffic flows in the level of 50 milliseconds.
