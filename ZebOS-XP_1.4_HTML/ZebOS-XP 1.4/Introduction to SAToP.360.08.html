nsm_if_mpls_l2_circuit_bind
Use this function to add or delete a new NSM interface type and create a mapping between PWs and TDM interfaces.
Syntax
int
nsm_if_mpls_l2_circuit_bind (struct cli *cli, char *vc_name, char *vc_type,
u_int16_t vlan_id, u_char vc_mode)
Input Parameters
*cli
Specifies the instance of the CLI structure.
*vc_name
Port used for a VC name
*vc_type
Port used for a VC type
vlan_id
VLAN ID
vc_mode
Port used for a VC mode
Output Parameters
None
Return Values
NSM_SUCCESS
NSM_FAILURE
