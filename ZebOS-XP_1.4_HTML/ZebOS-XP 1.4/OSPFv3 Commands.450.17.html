Open Shortest Path First Command Reference : CHAPTER 3 OSPFv3 Commands : debug ipv6 ospf lfa
  
debug ipv6 ospf lfa
Use this command to specify the debugging options for OSPFv3 Loop-free Alternate path
Use the no parameter with this command to disable this function.
Command Syntax
debug ipv6 ospf lfa
no debug ipv6 ospf lfa
Parameters
None
Command Mode
Privileged Exec mode and Configure mode
Examples
#debug ipv6 ospf lfa
