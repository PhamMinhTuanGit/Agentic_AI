Label Distribution Protocol Developer Guide : CHAPTER 11 LDP MIBs API : ldp_snmp_api_get_peer_trans_addr
  
ldp_snmp_api_get_peer_trans_addr
This call gets the peer transport address.
Syntax
int
ldp_snmp_api_get_peer_trans_addr (struct ldp *ldp,
struct ldp_entity *entity,
struct ldp_id *peer_id,
struct pal_in4_addr *addr)
Input Parameters
ldp
LDP instance
entity
LDP entity ID
peer_id
LDP peer ID
Output Parameters
addr
Transport address of the peer
Return Values
LDP_SUCCESS
LDP_FALSE
