Network Services Module Command Reference : CHAPTER 2 Common Exec Mode Commands : terminal length
  
terminal length
Use the terminal length command to set number of lines displayed on a terminal.
Command Syntax
terminal length <0-511>
Parameters
<0-511>
The number of lines on a terminal. The default length is 25 lines.
Command Mode
Exec mode and Privileged Exec mode
Examples
The following example sets the terminal length to 30 lines.
#terminal length 30
