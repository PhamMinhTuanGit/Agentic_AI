Multi-Protocol Label Switching Command Reference : CHAPTER 9 MPLS-TP LPS Commands : show mpls-tp lps protection-group summary
  
show mpls-tp lps protection-group summary
Use this command to display summary information about an MPLS-TP protection group.
Command Syntax
show mpls-tp lps protection-group summary
Parameters
None
Command Mode
Exec mode
Examples
#show mpls-tp lps protection-group summary
Total Number of PS groups configured : 2
