mstp_nsm_recv_vlan_port_type
This function processes the change of port type message from NSM. If it is a customer edge port, it creates a spanning tree domain for the customer edge port.
Syntax
static int
mstp_nsm_recv_vlan_port_type (struct nsm_msg_header *header,
void *arg, void *message);
Input Parameters
header
The message header.
arg
The argument for the message.
message
The message to be handled.
Output Parameters
None
Return Values
RESULT_OK always
