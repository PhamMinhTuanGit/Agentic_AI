Layer 2 Command Reference : CHAPTER 10 GVRP Commands : set gvrp enable
  
set gvrp enable
Use this command to enable GVRP globally on a switch for a default bridge instance. This command does not enable GVRP for all ports of the bridge. After enabling GVRP globally, use the set port gvrp command to enable GVRP on individual ports of the bridge (see set port gvrp).
Command Syntax
set gvrp enable bridge BRIDGE_NAME
Parameters
BRIDGE_NAME
Bridge identifier.
Command Mode
Configure mode
Examples
#configure terminal
(config)#set gvrp enable bridge 12
