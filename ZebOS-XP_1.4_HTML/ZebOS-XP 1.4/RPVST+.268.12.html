rpvst_plus_api_set_msti_port_path_cost
This function sets the priority level of a port on a VLAN.
Syntax
int
rpvst_plus_api_set_msti_port_path_cost (char *br_name,
char *ifname, int vid,
u_int32_t path_cost)
Input Parameters
br_name
Name of the bridge.
ifname
The interface name.
vid
VLAN ID to be configured. Must be between 2 and 4094.
path_cost
Path cost. Must be between MSTP_MIN_PATH_COST and MSTP_MAX_PATH_COST.
Output Parameters
None
Return Values
RESULT_OK when function succeeds.
RESULT_ERROR when function fails.
