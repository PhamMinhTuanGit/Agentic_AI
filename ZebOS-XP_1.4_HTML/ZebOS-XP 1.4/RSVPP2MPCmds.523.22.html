RSVP-TE Command Reference : CHAPTER 7 Point-to-Multipoint Commands : traffic
  
traffic
Use this command to set the traffic type for a P2MP LSP.
Use the no parameter with this command to remove a configured traffic type.
Command Syntax
traffic (guaranteed|controlled-load)
no traffic
Parameters
guaranteed
Set traffic type to guaranteed
controlled-load
 
Set traffic type to controlled-load
Command Mode
P2MP LSP mode
Examples
(config-p2mp-lsp)#traffic controlled-load
 
(config-p2mp-lsp)#traffic guaranteed
 
(config-p2mp-lsp)#no traffic
(config-p2mp-lsp)#
