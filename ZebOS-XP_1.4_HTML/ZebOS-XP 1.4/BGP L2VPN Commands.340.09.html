Multi-Protocol Label Switching Command Reference : CHAPTER 6 Unified L2VPN commands : route-target
  
route-target
Use this command to configure route target for MPLS layer 2 virtual circuit/VPLS instance.
Command Syntax
route-target ASN:nn_or_IP-address:nn
Parameters
ASN:nn_or_IP-address:nn
 
Specify route-target value
Command Mode
VPWS mode and VPLS mode
Example
(config)#l2vpn-vpws vpws1
(config-vpws)#protocol ldp
(config-vpws)#vc-id 10
(config-vpws)#route-target 100:20
 
(config)#l2vpn-vpls vpls1
(config-vpls)#vpn-id 2
(config-vpls)#protocol ldp autodiscovery-bgp
(config-vpls)#route-target 100:20
