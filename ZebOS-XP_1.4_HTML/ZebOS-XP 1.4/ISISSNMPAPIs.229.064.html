isis_get_sys_level_min_lsp_gen_interval
This call gets the minimum interval, in seconds, between successive generation of LSPs with the same LSP ID by the instance of the IS-IS protocol at this level.
Syntax
int isis_get_sys_min_level_lsp_gen_interval (u_int32_t vr_id, u_int32_t instance, u_int32_t level, u_int32_t *ret);
Input Parameters
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
level
IS-IS level index.
Output Parameters
ret
Minimum interval, in seconds, between successive generation of LSPs.
Return Values
ISIS_API_GET_SUCCESS for the specified level found.
ISIS_API_GET_ERROR for the level not found.
