DHCP Client Configuration for IPv4
Before Configuring DHCP in client (DUT), make sure that DHCP server is ready and also dhcpd is running on the server machine.
.
Figure 7-1: DHCP Client Configuration
DUT
 
#configure terminal
Enter Configure mode.
(config)#feature dhcp
Enable the feature dhcp. This will be enabled by default.
(config)#interface xe1
Specify the interface(xe1) to be configured and enter the interface mode.
(config-if)#ip address dhcp
The client requests for the IP address to the server, once it receives the Acknowledgement from the server, it assigns the IP address to the interface in which this command is enabled.
(config if)#exit
Exit from the interface mode.
Validation Commands
show running-config dhcp, show ip interface brief
