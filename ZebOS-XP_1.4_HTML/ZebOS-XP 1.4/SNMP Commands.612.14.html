System Management Command Reference : CHAPTER 11 Simple Network Management Protocol : snmp-server contact
  
snmp-server contact
Use this command to set the system contact information for the device (sysContact object).
Use the no form of this command to remove the system contact information.
Command Syntax
snmp-server contact (|TEXT)
no snmp-server contact (|TEXT)
Parameters
TEXT
System contact information; maximum length 32 characters without spaces
Command Mode
Configure mode
Examples
#configure terminal
(config)#snmp-server contact Irving@555-0150
