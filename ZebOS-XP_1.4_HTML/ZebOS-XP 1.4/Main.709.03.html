Interface Tracking
The VRRP Interface Tracking feature allows tracking the interface state that can alter the priority level of a virtual router for a VRRP group. For example, an interface can be tracked and if it goes down, then the priority of the VRRP group can be lowered, which may allow another VRRP router to become the new group master virtual router. ZebOS-XP allows tracking of only one interface per VRRP group.
