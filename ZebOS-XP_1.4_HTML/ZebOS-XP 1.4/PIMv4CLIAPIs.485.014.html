msdp_api_sa_cache_clear
This function clears Multicast Source Discovery Protocol (MSDP) Source-Active (SA) cache entries.
The clear ip msdp sa-cache command calls this function.
Syntax
int
msdp_api_sa_cache_clear (u_int32_t vr_id, char *vrf_name,
bool_t grp_addr_provided, struct pal_in4_addr grp_addr)
Input Parameters
vr_id
Virtual router ID
vrf_name
VPN routing/forwarding name
grp_addr_provided
 
Specify PAL_TRUE if a group address is specified in grp_addr or PAL_FALSE to clear all SA cache entries
grp_addr
Multicast group address
Output Parameters
None
Return Values
MSDP_API_SET_SUCCESS when the function succeeds
MSDP_API_SET_ERR_VR_DOESNT_EXIST when vr_id does not exist
MSDP_API_SET_ERR_WRONG_VRF when the vrf_name does not exist
