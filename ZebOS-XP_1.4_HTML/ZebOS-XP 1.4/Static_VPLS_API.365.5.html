nsm_vpls_mesh_peer_ipv4_add_cli
This call is used to add a VPLS mesh peer.
Syntax
nsm_vpls_mesh_peer_ipv4_add_cli(u_int32_t vr_id,
u_int32_t vpls_id, char *sz_peer,
u_char mapping_type,
char *tunnel_info, u_int8_t fec_type_vc,
char *sz_mode, char *sec_peer)
Input Parameters
vr_id
VR identifier
vpls_id_str
VPLS identifier
sz_peer
Peer address
mapping_type
Mapping type
tunnel_info
Tunnel name and tunnel ID information
fec_type_vc
Identify VC type
sz_mode
Specify mode
sec_peer
Secondary peer address
Output Parameter
None
