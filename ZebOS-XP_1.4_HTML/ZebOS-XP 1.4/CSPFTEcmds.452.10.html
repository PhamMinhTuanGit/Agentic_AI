Open Shortest Path First Command Reference : CHAPTER 5 CSPF-TE Commands : show ip ospf te-database
  
show ip ospf te-database
Use this command to display traffic engineering (TE) information in OSPFv2.
Command Syntax
show ip ospf (<0-65535>|) te-database
Parameter
<0-65535>
Display the process ID number.
Command Mode
Exec and Privileged Exec modes
Example
