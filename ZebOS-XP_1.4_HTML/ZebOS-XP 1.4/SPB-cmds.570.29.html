isis-spb retransmit-interval
Use this command to set the LSP retransmission interval.
Use the no form of this command to set the interval to its default (5 seconds).
Command Syntax
isis-spb retransmit-interval <0-65535>
no isis-spb retransmit-interval
Parameters
<0-65535>
Specify the retransmission interval in seconds.
Default
By default, ZebOS-XP uses an interval of 5 seconds.
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth0
(config-if)#isis-spb retransmit-interval 10
 
(config-if)#no isis-spb retransmit-interval
