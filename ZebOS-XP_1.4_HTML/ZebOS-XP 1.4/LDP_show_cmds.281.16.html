Label Distribution Protocol Command Reference : CHAPTER 3 LDP Show Commands : show ldp statistics
  
show ldp statistics
Use this command to display LDP statistics.
Command Syntax
show ldp statistics
Parameter
None
Command Mode
Exec mode and Privileged Exec mode
Example
The following is a sample output from the show ldp statistics command.
