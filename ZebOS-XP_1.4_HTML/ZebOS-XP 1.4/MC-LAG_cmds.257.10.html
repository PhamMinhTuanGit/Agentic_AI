Layer 2 Command Reference : CHAPTER 8 Multi-Chassis Link Aggregation Commands : portal-address
  
portal-address
Use this command to set the MAC address of the portal system.
Command Syntax
portal-address MAC
Parameters
MAC
MAC address in HHHH.HHHH.HHHH format; the values 0000.0000.0000 and FFFF.FFFF.FFFF are not valid
Command Mode
MLAG mode
Example
#config terminal
(config)#mlag configuration 1
(config-mlag)#portal-address 5254.0059.424f
