debug trill nsm
Use this command to enable debugging for the TRILL network services module (NSM).
Use the no parameter with this command to disable this function.
Command Syntax
debug trill nsm
no debug trill nsm
undebug trill nsm
Parameters
None
Command Mode
Exec mode and Privilege Exec mode
Examples
#debug trill nsm
 
#no debug trill nsm
