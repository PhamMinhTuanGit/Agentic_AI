show ip rip vrf
Use this command to display VRF information. This command is supported in RIP and RIPng (IPv4 and IPv6).
Command Syntax
show ip rip (database) vrf WORD
Parameters
database
Specify to display information about the IP RIP database.
WORD
Specify the name for the VRF instance.
Command Mode
Privileged Exec mode and Exec mode
Examples
#show ip rip database vrf IPI
Codes: R - RIP, Rc - RIP connected, Rs - RIP static, K - Kernel,
C - Connected, S - Static, O - OSPF, I - IS-IS, B - BGP
