bfd_notify_event
The bfd_notify_event enumeration defines all the BFD notification events.

Description

BFD_NOTIFY_LINK_NEW

BFD_NOTIFY_LINK_UP
When a link is up
BFD_NOTIFY_LINK_DOWN
When a link is down
BFD_NOTIFY_ADDRESS_NEW

BFD_NOTIFY_MAX
Maximum
