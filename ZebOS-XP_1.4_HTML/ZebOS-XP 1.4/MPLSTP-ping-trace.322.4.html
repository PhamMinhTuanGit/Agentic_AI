PE2 (OAM) - Ping to Ingress Node
 
#ping mpls-tp meg-name meg-1 me-name me-1 detail
Initiate the LSP-Ping from PE2 to PE1 with meg-1 and me-1.
PE2#ping mpls-tp meg-name meg-1 me-name me-1 detail
Sending 5 MPLS Echos to MEG: meg-1 and ME: me-1, timeout is 5 seconds
 
Codes:
'!' - Success, 'Q' - request not sent, '.' - timeout,
'x' - Retcode 0, 'M' - Malformed Request, 'm' - Errored TLV,
'N' - LBL Mapping Err, 'D' - DS Mismatch,
'U' - Unknown Interface, 'R' - Transit (LBL Switched),
'B' - IP Forwarded, 'F' No FEC Found, 'f' - FEC Mismatch,
'P' - Protocol Error, 'X' - Unknown code,
'Z' - Reverse FEC Validation Failed
 
Type 'Ctrl+C' to abort
