isis_get_sys_exist_state
This call gets the state of the IS-IS router of this instance.
Syntax
int
isis_get_sys_exist_state (u_int32_t vr_id, u_int32_t instance, u_int32_t *ret);
Input Parameters
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
Output Parameters
ret
State of the IS-IS router:
1
Active
2
Not in service
3
Not ready
4
Create and go
5
Create and wait
6
Destroy
Return Values
ISIS_API_GET_SUCCESS for instance found.
ISIS_API_GET_ERROR for instance not found.
