nsm_mpls_set_ftn_protocol
This function sets the IP protocol to match against the IPv4 protocol number in the packet.
Syntax
u_int32_t
nsm_mpls_set_ftn_protocol (struct nsm_master *nm,
u_int32_t ftn_ix, u_int32_t protocol)
Input Parameters
nm
NSM master
ftn_ix
Index to a conceptual row in the FTN table
protocol
IP protocol to match against the IPv4 protocol number in the packet; the only permitted value is match all (255)
Output Parameters
None
Return Values
NSM_API_SET_SUCCESS when the function succeeds
NSM_API_SET_ERROR when the function fails
