Layer 2 Developer Guide : CHAPTER 8 VLAN Registration Protocol : API : gvrp_disable_port
  
gvrp_disable_port
This function disables GVRP on a port.
Syntax
int
gvrp_disable_port (struct nsm_bridge_master *master,
struct interface *ifp)
Input Parameters
master
Pointer to the NSM master.
ifp
Interface pointer.
Output Parameters
None
Return Values
CLI_SUCCESS when function succeeds.
CLI_ERROR when function fails.
