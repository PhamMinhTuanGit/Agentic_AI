Network Services Module Command Reference : CHAPTER 6 Traffic Engineering Commands : remote-link-id
  
remote-link-id
Use this command to configure remote link id for each TE link.
Use the no option with this command to remove the remote link ID from a TE link.
Command Syntax
remote-link-id A.B.C.D
no remote-link-id (A.B.C.D|)
Parameters
A.B.C.D
Remote link ID in IPv4 address format.
Command Mode
TE Link mode
Examples
#configure terminal
(config)#te-link te1 local-link-id 172.1.1.1
(config-te)#remote-link-id 172.1.2.3
