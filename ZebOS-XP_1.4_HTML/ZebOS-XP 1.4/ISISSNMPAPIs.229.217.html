isis_get_is_adj_extended_circ_id
This call gets the four byte extended circuit ID learned from the Neighbor during 3-way handshake, or 0.
Syntax
int
isis_get_is_adj_extended_circ_id (u_int32_t vr_id, u_int32_t instance,
u_int32_t circindex, u_int32_t adjindex,
u_int32_t *ret);
Input Parameter
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
circindex
IS-IS circuit index.
adjindex
IS-IS adjacent index.
Output Parameters
ret
Four-byte extended circuit ID learned from the neighbor during 3-way handshake or 0. Output is always 0.
Return Value
ISIS_API_GET_SUCCESS for the adjacent index found in the specified circuit.
ISIS_API_GET_ERROR for the adjacent index not found in the specified circuit.
