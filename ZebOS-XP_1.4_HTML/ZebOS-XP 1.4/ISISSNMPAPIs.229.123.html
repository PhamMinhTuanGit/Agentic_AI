isis_get_circ_level_wide_metric
This call gets the wide metric value of this circuit for this level.
Syntax
int isis_get_circ_level_wide_metric (u_int32_t vr_id, u_int32_t instance, u_int32_t circindex, u_int32_t level, u_int32_t *ret);
Input Parameters
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
circindex
IS-IS circuit index.
level
IS-IS level index, that is, 1 for level 1 IS or 2 for level 2 IS.
Output Parameters
ret
Wide metric for IS neighbors which pick between 0 to 1,677,215.
Return Values
ISIS_API_GET_SUCCESS for supported IS level index found in the specified circuit index.
ISIS_API_GET_ERROR for supported IS level index not found in the specified circuit index.
