Label Distribution Protocol Developer Guide : CHAPTER 9 LDP API : ldp_api_session_restart
  
ldp_api_session_restart
This call restarts the LDP session.
Syntax
int
ldp_api_session_restart (struct ldp_session *session, u_char notify,
bool_t restart_gracefully)
Input Parameters
ldp_session
LDP session
notify
Flag to indicate if notifications are to be sent
restart_gracefully
Restart gracefully
Output Parameters
None
Return Values
0 if session is restarted successfully
