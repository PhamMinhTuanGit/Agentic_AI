trill_get_rbridge_esadi_status
This function gets the RBridge ESADI status.
Syntax
int
trill_get_rbridge_esadi_status (u_int32_t vr_id, u_int32_t instance,
u_int32_t vlanindex, u_int32_t *ret)
Input Parameters
vr_id
An integer that contains the TRILL VR identifier.
instance
An integer that contains the TRILL instance ID.
vlanindex
An integer containing the VLAN index.
Output Parameters
*ret
An integer containing a return value.
Return Value
TRILL_API_GET_SUCCESS for valid Instance ID found
TRILL_API_GET_ERROR for invalid Instance ID not found
