System Management Command Reference : CHAPTER 4 Dynamic Host Configuration Protocol Relay : ip dhcp relay
  
ip dhcp relay
Use this command to enable the DHCP relay agent.
Use the no form of this command to disable the DHCP relay agent.
Command Syntax
ip dhcp relay
no ip dhcp relay
Parameters
None
Command Mode
Configure mode
Examples
#configure terminal
(config)#ip dhcp relay
 
#configure terminal
(config)#no ip dhcp relay
