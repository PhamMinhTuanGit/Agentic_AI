Intermediate System to Intermediate System Command Reference : CHAPTER 2 IS-IS Commands : disable-ldp
  
disable-ldp
Use this command to disable ISIS IPv4 or ISIS IPv6 on a specified interface.
This command disables the transmission of Hello packets through the current interface, and clears all created sessions and adjacencies for this interface. Use disable-ldp alone to disable only ISIS IPv4 on the interface.
Use the enable-ldp to enable LDP on an interface (see enable-ldp for more information).
Command Syntax
disable-ldp (ipv4|)
disable-ldp (ipv4|ipv6|)
Parameters
ipv4
Disables IPv4 on the interface.
ipv6
Disables IPv6 on the interface.
Command Mode
Interface mode
Examples
The following example disables ISIS IPv4 on interface eth0.
#configure terminal
(config)#interface eth0
(config-if)#disable-ldp
The following example disables ISIS IPv4 on interface eth0.
#configure terminal
(config)#interface eth0
(config-if)#disable-ldp ipv4
The following example disables ISIS IPv6 on interface eth0.
#configure terminal
(config)#interface eth0
(config-if)#disable-ldp ipv6
