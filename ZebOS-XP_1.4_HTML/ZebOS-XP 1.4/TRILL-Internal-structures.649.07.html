trill_interface
This data structure represents the data structure of the TRILL logical interface and contains a Level-1 substructure. This structure has a neighbor table for broadcast or point-to-point neighbor structure. It contains interface-related configuration parameters. It also contains LSP flooding queue, sending-packet buffer, circuit-ID, read/write threads and other interface-related information.
