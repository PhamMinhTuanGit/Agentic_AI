Carrier Ethernet Command Reference : CHAPTER 8 Provider Bridging Commands : vlan bridge name state
  
vlan bridge name state
Use this command to add a VLAN.
Command Syntax
vlan <2-4094> bridge <1-32> name WORD (state (enable|disable)|)
Parameters
vlan
The VLAN.
<2-4094>
The VLAN ID
bridge
The bridge
<1-32>
The bridge ID
name
The VLAN name
WORD
The name of the VLAN
state
Operational state of the VLAN; if not specified, the default is to enable the VLAN
enable
Set the VLAN to enabled
disable
Set the VLAN to disabled
Command Mode
VLAN Configuration mode
Examples
#configure terminal
(config)#vlan database
(config-vlan)#vlan 12 bridge 1 name newword state disable
