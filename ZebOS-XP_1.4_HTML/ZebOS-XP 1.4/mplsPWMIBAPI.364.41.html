nsm_mpls_set_pw_mpls_mpls_type
This function sets the outer tunnel type for a virtual circuit.
Syntax
#include "nsm/mpls/nsm_mpls_vc_snmp.h"
u_int32_t
nsm_mpls_set_pw_mpls_mpls_type (struct nsm_master *nm,
u_int32_t pw_ix, u_int32_t mpls_type);
Input Parameters
nm
Pointer to the NSM master structure
pw_ix
Index to the virtual circuit table
mpls_type
Type; one of these constants from nsm/mpls/nsm_mpls_vc_api.h:
MPLSTE
Outer tunnel set up by MPLS-TE
MPLSNONTE
Outer tunnel set up by LDP
PWONLY
No outer tunnel label; static provisioning without an MPLS tunnel
Output Parameters
None
Return Value
NSM_API_SET_ERROR when the PW index is not valid
NSM_API_SET_SUCCESS when the function succeeds
