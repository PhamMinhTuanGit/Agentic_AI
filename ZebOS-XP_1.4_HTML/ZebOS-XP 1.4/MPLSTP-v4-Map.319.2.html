Topology
Figure 23-1 shows an example of a route. Add the static route at CE1 (customer edge router 1) node to reach the PE2 (provider edge router 2) network. Similarly, add the static route at CE2 node to reach the PE1 node. Following is a summary of the configuration:
• Configure the static route on CE1.
• Map the IPv4 route at PE1 and PE2 (if the tunnel is co-routed).
• Ping traffic to go through CE1 to CE2.
