Bidirectional Forwarding Detection Command Reference : CHAPTER 3 Protocol Commands for BFD : bfd all-interfaces
  
bfd all-interfaces
Use this command to enable BFD for all neighbors maintained by an OSPF or RIP process, or an ISIS instance.
Use the no form of the command to disable BFD.
Note: This command does not apply BFD to virtual-link neighbors.
Command Syntax
bfd all-interfaces
no bfd all-interfaces
Parameters
None
Command Mode
Configure router mode
Example
#configure terminal
(config)#router ospf
(config-router)#bfd all-interfaces
 
#configure terminal
(config)#router isis
(config-router)#bfd all-interfaces
 
#configure terminal
(config)#router rip
(config-router)#bfd all-interfaces
