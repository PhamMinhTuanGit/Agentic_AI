Unicast Routing Information Base Command Reference : CHAPTER 2 Unicast RIB Commands : ip vrf isid
  
ip vrf isid
Use this command to create a VRF (Virtual Routing and Forwarding) instance associated with an I-SID (service instance identifier) that needs to advertise its routes over an SPB network.
Use the no form of this command to remove a VRF.
Note: This command is not supported for ZebIC releases.
Command syntax
ip vrf WORD isid <1-16777214>
no ip vrf WORD
Parameters
WORD
VRF instance name
<1-16777214>
Service instance identifier
Command Mode
Configure mode
Examples
#configure terminal
(config)#ip vrf vpn2 isid 2
