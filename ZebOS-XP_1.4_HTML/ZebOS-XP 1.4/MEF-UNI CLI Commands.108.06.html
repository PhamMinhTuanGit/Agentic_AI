Carrier Ethernet Command Reference : CHAPTER 6 MEF User Network Interface Commands : ethernet uni id
  
ethernet uni id
Use this command to set the name of an UNI.
Use the no option with this command to delete an UNI name.
Command Syntax
ethernet uni id NAME (type (root|leaf) (svlan <2-4094>|evc-id EVCID)|)
no ethernet uni id NAME (svlan-id <2-4096>|evc-id EVCID|)
Parameters
id
UNI identifier
NAME
UNI identifier <1-64>
type
Whether the UNI is root or leaf:
root
The UNI can send service frames to all other points in the EVC
leaf
The UNI can send and receive and service frames to and from root only
svlan
SVLAN
<2-4094>
SVLAN identifier
evc
EVC
EVC_ID
EVC identifier
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth1
(config-if)#ethernet uni id fred type root svlan 5
