rbridge trill bridge
Use this command create an RBridge TRILL instance and bind it to a bridge instance. Only one instance is supported; entering a second instance results in a return error.
Use the no parameter with this command to reset the configuration.
Command Syntax
rbridge trill (<1-32>|) bridge <1-32>
no rbridge trill (<1-32>|) bridge <1-32>
Parameters
<1–32>
Specify the RBridge instance.
<1–32>
Specify the bridge instance.
Command Mode
RBridge mode
Examples
>enable
#configure terminal
(config)#bridge 1 protocol trill
(config)#rbridge trill 1
(config-rb)#rbridge trill 1 bridge 31
 
(config-rb)#no rbridge trill 1 bridge 31
