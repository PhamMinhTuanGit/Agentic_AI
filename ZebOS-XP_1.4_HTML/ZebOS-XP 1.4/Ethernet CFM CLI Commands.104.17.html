Carrier Ethernet Command Reference : CHAPTER 2 Ethernet CFM Commands : dvm
  
dvm
Use this command to configure delay variation measurement (DVM) for a MEP.
Command Syntax
dvm (unicast (rmpid MEPID)|multicast) duration DURATION ((interval (1 | 2 | 3 | 4))|)
Parameters
unicast
Specify the unicast delay measurement.
rmpid
Specify the MEPID of remote MEP.
multicast
Specify the multicast delay measurement.
duration
Specify the DVM duration <5-60>.
interval
Specify a transmission interval.
1
100 ms>
2
10 ms>
3
1 second.
4
10 seconds.
Command Mode
Ethernet CFM MEP configuration mode
Example
(config-cfm-mep)#dvm multicast duration 12 interval 1
