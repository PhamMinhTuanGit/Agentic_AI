Virtual Routing Command Reference : CHAPTER 2 Virtual Routing Commands : show VR and VRF
  
show VR and VRF
Use this command to display a list of all virtual routers and their descriptions.
Command Syntax
show virtual-router
show virtual-router WORD
show virtual-router <1-512>
Parameters
WORD
Display the name of the virtual router.
<1-512>
Display the current configuration mode.
Command Mode
Exec mode and Privileged Exec mode
Example
The following is a sample output of this command displaying two Virtual Routers and their descriptions:
#show virtual-router
Virtual Router vr1
VR-ID: 1
Router-ID: (unset)
Interfaces: eth1
 
Virtual Router vr2
VR-ID: 2
Router-ID: (unset)
Interfaces: eth2
