vrrp_api_walk_all_sessions
This function refers to all sessions that are active.
Syntax
int vrrp_api_walk_all_sessions (int ipi_vrid, void *ref, int af_type, vrrp_api_sess_walk_fun_t efun, int *num_sess);
Input Parameters
ipi_vrid
Virtual router ID.
ref
 
af_type
Address Family
vrrp_api_sess_walk_fun_t
 
vrid
VRRP session virtual router ID (1 -255).
num_sess
Number of sessions
Output Parameters
None
Return Values
VRRP_API_SET_ERR_NO_SUCH_SESSION when no session is found
VRRP_OK when the interval for a VRRP session is set
