Shortest Path Bridging Command Reference : CHAPTER 2 SPB Configuration Commands : bridge spvid-pool
  
bridge spvid-pool
Use this command to set the Shortest Path VLAN identifier (SPVID) pool range.
The default SPVID pool range is <3600-3999>.
Use the no form of this command to reset the SPVID pool range to its default.
Command Syntax
bridge (<1-32> | backbone) spvid-pool <1-4094> to <1-4094>
no bridge (<1-32> | backbone) spvid-pool
Parameters
<1-32>
Bridge identifier.
backbone
Backbone bridge.
<1-4094>
Starting and ending SPVID.
Command Mode
SPB mode
Example
#configure terminal
(config)#spb configuration
(config-spb)#bridge 2 spvid-pool 100 to 200
