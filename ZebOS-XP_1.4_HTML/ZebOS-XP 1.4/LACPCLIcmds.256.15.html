Layer 2 Command Reference : CHAPTER 7 Link Aggregation Control Protocol Commands : show port etherchannel
  
show port etherchannel
Use this command to display details about an LACP interface.
Command Syntax
show port etherchannel IFNAME
Parameters
IFNAME
Interface name
Command Mode
Exec and Privileged Exec mode
Example
# show port etherchannel eth1
