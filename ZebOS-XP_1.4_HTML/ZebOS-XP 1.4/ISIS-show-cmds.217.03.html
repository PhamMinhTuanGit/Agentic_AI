Intermediate System to Intermediate System Command Reference : CHAPTER 3 IS-IS Show Commands : show clns neighbors
  
show clns neighbors
Use this command to display IS neighbor adjacencies.
Command Syntax
show clns neighbors (detail|)
show clns WORD neighbors (detail|)
show clns neighbors IFNAME (detail|)
show clns WORD neighbors IFNAME (detail|)
Parameters
WORD
Show information for specified instance.
IFNAME
Show information about a single interface.
detail
Show detailed information for all interfaces.
Command Mode
Exec mode, Privileged Exec mode
Example
#show clns neighbors detail
