Layer 2 Command Reference : CHAPTER 4 Spanning Tree Protocol Commands : bridge instance
  
bridge instance
Use this command to add an MST instance to a bridge.
Use the no form of this command to delete an MST instance identifier from a bridge.
Command Syntax
bridge (<1-32> | backbone) instance (<1-63> | spbm | spbv)
no bridge (<1-32> | backbone) instance (<1-63> | spbm | spbv)
Parameters
<1-32>
Bridge identifier.
backbone
Backbone bridge.
<1-63>
MST instance identifier.
spbm
Shortest Path Bridging - MAC instance.
spbv
Shortest Path Bridging - VID instance.
Command Mode
MST configure mode
Examples
#configure terminal
(config)#bridge 4 protocol mstp
(config)#spanning-tree mst configuration
(config-mst)#bridge 4 instance 3
...
(config-mst)#no bridge 4 instance 3
