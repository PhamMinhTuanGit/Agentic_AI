Terminal Access Controller Access Control System Plus (TACACS+)
An authentication method that provides access control for networked devices using one or more centralized servers. TACACS+ provides separate authentication, authorization, and accounting (AAA) services. (Usually pronounced like tack-axe.)
See also Lightweight Directory Access Protocol (LDAP), Remote Authentication Dial In User Service (RADIUS).
