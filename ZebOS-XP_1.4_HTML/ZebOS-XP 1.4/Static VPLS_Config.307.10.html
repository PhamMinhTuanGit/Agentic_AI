Multi-Protocol Label Switching Configuration Guide : CHAPTER 11 Static VPLS Configuration : Remove Configurations
  
Remove Configurations
Folow these steps to remove VPLS peer and VPLS spoke FIB entries from router PE2.
 
#configure terminal
Enter configure mode.
(config)#no vpls fib-entry 100 peer 1.1.1.1
Remove VPLS FIB for VPLS peer PE1.
(config)#no vpls fib-entry 100 peer 3.3.3.3
Remove VPLS FIB for VPLS peer PE3.
(config)#no vpls fib-entry 100 spoke-vc t1
Remove VPLS FIB for VPLS spoke t1.
(config)#exit
Exit Configure mode.
