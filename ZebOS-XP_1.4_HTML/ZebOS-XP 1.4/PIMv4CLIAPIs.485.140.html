pim4_api_vif_unbind_bundle
This function unbinds the interface from an ECMP Bundle.
Syntax
int
pim4_api_vif_unbind_bundle (u_int32_t vr_id, char *ifname, char *bundle_name)
Input Parameters
vr_id
Virtual router ID (0-255)
vrf_id
VPN Routing/Forwarding Instance ID
ifname
Interface Name
bundle_name
ECMP Bundle name
Output Parameters
None
Return Values
PIM_API_SET_ERR_WRONG_VRF when PIM VRF interface is not found
PIM_API_SET_ERR_VIF_NOT_EXIST when PIM VIF has not been created for the interface
PIM_API_SET_ERR_NO_MATCH_FOR_CONFIGURED_VALUE when the bundle name does not match the configured value
PIM_API_SET_ERR_COMMAND_NOT_CONFIGURED The interface has not been bound to any bundle.
PIM_API_SUCCESS when the function executes properly
