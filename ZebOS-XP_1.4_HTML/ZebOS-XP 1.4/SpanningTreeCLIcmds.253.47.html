Layer 2 Command Reference : CHAPTER 4 Spanning Tree Protocol Commands : show user-priority
  
show user-priority
Use this command to display the user priority data.
Command Syntax
show user-priority interface IFNAME
Parameters
interface
Displays the interface name.
Command Mode
Exec mode and Privilege Exec mode
Example
The following is a sample output of this command displaying set user priority for interface eth4.
#show user-priority interface eth4
Default user priority: 7
