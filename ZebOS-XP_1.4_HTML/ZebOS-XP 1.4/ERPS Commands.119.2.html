Carrier Ethernet Command Reference : CHAPTER 17 G.8032 ERPS Version 1 Commands : bridge g8032 ring-id
  
bridge g8032 ring-id
Use this command to create a Ethernet Ring Protection group.
Use the no form of this command to delete a Ethernet Ring Protection group.
Note: Provider Backbone Bridging is not supported for ZebIC releases.
Command Syntax
bridge <1-32> g8032 ring-id RINGID east-interface IFNAME west-interface IFNAME (instance <1-63> |)
bridge (<1-32> | backbone) g8032 ring-id RINGID east-interface IFNAME west-interface IFNAME (instance <1-63> |)
no bridge <1-32> g8032 ring-id RINGID
no bridge (<1-32> | backbone) g8032 ring-id RINGID
Parameters
bridge
Bridge.
<1-32>
Bridge ID.
backbone
Backbone bridge.
ring-id
Ethernet Ring Protection group
RINGID
Ethernet Ring Protection group ID <1-65535>
east-interface
The east interface.
IFNAME
The east interface name.
west-interface
The west interface.
IFNAME
The west interface name.
Command Mode
Configure mode
Examples
#configure terminal 
(config)#bridge 1 g8032 ring-id 1 east-interface eth0 west-interface eth1 instance 2
(config)#no bridge 1 g8032 ring-id 1
