isis_get_sys_level_overload_state
This call gets the state of the database for the instance of the IS-IS protocol at this level.
Syntax
int isis_get_sys_level_overload_state (u_int32_t vr_id, u_int32_t instance, u_int32_t level, u_int32_t *ret);
Input Parameters
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
level
IS-IS level index.
Output Parameters
ret
State of the level 1 database:
1
isisLevelStateOff
2
isisLevelStateOn
3
isisLevelStateWaiting
4
isisLevelStateOverloaded
Return Values
ISIS_API_GET_SUCCESS for the specified level found.
ISIS_API_GET_ERROR for the level not found.
