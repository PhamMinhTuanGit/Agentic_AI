Network Services Module Command Reference : CHAPTER 2 Common Exec Mode Commands : debug nsm packet
  
debug nsm packet
Use this command to enable debugging of NSM packet events.
Use the no parameter with this command or the undebug command to disable packet debugging.
Command Syntax
debug nsm packet (recv|send|) (detail|)
no debug nsm packet (recv|send|) (detail|)
undebug nsm packet (recv|send|) (detail|)
Parameters
recv
Specify the debug option-set for receive packet.
send
Specify the debug option-set for send packet.
detail
Sets the debug option to provide detailed information.
Command Mode
Privileged Exec mode, and Configure mode
Example
#debug nsm packet
#debug nsm packet recv detail
