Virtual Router Redundancy Protocol Command Reference : CHAPTER 2 VRRP Commands : show debugging vrrp
  
show debugging vrrp
Use this command to display the set VRRP debugging option.
Command Syntax
show debugging vrrp
Parameters
None
Command Mode
Exec mode and Privileged Exec mode
Example
#show debugging vrrp
VRRP event debugging is on
VRRP packet debugging is on
