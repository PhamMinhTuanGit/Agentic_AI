trill_instance_unset
This function deletes the specified TRILL router instance. It is called by the no rbridge trill CLI command and is contained in the trill_api.c file.
Syntax
s_int32_t
trill_instance_unset (u_int32_t vr_id, char *name);
Input Parameters
vr_id
Specifies the identification of the virtual router.
*name
Specifies the name of the interface.
Output Parameters
None
Return Values
TRILL_API_SET_SUCCESS: Indicates the function call executed properly.
TRILL_API_SET_ERR_INSTANCE_NOT_EXIST: Indicates there is no active IS-IS instance for the specified tag.
TRILL_API_SET_ERR_TAG_TOO_LONG: The tag length exceeds 60 characters.
TRILL_API_SET_ERR_VR_NOT_EXIST: Indicates there is no active instance of a virtual router.
