Open Shortest Path First Command Reference : CHAPTER 5 CSPF-TE Commands : show cspf ipv6 lsp
  
show cspf ipv6 lsp
Use this command to display information about all the LSPs stored in the CSPF database for all OSPFv3 instances.
Note: This command is not supported for ZebIC releases.
Command Syntax
show cspf ipv6 lsp
Command mode
Exec and Privileged Exec mode
Parameters
None
Example
Following is a sample output from the show cspf ipv6 lsp command.
