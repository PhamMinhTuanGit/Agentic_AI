Data Center Bridging Command Reference : CHAPTER 2 Enhanced Transmission Selection Commands : application-priority enable (interface)
  
application-priority enable (interface)
Use this command to enable the application priority feature of DCB on an interface.
Use the no form of this command to disable application priority on an interface.
Command Syntax
application-priority enable
no application-priority
Parameters
None
Command Mode
Interface mode
Example
#configure terminal
(config)#interface eth1
(config-if)#application-priority enable
