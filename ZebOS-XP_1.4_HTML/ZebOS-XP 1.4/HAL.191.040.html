Platform Integration Developer Guide : CHAPTER 2 Hardware Abstraction Layer : General API : hal_statistics_clear
  
hal_statistics_clear
Clear the statistics corresponding to the port ID given as input.
Syntax
int
hal_statistics_clear (u_int32_t port_id);
Input Parameters
port_id
Port ID for which statistics are to be obtained
Output Parameters
None
Return Values
HAL_ERROR if unable to clear the statistics
HAL_SUCCESS
