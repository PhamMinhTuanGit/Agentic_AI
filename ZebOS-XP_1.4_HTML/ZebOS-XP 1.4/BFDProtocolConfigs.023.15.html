Bidirectional Forwarding Detection Configuration Guide : CHAPTER 2 BFD Protocol Configurations : BFD Configuration in RIP : Topology
  
Topology
Figure 2-7: Basic Topology for BFD in RIP
Configuration for R1
 
R1#configure terminal
Enter the Configure mode.
R1(config)#router rip
Enter the Router mode for RIP.
R1(config-router)#network 10.1.1.0/24
Advertise network 10.1.1.0/24 in RIP.
R1(config-router)#bfd all-interfaces
Enable BFD for all neighbors.
 
or
R1(config-router)#neighbor 10.1.1.2 fall-over bfd
Enable BFD for a specific RIP neighbor
