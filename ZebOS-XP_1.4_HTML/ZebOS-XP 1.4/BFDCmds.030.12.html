bfd notification
Use this command to enable or disable BFD notification.
Command Syntax
bfd notification (enable | disable)
Parameters
disable
Disable BFD notification.
enable
Enable BFD notification.
Command Mode
Configure mode
Examples
#configure terminal
(config)#bfd notification enable
 
(config)#bfd notification disable
