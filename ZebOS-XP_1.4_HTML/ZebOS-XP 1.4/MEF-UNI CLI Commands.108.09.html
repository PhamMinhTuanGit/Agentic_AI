show ethernet uni bundling
Use this command to show bundling and multiplexing settings.
Command Syntax
show ethernet uni bundling (uni-id UNI_NAME | interface IF_NAME | (bridge <1-32>|))
Parameters
uni-id
UNI ID on which the status needs to be displayed
UNI_NAME
Specify the UNI ID.
interface
Specify the interface.
IF_NAME
Specify the interface name.
bridge
Specify a bridge.
<1-32>
Specify a bridge ID.
Command Mode
Executive mode
Example
#show ethernet uni bundling bridge 1
