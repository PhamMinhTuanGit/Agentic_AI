Multi-Protocol Label Switching Command Reference : CHAPTER 2 MPLS Commands : show mpls out-segment-table
  
show mpls out-segment-table
Use this command to display detailed information of out-segment entries (also known as NHLFE) table.
Command Syntax
show mpls out-segment-table
Parameters
None
Command Mode
Exec mode and Privileged Exec mode
Example
#show mpls out-segment-table
#
