Label Distribution Protocol Developer Guide : CHAPTER 11 LDP MIBs API : ldp_snmp_get_session_node
  
ldp_snmp_get_session_node
This call gets the LDP session which matches the given entity ID and peer LDP ID.
Syntax
struct listnode *
ldp_snmp_get_session_node (struct ldp *ldp,
struct ldp_id *entity_id,
s_int32_t* entity_indx,
struct ldp_id *peer_id)
Input Parameters
ldp
LDP instance
entity_id
Entity LDP ID
entity_indx
LDP entity index
peer_id
Peer LDP ID
Output Parameters
None
Return Values
LDP session node
NULL
