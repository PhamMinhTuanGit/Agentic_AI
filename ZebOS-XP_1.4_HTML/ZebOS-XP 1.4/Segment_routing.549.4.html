Segment Routing Command Reference : CHAPTER 2 Segment Routing Commands : segment-routing-static
  
segment-routing-static
Use this command to create a static segment routing entry.
Use the no form of this command to remove a static segment routing entry.
Command Syntax
segment-routing-static A.B.C.D/M A.B.C.D INTERFACE {PREFIX-SID (nexthop-route|)}
segment-routing-static (vrf NAME|) A.B.C.D/M A.B.C.D INTERFACE {PREFIX-SID (nexthop-route|)}
no segment-routing-static A.B.C.D/M A.B.C.D INTERFACE {PREFIX-SID (nexthop-route|)}
no segment-routing-static (vrf NAME|) A.B.C.D/M A.B.C.D {INTERFACE PREFIX-SID (nexthop-route|)}
Parameters
NAME
VRF name
A.B.C.D/M
Prefix or FEC with mask
A.B.C.D
Next hop IPv4 address
INTERFACE
Outgoing interface name
PREFIX-SID
Segment identifier (SID) for the prefix/FEC <1024000-1048319>
nexthop-route
The prefix belongs to the next hop; do not specify this parameter if the current device does penultimate hop popping (PHP)
Command Mode
Configure mode
Example
#configure terminal
(config)#segment-routing-static 192.168.100.0/24 192.168.2.16 eth0 1035555 nexthop-route
