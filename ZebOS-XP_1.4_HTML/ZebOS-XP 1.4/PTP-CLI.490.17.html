ptp-unicast
Use this command to enable or disable PTP unicast on an interface.
Before you give this command, you must have previously created a clock with the ptp-clk command.
Command Syntax
ptp-unicast-enable (max-table-size SIZE |)
ptp-unicast-disable
Parameters
max-table-size
Maximum size of the unicast neighbor table.
SIZE
Maximum size of the unicast neighbor table <5-50>. The default value is 1.
Command Mode
PTP clock port configure mode
Examples
>ena
#config term
Enter configuration commands, one per line. End with CNTL/Z.
(config)#interface eth0
(config-if)#clock-port
(config-clk-port)#ptp-unicast-enable max-table-size 20
