CHAPTER 9 GMRP Commands
This chapter contains the commands to configure specific VLANs or all VLANs on bridges or switches using the GARP Multicast Registration Protocol. GMRP supports a mechanism to enable bridges and end stations to dynamically register group membership information with the MAC bridges attached to the same LAN segment, and for that information to be disseminated across all bridges in the Bridged LAN that supports extended filtering services. The operation of GMRP relies upon the services provided by the GARP (Generic Attribute Registration Protocol).
This chapter provides a description, syntax, and examples of the GMRP commands. It includes the following commands:
• clear gmrp
• debug gmrp
• set gmrp disable
• set gmrp enable
• set gmrp extended-filtering
• set gmrp fwdall
• set gmrp registration
• set gmrp timer
• set port gmrp
• show debugging gmrp
• show gmrp configuration
• show gmrp machine
• show gmrp statistics
• show gmrp timer
