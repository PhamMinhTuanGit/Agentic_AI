ethernet cfm traceroute cache size
Use this command to set a traceroute cache size for a bridge.
Use the no form of this command to remove the traceroute cache size.
Command Syntax
ethernet cfm traceroute cache size ENTRIES (bridge <1-32>|)
no ethernet cfm traceroute cache size (bridge <1-32>|)
Parameters
bridge
Identify a bridge.
<1-32>
Bridge ID.
size
Indicates the size of the cache.
ENTRIES
Indicates the size of the cache.
Command Mode
Configure mode
Examples
(config)#ethernet cfm traceroute cache bridge 1
(config)#ethernet cfm traceroute cache size 29 bridge 1
(config)#no ethernet cfm traceroute cache size bridge 1
(config)#no ethernet cfm traceroute cache bridge 1
