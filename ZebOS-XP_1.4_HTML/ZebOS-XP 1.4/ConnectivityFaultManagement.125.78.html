cfm_send_1dm
This function is called by the command ethernet cfm 1dm parameter to send one-way delay measurement frames on for a MEP in a specific MD.
Syntax
#include "cfm_dm.h"
struct cfm_1dm_tx *
cfm_send_1dm (struct onmd_bridge *bridge, u_int8_t *md_name,
u_int16_t vid, u_int32_t mpid, u_int32_t rmpid,
u_int16_t duration, u_int8_t tx_interval,
u_int8_t frame_type)
Input Parameters
bridge
Bridge
md_name
Name of the MD
vid
VLAN ID <1-4094>
mpid
ID of the host MEP <1-8191>
rmip
ID of the remote MEP <1-8191>
duration
DM duration in the range of <5-50> seconds
interval
DM transmission interval
frame_type
Whether unicast or multicast
Output Parameters
None
Return Values
Pointer to the cfm_1dm_tx structure when the function succeeds
NULL when not sent
