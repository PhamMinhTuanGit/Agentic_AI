Carrier Ethernet Developer Guide : Appendix A G.8032 (ERPS) Version 1 : Command API
  
Command API
The functions in this section are called by the commands in the Carrier Ethernet Command Reference.
 
Function
Description
g8032_api_update_rpl
Updates the ring protection link owner
g8032_api_update_shared_link
Updates shared link information for protection rings
g8032_api_update_timers
Updates the timers for a protection ring
g8032_cfm_association
Adds a CFM association and configures an MD name, an MA name, and a bridge name
g8032_cfm_de_association
Deletes a CFM association from an MD, an MA, and a bridge
g8032_find_ring_by_id
Gets a ring node
