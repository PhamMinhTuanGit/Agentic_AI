Multi-Protocol Label Switching Command Reference : CHAPTER 5 Virtual Private LAN Service Commands : ve-range
  
ve-range
Use this command to identify a range of VE IDs for a VPLS in an autonomous system (AS).
A label block, defined by a Label Base (LB) and a VE block size (VBS), is a contiguous set of labels {LB, LB+1, ..., LB+VBS-1}. The ve-range command sets the block size in multiples of eight.
Use the no parameter with this command to remove a VPLS VE range size.
Command Syntax
ve-range <8-128>
no ve-range <8-128>
Parameters
<8-128>
VE range size as a 2-octet integer
Note: Ranges assigned must be given in multiples of eight.
Command Mode
VPLS Signaling mode
Examples
#configure terminal
(config)# mpls vpls test 100
(config-vpls)#signaling bgp
(config-vpls-sig)# ve-range 32
(config-vpls-sig)#exit
