CHAPTER 11 SAToP Commands
This chapter provides a reference for the SAToP (Structure-Agnostic Time Division Multiplexing over Packet) commands for pseudo wire encapsulation for Time Division Multiplexing (TDM) bit-streams (T1, E1, T3, E3). It includes the following commands:
• interface tdm
• jitter-buffer-size
•  
• rtp-header
• show tdm error-detection-timers
• show tdm interface
• show tdm satop-statistics
• tdm payload-bytes
• timer error-clear
• timer error-set
