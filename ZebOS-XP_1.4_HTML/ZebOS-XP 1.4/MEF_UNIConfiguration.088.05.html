Carrier Ethernet Configuration Guide : CHAPTER 6 MEF UNI Configuration : LACP Peering : Host Machines
  
Host Machines
HOST-1
 
HOST-1#configure terminal
Enter configure mode.
HOST-1(config)#interface eth1
Enter interface mode.
HOST-1(config-if)#switchport
Configure the interface as a Layer 2 interface.
HOST-1(config-if)#channel-group 1 mode active
Associate the interface to a channel group specified in active mode, so that link aggregation is enabled on the interface.
HOST-1(config-if)#exit
Exit interface mode.
HOST-1(config)#interface eth2
Enter interface mode.
HOST-1(config-if)#switchport
Configure the interface as a Layer 2 interface.
HOST-1(config-if)#channel-group 1 mode active
Associate the interface to a channel group specified in active mode, so that link aggregation is enabled on the interface.
