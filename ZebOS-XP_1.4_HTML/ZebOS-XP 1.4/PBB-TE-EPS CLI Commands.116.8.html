Carrier Ethernet Command Reference : CHAPTER 14 PBB-TE APS Commands : show pbb-te aps-group
  
show pbb-te aps-group
Use this command to display protection group details for a specific APS group or to display a summary for all APS groups configured.
Command Syntax
show pbb-te aps-group (APS-ID | all)
Parameters
aps-group
APS group ID <1-4094>
APS-ID
APS group ID <1-4094>
all
Display all APS group information
Command Mode
Exec mode
Example
#show pbb-te aps-group 1
