show trill esadi-instance
Use this command to display instance information for TRILL ESADI.
Command Syntax
show trill esadi-instance (vlan <1-4094>|)
Parameters
<1-4094>
Display a VLAN identifier.
Command Mode
Exec mode and Privilege Exec mode
Examples
#show trill esadi-instance
VLAN ESADI-priority CSNP-timer state confidence DRB-system-id
