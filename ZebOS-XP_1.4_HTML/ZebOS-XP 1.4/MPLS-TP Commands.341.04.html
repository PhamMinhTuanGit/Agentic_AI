Multi-Protocol Label Switching Command Reference : CHAPTER 7 MPLS-TP Commands :
  
 
Use this command to bind an interface to an MPLS-TP Layer 2 virtual circuit that was created in the Configure mode.
Use the no parameter with this command to delete this instance.
Command Syntax
NAME (ethernet|vlan <2-4094>|)
NAME (ethernet|)
no NAME (ethernet|vlan <2-4094>|)
Parameters
NAME
Name of the Layer 2 circuit; maximum 16 characters
ethernet
Identify this object as Ethernet
vlan
Identify this object as a VLAN
<2-4094>
Enter a VLAN ID
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth0
(config-if)# mycircuit ethernet
