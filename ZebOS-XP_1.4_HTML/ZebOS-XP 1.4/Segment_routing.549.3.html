Segment Routing Command Reference : CHAPTER 2 Segment Routing Commands : segment-routing mpls
  
segment-routing mpls
Use this command to enable MPLS-based segment routing globally on the device.
Use the no form of this command to disable segment routing.
Command Syntax
segment-routing mpls (ospf|)
no segment-routing mpls (ospf|)
Parameters
ospf
Enable segment routing for OSPFv2 (default)
Command Mode
Configure mode
Example
#configure terminal
(config)#segment-routing mpls
