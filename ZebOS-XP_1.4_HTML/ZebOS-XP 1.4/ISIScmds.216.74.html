Intermediate System to Intermediate System Command Reference : CHAPTER 2 IS-IS Commands : restart isis graceful
  
restart isis graceful
Use this command to force to restart the ISIS router.
Command Syntax
restart isis graceful (grace-period <1-65535>|)
Parameters
grace-period
Specify a grace period in seconds <1-65535>.
Default
By default, the ISIS router is not restarted gracefully.
Command Mode
Privileged Exec mode
Example
#restart isis graceful grace-period 60
