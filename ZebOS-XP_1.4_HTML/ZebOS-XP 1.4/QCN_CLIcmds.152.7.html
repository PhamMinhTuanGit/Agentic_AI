Data Center Bridging Command Reference : CHAPTER 3 Quantized Congestion Notification Commands : show qcn cnpv
  
show qcn cnpv
Use this command to display application priority table per interface.
Command Syntax
show qcn cnpv
show qcn cnpv ((bridge BRIDGE_ID) | (interface PORT_ID ))
Parameter
bridge
Bridge.
<1-32>
Bridge ID.
interface
Interface.
PORT_ID
Interface name.
Command Mode
Exec mode
Example 1
#show qcn cnpv bridge 2
