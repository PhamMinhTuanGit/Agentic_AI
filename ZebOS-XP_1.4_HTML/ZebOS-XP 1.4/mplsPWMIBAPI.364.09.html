nsm_mpls_get_pw_up_dn_notify
This function gets the up down notification setting.
Syntax
#include "nsm/mpls/nsm_mpls_vc_api.h"
u_int32_t
nsm_mpls_get_pw_up_dn_notify (struct nsm_master *nm, int *val);
Input Parameters
nm
Pointer to the NSM master structure
Output Parameters
val
Pointer to the notification setting
Return Value
NSM_API_GET_ERROR when the pointer to NSM master structure is NULL
NSM_API_GET_SUCCESS when the function succeeds
