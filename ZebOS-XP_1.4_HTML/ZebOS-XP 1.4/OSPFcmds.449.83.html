Open Shortest Path First Command Reference : CHAPTER 2 OSPFv2 Commands : show ip ospf route
  
show ip ospf route
Use this command to display the OSPF routing table.
Command Syntax
show ip ospf (<0-65535>|) route ( A.B.C.D |A.B.C.D/M |summary |)
show ip ospf (<0-65535>|) route ( A.B.C.D |A.B.C.D/M |summary | fast-reroute |)
Parameters
<0-65535>
Router process identifier.
A.B.C.D
Single route.
A.B.C.D/M
Single exact match route.
summary
Route counts.
fast-reroute
Fast-reroute routes.
Command Mode
Privileged Exec mode
Examples
