rsvp_snmp_get_hop_as_num
This function gets the autonomous system number of this hop.
Note: There is no support for mplsTunnelHopAddrType asnumber (3) in the backend, so ret is always zero.
Syntax
u_int32_t
rsvp_snmp_get_hop_as_num (u_int32_t *ero_ix, u_int32_t *path_ix,
u_int32_t *hop_ix,
u_int32_t *ret)
Input Parameters
ero_ix
Primary index identifying an explicit route object
path_ix
Secondary index identifying a group of hops for a configured path
hop_ix
Secondary index identifying a particular hop
Output Parameters
ret
There is no support for mplsTunnelHopAddrType asnumber (3) in the backend, so this parameter is always zero
Return Value
RSVP_API_GET_SUCCESS when the function succeeds
RSVP_API_GET_ERROR when the tunnel hop is not found
