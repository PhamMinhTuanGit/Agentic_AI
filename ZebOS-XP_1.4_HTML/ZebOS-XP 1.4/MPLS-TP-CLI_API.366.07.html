Multi-Protocol Label Switching Developer Guide : CHAPTER 19 MPLS-TP Command API : nsm_api_mpls_tp_if_unset
  
nsm_api_mpls_tp_if_unset
This function resets (unconfigures) the MPLS-TP capability on an interface.
This function is called by the no mpls-tp provider-interface CLI command.
Syntax
int
nsm_api_mpls_tp_if_unset (u_int32_t vr_id,u_int32_t ifindex);
Input Parameters
vr_id
The virtual router (VR) instance ID
ifindex
The outgoing interface index
Output Parameters
None
Return Values
NSM_API_SET_SUCCESS when the function executed properly
NSM_API_SET_ERR_IF_NOT_EXIST when the interface does not exist
NSM_API_SET_ERR_VR_NOT_EXIST when the virtual router does not exist
NSM_API_UNSET_ERR_IF_NOT_MPLS_TP_CAP when the interface was not configured as MPLS-TP Provider
NSM_ERR_LS_ON_LOOPBACK when unable to enable label switching on loopback
NSM_FAILURE when unable to disable label switching
NSM_MPLS_TP_FTN_ILM_EXISTS when MPLS-TP is active on this interface; cannot be unset
