Carrier Ethernet Command Reference : CHAPTER 6 MEF User Network Interface Commands : ce-vlan
  
ce-vlan
Use this command to configure Customer Edge (CE) VLAN class of service (COS) preservation for a particular SVLAN.
Use the no for of this command to unset preserve-cos.
Command Syntax
ce-vlan preserve-cos VLAN_ID
ce-vlan preserve-cos VLAN_ID bridge <1-32>
no ce-vlan preserve-cos VLAN_ID
no ce-vlan preserve-cos VLAN_ID bridge <1-32>
Parameters
VLAN_ID
Specify the VLAN ID of the service VLAN <1-4094>
bridge
Specify a bridge.
<1-32>
Specify a bridge ID.
Command Mode
Configure mode
Examples
#configure terminal
(config)#ce-vlan preserve-cos 2
 
#configure terminal
(config)#no ce-vlan preserve-cos 2
