Platform Integration Developer Guide : CHAPTER 2 Hardware Abstraction Layer : IPv4 API : hal_ipv4_mc_vif_add
  
hal_ipv4_mc_vif_add
This function creates a virtual interface (VIF).
Syntax
int
hal_ipv4_mc_vif_add (u_int32_t index, u_int32_t phy_ifindex,
struct hal_in4_addr *loc_addr, struct hal_in4_addr *rmt_addr,
u_int16_t flags)
Input Parameters
index
VIF index
phy_ifindex
Interface index
loc_addr
VIF local address
rmt_addr
VIF remote address (tunnel)
flags
VIF flags
Output Parameters
None
Return Value
HAL_IPV4_MC_VIF_EXISTS
< 0 when function fails
HAL_SUCCESS when function succeeds
