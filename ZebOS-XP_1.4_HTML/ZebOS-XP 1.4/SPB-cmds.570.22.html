Shortest Path Bridging Command Reference : CHAPTER 2 SPB Configuration Commands : isis-spb hostname
  
isis-spb hostname
Use this command to set the name of the host for the SPB bridge.
Use the no form of this command to delete the host name.
Command Syntax
isis-spb hostname TAG_NAME
no isis-spb hostname
Parameters
TAG_NAME
The name of the host. The maximum length is 16 characters.
Command Mode
ISIS-SPB mode
Example
#config terminal
#(config)isis-spb configuration bridge backbone
#(isis-spb-config)isis-spb hostname BEB1
