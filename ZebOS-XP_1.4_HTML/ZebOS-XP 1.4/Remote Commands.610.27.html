System Management Command Reference : CHAPTER 9 Remote Management : copy scp binary file (interactive)
  
copy scp binary file (interactive)
Use this command to copy a binary (executable) file from an SCP server to the local device.
Command Syntax
copy scp file (imi|imish|nsm|ospfd|hostpd|bgpd|isisd|ospf6d|all)
Parameters
imi
Integrated Management Interface executable
imish
Integrated Management Interface shell executable
nsm
NSM executable
ospfd
OSPFv2 executable
hostpd
Host protocol executable
bgpd
BGP executable
isisd
ISIS executable
ospf6d
OSPFv3 executable
all
All executables
Command Mode
Privileged Exec mode
Examples
#copy scp nsm
