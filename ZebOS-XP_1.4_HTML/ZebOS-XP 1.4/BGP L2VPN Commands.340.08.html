Multi-Protocol Label Switching Command Reference : CHAPTER 6 Unified L2VPN commands : rd
  
rd
Use this command to configure route distinguisher for MPLS layer 2 virtual circuit/VPLS instance.
Command Syntax
rd ASN:nn_or_IP-address:nn
Parameters
ASN:nn_or_IP-address:nn
 
Specify route distinguisher value.ASN:nn or IP-address:nn
 
Command Mode
VPWS mode and VPLS mode
Example
(config)#l2vpn-vpws vpws1
(config-vpws)#protocol ldp
(config-vpws)#vc-id 10
(config-vpws)#rd 100:10
 
(config)#l2vpn-vpls vpls1
(config-vpls)#vpn-id 2
(config-vpls)#protocol ldp autodiscovery-bgp
(config-vpls)#rd 100:10
