nsm_dcb_assign_bw_percentage_to_tcg
This function assigns the bandwidth to the traffic class groups. The total of bandwidth should be 100.
Syntax
s_int32_t nsm_dcb_assign_bw_percentage_to_tcg (u_int32_t vr_id, char *ifname, u_int16_t *bw)
Input Parameters
vr_id
Virtual Router ID
ifname
Interface name
bw
Bandwidth value
Output Parameters
None
Return Values
NSM_DCB_API_SET_SUCCESS when the function succeeds.
