hal_arp_entry_del
This function deletes all ARP entries.
Syntax
int
hal_arp_entry_del(struct pal_in4_addr *ipaddr,
unsigned char *mac_addr, u_int32_t ifindex,
int is_notification)
Input Parameters
ipaddr
IP address.
mac_addr
MAC address.
ifindex
Interface index.
is_notification
Output Parameters
None
Return Value
< 0 when function fails
HAL_SUCCESS when function succeeds.
