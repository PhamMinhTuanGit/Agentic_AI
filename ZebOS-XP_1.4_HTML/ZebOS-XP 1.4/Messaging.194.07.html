Platform Integration Developer Guide : CHAPTER 5 System Messages : HAL Initialization Messages : VLAN Messages
  
VLAN Messages
 
Message
This Message is
HAL_MSG_VLAN_INIT
Initialize VLAN database.
HAL_MSG_VLAN_DEINIT
De-initialize VLAN database.
HAL_MSG_VLAN_ADD
Add VLAN to a bridge.
HAL_MSG_VLAN_DELETE
Remove VLAN from a bridge.
HAL_MSG_VLAN_SET_PORT_TYPE
Set port type (tagged/untagged and ingress filter on/off).
HAL_MSG_VLAN_SET_DEFAULT_PVID
Set default VLAN ID on port.
HAL_MSG_VLAN_ADD_VID_TO_PORT
Add port to VLAN.
HAL_MSG_VLAN_DELETE_VID_FROM_PORT
Remove port from VLAN.
HAL_MSG_VLAN_CLASSIFIER_ADD
Add VLAN classifier.
HAL_MSG_VLAN_CLASSIFIER_DELETE
Remove VLAN classifier.
HAL_MSG_VLAN_STACKING_ENABLE
Enable VLAN stacking on port.
HAL_MSG_VLAN_STACKING_DISABLE
Disable VLAN stacking on port.
