isis_set_prot_supp_exist_state
This call gets the state of the supported protocol.
Syntax
int isis_set_prot_supp_exist_state (u_int32_t vr_id, u_int32_t instance, u_int32_t protocol, u_int32_t val);
Input Parameter
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
protocol
Supported protocol:
129
ISO8473
204
IP
142
IPv6
val
State of the manually configured supported protocol:
1
Active
2
NotInService
3
NotReady
4
CreateAndGo
5
CreateAndWait
6
Destroy
Output Parameter
None
Return Value
ISIS_API_SET_SUCCESS for set complete in the specified instance.
ISIS_API_SET_ERROR for set not complete in the specified instance.
