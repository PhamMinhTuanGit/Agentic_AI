Virtual Routing Command Reference : CHAPTER 3 Logical Switch Router Commands : allocate interface
  
allocate interface
Use this command to bind the interface to LSR instance.
Use the no parameter to unbind the interface to LSR instance.
Note: This command can be used in default LSR only.
Command Syntax
allocate interface IFNAME
no allocate interface IFNAME
Parameters
IFNAME
Specify the interface name.
Command Mode
LSR-config mode
Examples
#configure terminal
(config)#virtual-router VR1
(config-test-lsr)#allocate interface eth1
 
(config-test-lsr)#no allocate interface eth1
