isis_get_prot_supp_exist_state
This call gets the state of the supported protocol.
Syntax
int isis_get_prot_supp_exist_state (u_int32_t vr_id, u_int32_t instance, u_int32_t protocol, u_int32_t *ret);
Input Parameters
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
protocol
Supported protocol:
129
ISO8473
204
IP
142
IPv6
Output Parameters
ret
State of the manually configured supported protocol:
1
Active (default)
2
Not in service
3
Not ready
4
Create and go
5
Create and wait
6
Destroy
Return Values
ISIS_API_GET_SUCCESS for supported protocol found in the specified instance.
ISIS_API_GET_ERROR for supported protocol not found in the specified instance.
