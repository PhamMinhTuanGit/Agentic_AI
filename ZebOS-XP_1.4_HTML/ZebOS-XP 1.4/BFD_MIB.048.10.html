Bidirectional Forwarding Detection Developer Guide : CHAPTER 14 BFD MIB Support : APIs : bfd_api_set_sess_addr_type
  
bfd_api_set_sess_addr_type
This function is used to set the session address type.
Syntax
s_int32_t
bfd_api_set_sess_addr_type (struct bfd *bfd, u_int32_t index,
u_int32_t intval, bool_t snmp)
Input Parameters
bfd
A pointer to BFD structure
index
Session index
intval
Value to be set
snmp
Enable SNMP
Output Parameters
None
Return Values
BFD_FAILURE when the function fails
BFD_SUCCESS when the function succeeds
