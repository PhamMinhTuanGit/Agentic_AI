Carrier Ethernet Command Reference : CHAPTER 16 Ethernet Protection Switching Commands : g8031 signal-sync
  
g8031 signal-sync
Use this command to make an EPS signal-synchronize
Use the no form of this command to clear the signal-synchronize
Command Syntax
g8031 signal-sync
no g8031 signal-sync
Parameters
None
Command Mode
G8031 configure switching mode
Examples
#configure terminal
(config)#g8031 configure switching eps-id 10 bridge 1
(g8031-config-switching)#g8031 signal-sync
(g8031-config-switching)#no g8031 signal-sync
(g8031-config-switching)#exit
