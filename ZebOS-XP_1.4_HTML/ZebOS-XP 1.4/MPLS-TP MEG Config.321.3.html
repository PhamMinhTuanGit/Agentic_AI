Multi-Protocol Label Switching Configuration Guide : CHAPTER 25 MPLS-TP MEG Configuration : Configuring MEGs Using IETF Identifiers : Tunnel Service
  
Tunnel Service
PE1 (OAM)
 
#configure terminal
Enter configure mode.
(config)#ietf meg meg-1
Configure the MEG name as meg-1.
(config-ietf-meg)#service type tunnel
Configure the service type as tunnel.
(config-ietf-meg)#me me-1 tunnel
Configure the ME name as me-1.
(config-ietf-me)#service tunnel tnl1
Associate tnl1 with the ME.
