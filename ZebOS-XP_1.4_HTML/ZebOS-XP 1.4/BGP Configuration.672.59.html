Unicast Configuration Guide : CHAPTER 9 BGP : IPv6 Route Refresh : R1
  
R1
 
#configure terminal
Enter Configure mode.
(config)#interface eth1
Specify the interface (eth1)to configure, and enter Interface mode.
(config-if)#ip address 10.20.30.1/24
Configure the IP address on this interface
(config-if)#ipv6 address 3ffe::114/64
Configure the IPv6 address on this interface
(config-if)#exit
Exit Interface mode, and return to Configure mode.
(config)#router bgp 400
Assign the ASN value (400) to the router.
(config-router)#neighbor 3ffe::115 remote-as 7000
Specify the neighbor’s IPv6 address (3ffe::115) and the ASN value of the neighbor (7000).
(config-router)#address-family ipv6 unicast
Exchange IPv6 capabilities, and enter IPv6 mode.
(config-router-af)#neighbor 3ffe::115 activate
Activate the IPv6 peer.
(config-router-af)#redistribute static
Advertise the static routes.
