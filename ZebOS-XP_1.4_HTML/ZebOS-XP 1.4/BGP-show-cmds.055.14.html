Border Gateway Protocol Command Reference : CHAPTER 5 BGP Show Commands : show bgp neighbors advertised-routes
  
show bgp neighbors advertised-routes
Use this command to display the routes advertised to a BGP neighbor.
Command Syntax
show bgp neighbors (A.B.C.D|X:X::X:X) advertised-routes
show bgp (ipv4|ipv6) (unicast|multicast|) neighbors (A.B.C.D|X:X::X:X) advertised-routes
show ip bgp neighbors (A.B.C.D|X:X::X:X) advertised-routes
show ip bgp ipv4 (unicast|multicast) neighbors (A.B.C.D|X:X::X:X) advertised-routes
Parameters
A.B.C.D
IPv4 neighbor
X:X::X:X
IPv6 neighbor
ipv4
IPv4 addresses
ipv6
IPv6 addresses
multicast
Multicast prefixes
unicast
Unicast prefixes
Command Mode
Privileged Exec mode and Exec mode
Example
#show ip bgp ipv4 multicast neighbors 1.2.3.4 advertised-routes
