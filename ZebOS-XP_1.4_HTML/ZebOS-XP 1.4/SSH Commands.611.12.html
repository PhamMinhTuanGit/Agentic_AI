System Management Command Reference : CHAPTER 10 Secure Shell : ssh server port
  
ssh server port
Use this command to set the port number on which the SSH server listens for connections. The default port on which the SSH server listens is 22.
You can only give this command when the SSH server is disabled. See the feature ssh command.
Use the no form of this command to set the default port number (22).
Command Syntax
ssh server port <1-65535>
no ssh server port
Parameters
<1-65535>
Port number
Command Mode
Configure mode
Examples
#configure terminal
(config)#ssh server port 720
