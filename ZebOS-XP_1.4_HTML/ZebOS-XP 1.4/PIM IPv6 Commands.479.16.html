Protocol Independent Multicasting Command Reference : CHAPTER 3 PIMv6 Commands : ipv6 pim bidir-offer-limit
  
ipv6 pim bidir-offer-limit
Use this command to configure the number of unanswered offers before the device changes to the designated forwarder (DF).
Use the no command to remove the offer limit.
Note: This CLI is not supported on Hardware platform.
Command Syntax
ipv6 pim bidir-offer-limit <4-100>
no ipv6 pim bidir-offer-limit
Parameters
<4-100>
Specify the number of unanswered offers.
Command Default
The default value is three unanswered offers.
Command Mode
Global mode
Examples
#configure terminal
(config)#ipv6 pim bidir-offer-limit 99
 
(config)#no ipv6 pim bidir-offer-limit
