Enter configuration mode.
(config)#virtual-router VR1
Create a virtual router VR1.

Load the ospf module
(config)#exit
Exit configure mode.
(config)#int eth1
Enter interface mode
(config-if)#virtual-router forwarding VR1
Associate eth1 to VR1.
(config-if)#exit
Exit interface mode.
(config)#ip vrf vrf1
Create vrf1
(config)#exit
Exit configure mode.
(config)#int eth1
Enter interface mode
(config-if)#virtual-router forwarding VRF1
Associate eth1 to VRF1.

Configure the IP address to eth1
(config)#exit
Exit configure mode.
