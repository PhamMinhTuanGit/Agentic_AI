Unicast Configuration Guide : CHAPTER 12 VLAN Interfaces : Create a VLAN Interface : Configure an IP Address
  
Configure an IP Address
Once a VLAN interface is created, configure an IP address on it. Use the ipconfig command to configure the IP address of the VLAN interface, then use the same command to display information about the VLAN interface.
[root]#ifconfig eth1.10 inet 1.1.1.145 netmask 255.255.255.0 broadcast 1.1.1.255 up
