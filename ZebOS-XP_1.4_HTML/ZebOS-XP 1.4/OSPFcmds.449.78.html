Open Shortest Path First Command Reference : CHAPTER 2 OSPFv2 Commands : show ip ospf igp-shortcut-lsp
  
show ip ospf igp-shortcut-lsp
Use this command to show the IGP shortcut LSP used by OSPF.
Command Syntax
show ip ospf igp-shortcut-lsp
Parameters
None
Command Mode
Exec mode
Example
#show ip ospf igp-shortcut-lsp
Tunnel-endpoint Tunnel-id Tunnel-metric
8.8.8.8 101 2
