Routing Information Protocol Command Reference : CHAPTER 2 Routing Information Protocol Commands : show ip protocols rip
  
show ip protocols rip
Use this command to display RIP process parameters and statistics.
Command Syntax
show ip protocols
show ip protocols rip
Parameters
None
Command Mode
Exec mode and Privileged Exec mode
Example
This is an example of the output from the show ip protocols rip command:
