RSVP-TE Command Reference : CHAPTER 7 Point-to-Multipoint Commands : setup-priority
  
setup-priority
Use this command to configure a setup priority for the LSP.
Use the no parameter with this command to remove a setup priority.
Command Syntax
setup-priority <0-7>
no setup-priority
Parameters
<0-7>
Value of setup priority
Command Mode
P2MP LSP mode
Examples
(config-p2mp-lsp)#setup-priority 4
 
(config-p2mp-lsp)#no setup-priority
(config-p2mp-lsp)#
