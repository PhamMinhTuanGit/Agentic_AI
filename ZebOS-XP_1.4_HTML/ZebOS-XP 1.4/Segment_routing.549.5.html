Segment Routing Command Reference : CHAPTER 2 Segment Routing Commands : segment-routing-static edge-node
  
segment-routing-static edge-node
Use this command to create static entries in the FTN and ILM tables in the MPLS data plane.
Note: After this command executes, the segment node is considered an edge node (first/last node of a segment routing capability cloud).
Use the no form of this command to remove static entries in the FTN and ILM tables.
Command Syntax
segment-routing-static edge-node
no segment-routing-static edge-node
Parameters
None
Command Mode
Configure mode
Example
#configure terminal
(config)#segment-routing-static edge-node
