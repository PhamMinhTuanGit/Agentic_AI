trill_get_rbridge_unifdb_status
This call gets status of this entry.
Syntax
int
trill_get_rbridge_unifdb_status (u_int32_t vr_id, u_int32_t instance,
u_int32_t fdbid, u_char *macaddr,
u_int32_t *ret)
Input Parameters
vr_id
An integer that contains the TRILL VR identifier.
instance
An integer that contains the TRILL instance ID.
fdbid
Identity of this filtering database.
macaddr
Unicast MAC address for which the device has forwarding information.
Output Parameters
ret
Status of UniFdb.
1
Other
2
Invalid
3
Learned
4
Self
5
Mgmt
6
ESADI
Return Value
TRILL_API_GET_SUCCESS for valid Instance ID, DOT1QFDBID and MacAddr.
TRILL_API_GET_ERROR for valid Instance ID, DOT1QFDBID and MacAddr not found.
