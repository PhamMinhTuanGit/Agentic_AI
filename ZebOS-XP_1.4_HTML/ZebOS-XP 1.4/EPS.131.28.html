show_bridge_eps_gp
This function gets information about a specific EPS group on a bridge.
Syntax
void
show_bridge_eps_gp(struct cli *cli,
u_int8_t *br_name,
uint32_t eps_id)
Input Parameters
br_name
Name of the bridge
eps_id
Protection group ID for which information is requested
Output Parameters
cli
Pointer to the CLI structure
Return Values
None
