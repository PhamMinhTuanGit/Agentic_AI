trill_end_station_service_unset
This function removes the end station service. It is called by the no trill end-station-service-vlan CLI command and is contained in the trill_api.c file.
Syntax
s_int32_t
trill_end_station_service_unset (u_int32_t vr_id, char *name, u_int16_t vlan)
Input Parameters
vr_id
Specifies the identification of the virtual router.
*name
Specifies the name of the interface.
vlan
 
 
Specifies the VLAN range: 1–4094.
Output Parameters
None
Return Values
TRILL_API_SET_ERR_VR_NOT_EXIST: Indicates there is no active instance of a virtual router.
