Unicast Configuration Guide : CHAPTER 4 OSPF : Remove a Multiple-Instance Configuration
  
Remove a Multiple-Instance Configuration
R1
 
#configure terminal
Enter configure mode.
(config)#router ospf 1
Identify OSPF instance 1.
(config-router)#no network 1.1.1.0/24 area 0 instance-id 1
Disable OSPF for instance ID 1.
(config-router)#exit
Exit Router mode, and return to Configure mode.
(config)#router ospf 2
Identify OSPF instance 2.
(config-router)#no network 1.1.1.0/24 area 0 instance-id 2
Disable OSPF for instance ID 2.
(config-router)#exit
Exit Router mode, and return to Configure mode.
(config)#no enable ext-ospf-multi-inst
Disable multiple-instance capability.
