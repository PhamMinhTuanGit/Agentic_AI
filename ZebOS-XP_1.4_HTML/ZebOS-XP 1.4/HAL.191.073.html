Platform Integration Developer Guide : CHAPTER 2 Hardware Abstraction Layer : Flow Control API : hal_flow_control_set
  
hal_flow_control_set
This function sets the flow control properties of a port.
Syntax
int
hal_flow_control_set (unsigned int ifindex, unsigned char direction);
Input Parameters
ifindex
Port interface index
direction
HAL_FLOW_CONTROL_(OFF|SEND|RECEIVE)
Output Parameters
None
Return Value
HAL_ERR_FLOW_CONTROL_SET when function fails
HAL_SUCCESS when function succeeds
