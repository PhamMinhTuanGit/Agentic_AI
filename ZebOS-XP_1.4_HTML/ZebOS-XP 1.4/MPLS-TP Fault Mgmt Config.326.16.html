Multi-Protocol Label Switching Configuration Guide : CHAPTER 30 MPLS-TP Fault Management Configuration : MEG Configuration for Tunnel : P1 (OAM)
  
P1 (OAM)
 
#configure terminal
Enter configure mode.
(config)#ietf meg meg-5
Configure the MEG name as meg-5.
(config-ietf-meg)#service type datalink
Configure service type as datalink.
(config-ietf-meg)#me me-5 datalink
Configure ME name as me-5.
(config-ietf-me)#service datalink eth2
Configure the service datalink eth2 to be associated with the ME.
(config-ietf-me)#fault-management
Configure fault management (FM) on server layer at P1 (between P1 and P2) for tunnel tnl1.
