Multi-Protocol Label Switching Configuration Guide : CHAPTER 31 MPLS-TP Linear Protection Switching : Configure MEG for LPS : PE2 (OAM)
  
PE2 (OAM)
 
#configure terminal
Enter configure mode.
(config)#ietf meg meg1
Configure the MEG name as meg1.
(config-ietf-meg)#me me1 tunnel
Configure ME name as me1.
(config-ietf-me)#service tunnel primary-tunnel
Configure the primary-tunnel to be associated with the ME.
