Bidirectional Forwarding Detection Command Reference : CHAPTER 3 Protocol Commands for BFD : debug rip bfd
  
debug rip bfd
Use this command to debug BFD processes in RIP.
Use the no form of the command to stop debugging.
Command Syntax
debug rip bfd
no debug rip bfd
Parameters
None
Command Mode
Configure mode
Example
#configure terminal
(config)#debug rip bfd
