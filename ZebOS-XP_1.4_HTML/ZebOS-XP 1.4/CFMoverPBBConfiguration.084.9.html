The following show command for DUT-5 displays information about the maintenance points in the domain named abc associated with I-SID 3, on bridge 1, at maintenance level 3:
DUT-5#show ethernet cfm pbb maintenance-points remote domain-name abc isid 3 bridge 1
MPID LEVEL ISID MEP-UP Remote Mac
----------------------------------------------------------------
3 3 3 Yes 0002.a5e0.9563
The following ping command displays loopback and test information for the configured elements:
DUT-5#ping ethernet pbb multicast mepid 23 domain-name abc isid 3 tlv data 20 bridge 1
