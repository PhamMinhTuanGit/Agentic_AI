Multi-Protocol Label Switching Command Reference : CHAPTER 11 SAToP Commands :
  
 
Use this command to bind an interface to an MPLS-TP Layer 2 virtual circuit that was created in the Configure mode.
Use the no parameter with this command to delete this instance.
Command Syntax
NAME ((tdm-T1|tdm-E1|tdm-T3|tdm-E3) (primary|secondary|)|)
no NAME ((tdm-T1|tdm-E1|tdm-T3|tdm-E3)
Parameters
NAME
Name of the Layer 2 circuit; maximum 16 characters.
tdm-E1
TDM - E1 line.
tdm-E3
TDM - E3 line.
tdm-T1
TDM - T1 line.
tdm-T3
TDM - T3 line.
primary
Primary link.
secondary
Secondary link. This will not be activated unless primary fails.
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth0
(config-if)# new tdm-E1 primary
