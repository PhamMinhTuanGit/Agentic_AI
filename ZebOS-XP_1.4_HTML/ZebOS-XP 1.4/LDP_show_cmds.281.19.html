Label Distribution Protocol Command Reference : CHAPTER 3 LDP Show Commands : show ldp upstream
  
show ldp upstream
Use this command to display the status of all upstream sessions and label information exchanged.
Command Syntax
show ldp upstream
Parameter
None
Command Mode
Exec mode and Privileged Exec mode
Example
