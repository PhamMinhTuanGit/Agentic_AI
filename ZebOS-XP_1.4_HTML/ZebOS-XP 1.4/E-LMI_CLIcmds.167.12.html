Ethernet Local Management Interface Command Reference : CHAPTER 2 ELMI Commands : show debugging elmi
  
show debugging elmi
Use this command to display the ELMI debugging settings.
Command Syntax
show debugging elmi
Parameters
None
Command Modes
Executive Mode and Privileged Executive Mode
Examples
#show debugging elmi
ELMI debugging status:
ELMI timer debugging is on
ELMI protocol debugging is on
ELMI transmiting packet debugging is on
ELMI receiving packet debugging is on
ELMI event debugging is on
