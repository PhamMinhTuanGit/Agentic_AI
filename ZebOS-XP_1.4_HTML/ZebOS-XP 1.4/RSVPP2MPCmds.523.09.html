RSVP-TE Command Reference : CHAPTER 7 Point-to-Multipoint Commands : filter
  
filter
Use this command to configure the reservation style to use.
Command Syntax
filter (fixed|shared-explicit)
Parameters
fixed
Use a fixed filter for this trunk
shared-explicit
Use a shared-explicit filter for this trunk
Command Mode
P2MP Trunk mode
Examples
(config)#rsvp-trunk T1 ipv4 p2mp
(config-p2mp-trunk)#filter shared-explicit
(config-p2mp-trunk)#filter fixed
