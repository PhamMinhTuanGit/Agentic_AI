Bidirectional Forwarding Detection Command Reference : CHAPTER 4 BFD Static Route Commands : ip static fall-over bfd
  
ip static fall-over bfd
Use this command to enable or disable BFD support for a specific IPv4 static route.
Use the no form of the command to disable the BFD support for a specific IPv4 static route.
Command Syntax
ip static A.B.C.D/M A.B.C.D fall-over bfd (disable|)
no ip static A.B.C.D/M A.B.C.D fall-over bfd (disable|)
Parameters
A.B.C.D/M
The IPv4 destination prefix and mask length.
A.B.C.D
The IPv4 gateway address.
disable
Specify to disable BFD.
Command Mode
Configure mode
Example
#configure terminal
(config)#ip static 4.4.4.4/32 20.0.10.82 fall-over bfd
