Carrier Ethernet Command Reference : Appendix A CFM Version 1 Commands : ethernet cfm pbb ais interval
  
ethernet cfm pbb ais interval
Use this command to set a transmission interval for the Alarm Indicator Signaling (AIS) for a MEP in the desired domain. Use with a VLAN ID or a service instance (ISID) configured on a bridge or a backbone bridge.
Command Syntax
ethernet cfm pbb ais interval TX_INTERVAL mpid MEPID domain-name DOMAIN_NAME ((vlan VLAN_ID | isid ISID)|)(bridge <1-32> | backbone)
Parameters
interval
AIS transmission interval, in seconds; valid values are 1 or 60.
mpid
The identity of the host MEP.
duration
The duration of the delay measurements in the range of <5-60> seconds.
domain-name
The name of the maintenance domain.
backbone
Identifies the bridge as a backbone.
bridge
An integer in this range that identifies a bridge <1-32>.
isid
An integer that identifies an associated service instance.
vlan
(Optional) An integer that identifies a VLAN.
Command Mode
Enable mode
Examples
#ethernet cfm pbb ais interval 60 mpid 23 domain-name abc vlan 2 bridge 1
#ethernet cfm pbb ais interval 10 mpid 22 domain-name isid backbone
