Layer 2 Command Reference : CHAPTER 5 RPVST+ Commands : show bridge mstp
  
show bridge mstp
Use this command to display MSTP information for RPVST+.
Command Syntax
show bridge mstp
Parameters
None
Command Mode
Exec mode and Privileged Exec mode
Example
#show bridge mstp
bridge CVLAN SVLAN BVLAN port mac fwd timeout
