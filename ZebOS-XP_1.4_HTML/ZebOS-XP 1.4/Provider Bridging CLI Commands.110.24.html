vlan bridge state
Use this command to add a VLAN.
Command Syntax
vlan <2-4094> bridge <1-32> state (enable|disable)
Parameters
vlan
The VLAN.
<2-4094>
The VLAN ID
bridge
The bridge
<1-32>
The bridge ID
state
Operational state of the VLAN
enable
Set the VLAN to enabled
disable
Set the VLAN to disabled
Command Mode
VLAN Configuration mode
Examples
#configure terminal
(config)#vlan database
(config-vlan)#vlan 12 bridge 1 state disable
