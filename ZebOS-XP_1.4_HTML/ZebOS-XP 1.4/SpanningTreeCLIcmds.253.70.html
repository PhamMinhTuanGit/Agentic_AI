Layer 2 Command Reference : CHAPTER 4 Spanning Tree Protocol Commands : user-priority-regen-table
  
user-priority-regen-table
Use this command to set the value for the mapping of user-priority to regenerated user-priority.
Command Syntax
user-priority-regen-table user-priority <0-7> regenerated-user-priority <0-7>
Parameters
user-priority
Port priority that has to be mapped.
<0-7>
Set the user priority value.
regenerated-user-priority
 
Specify the regenerated values to be used for the user priority.
<0-7>
Regenerated user priority value.
Default
The default value is 0.
Command Mode
Interface mode
Examples
(config)#interface eth0
(config-if)#user-priority-regen-table user-priority 3 regenerated-user-priority 5
