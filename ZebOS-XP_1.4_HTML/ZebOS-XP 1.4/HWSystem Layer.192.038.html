Functions
Description

Locks all parents.
hsl_ifmgr_unlock_parents
Unlocks all parents.

Registers an OS-specific callback.
hsl_ifmgr_unset_os_callbacks
Unregisters an OS-specific callback.
hsl_ifmgr_set_hw_callbacks

hsl_ifmgr_unset_hw_callbacks
