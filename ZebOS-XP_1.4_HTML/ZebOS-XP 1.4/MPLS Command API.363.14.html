nsm_mpls_api_del_lsp_tunnel
This function deletes an LSP tunnel.
Syntax
int
nsm_mpls_api_del_lsp_tunnel (struct nsm_master *nm,
struct interface *ifp, u_int32_t in_label)
Input Parameters
nm
A pointer to NSM master structure
ifp
Pointer to the interface
in_label
Incoming label
Output Parameters
None
Return Values
NSM_ERR_NOT_FOUND when the LSP tunnel is not found
NSM_SUCCESS when the LSP tunnel is deleted successfully
