Multi-Protocol Label Switching Command Reference : CHAPTER 6 Unified L2VPN commands : vpn-id
  
vpn-id
Use this command to configure VPN identifier for a VPLS instance.
Command Syntax
vpn-id <1-4294967295>
Parameters
<1-4294967295>
Specify value for VPLS
 
Command Mode
VPLS mode
Example
(config)#l2vpn-vpls vpls2
(config-vpls)#vpn-id 20
