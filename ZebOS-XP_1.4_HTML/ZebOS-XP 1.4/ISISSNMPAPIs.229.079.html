isis_get_next_sys_level_set_overload
This call gets the next state of the overload bit for the instance of the IS-IS protocol at the next level.
Syntax
int isis_get_next_sys_level_set_overload (u_int32_t vr_id, u_int32_t *instance, u_int32_t *level, int indexlen, u_int32_t *ret);
Input Parameters
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
level
IS-IS level index.
indexlen
Length of the index.
Output Parameters
ret
State of the overload bit:
1
isisTruthValueTrue
2
isisTruthValueFalse
Return Values
ISIS_API_GET_SUCCESS for the specified next level found.
ISIS_API_GET_ERROR for the next level not found.
