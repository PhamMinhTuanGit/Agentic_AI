Carrier Ethernet Command Reference : CHAPTER 2 Ethernet CFM Commands : ethernet cfm mep
  
ethernet cfm mep
Use this command to create a MEP and set it to the up or down state. This command switches you into Ethernet CFM MEP configuration mode.
Note: To create a link-level MEP, do not enter a the local-vid parameter.
Use the no form of this command to delete a MEP.
Command Syntax
ethernet cfm mep (down|up) mpid MEPID active (true | false) domain DOMAIN_NAME (vlan VLANID|)(local-vid VID|)(uni-mep|) (bridge <1-32>|)
no ethernet cfm mep (down|up) mpid MEPID domain DOMAIN_NAME (vlan VLANID|)
(local-vid VID|)(bridge <1-32>|)
Parameters
down
Specify a down MEP.
up
Specify an up MEP.
mep
Host MEP.
MEPID
Specify the host MEP ID <1-8191>.
active
Specify the administrative state of the MEP.
true
Set the state of the MEP to active.
false
Set the state of the MEP to inactive.
domain
Specify the maintenance domain name.
DOMAIN_NAME
Specify the maintenance domain name.
vlan
Specify the VLAN. When no primary VLAN is entered, the MEP uses the primary VLAN of the maintenance association.
VLAN_ID
Specify the VLAN ID.
local-vid
Specify the ID of the local VLAN.
VID
Specify the VLAN ID.
uni-mep
Specify that the MEP is a User Network Interface type.
bridge
Specify a bridge.
<1-32>
Specify a bridge ID.
Command Mode
Interface mode
Example
(config)#interface eth1
(config-if)#ethernet cfm mep down mpid 23 active true domain abc vlan 3 bridge 1
(config-if)#ethernet cfm mep down mpid 23 active true domain abc vlan 3 local-vid 4 bridge 1
(config-if)#ethernet cfm mep down mpid 23 active true domain abc bridge 1
(config-if)#no ethernet cfm mep down mpid 23 domain abc vlan 3 bridge 1
(config-if)#no ethernet cfm mep down mpid 23 domain abc bridge 1
