Label Distribution Protocol Command Reference : CHAPTER 3 LDP Show Commands : show mpls ldp session
  
show mpls ldp session
Use this command to display LDP session information.
Command Syntax
show mpls ldp session A.B.C.D
show mpls ldp session X:X::X:X
Parameter
A.B.C.D
The IPv4 address of the peer for which information is to be shown.
X:X::X:X
The IPv6 address of the peer for which information is to be shown.
Command Mode
Exec mode and Privileged Exec mode
Example
#show mpls ldp session 10.10.0.5
