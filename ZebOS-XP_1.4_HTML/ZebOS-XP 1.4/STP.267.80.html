mstp_api_set_port_forceversion
This function sets the force version for a port.
Syntax
int
mstp_api_set_port_forceversion (char *name,
char *ifName,
s_int32_t version)
Input Parameters
name
Name of the bridge.
ifName
The interface name.
version
The version identifier; one of these constants from mstpd/mstp_config.h:
BR_VERSION_STP
 
STP
BR_VERSION_RSTP
 
RSTP
BR_VERSION_MSTP
 
MSTP
Output Parameters
None
Return Values
RESULT_OK when bridge enable succeeds
RESULT_ERROR when bridge enable fails
