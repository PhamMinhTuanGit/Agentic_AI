Segment Routing Command Reference : CHAPTER 2 Segment Routing Commands : show ip ospf segment-routing capability
  
show ip ospf segment-routing capability
Use this command to display the segment routing capabilities of OSPF advertisement routers.
Command Syntax
show ip ospf (<0-65535>|) segment-routing capability
Parameters
<0-65535>
Router process identifier.
Command Mode
Privileged Exec mode
Example
#show ip ospf segment-routing capability
-----------------------------------------------------
Advertisement Router Capability :1.1.1.1
Algorithm :0
Total SID'S Supported :24320
SID Range List Count :1
SID's Range :1024000 - 1048319
-----------------------------------------------------

Algorithm :0
Total SID'S Supported :24320
