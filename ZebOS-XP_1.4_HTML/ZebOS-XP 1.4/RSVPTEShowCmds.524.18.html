RSVP-TE Command Reference : CHAPTER 8 Show Commands : show rsvp p2mp-session
  
show rsvp p2mp-session
Use these commands to display information about P2MP RSVP sessions, including ingress, egress and transit details.
Command Syntax
show rsvp p2mp-session
show rsvp p2mp-session ingress
show rsvp p2mp-session ingress branch
show rsvp p2mp-session transit
show rsvp p2mp-session transit branch
show rsvp p2mp-session transit bud
show rsvp p2mp-session egress
Parameters
None
Command Mode
Privileged Exec and Exec modes
Examples
#show rsvp p2mp-session
