Label Distribution Protocol Developer Guide : CHAPTER 9 LDP API : ldp_api_get_loop_detect_hop_limit
  
ldp_api_get_loop_detect_hop_limit
This call returns the loop-detect hop-count limit for the given entity, if the loop detection is enabled.
Syntax
u_char
ldp_api_get_loop_detect_hop_limit (struct ldp *ldp,
struct ldp_entity *entity)
Input Parameters
ldp
LDP instance
entity
LDP entity
Output Parameters
None
Return Values
Hop count limit
LDP_ERROR
