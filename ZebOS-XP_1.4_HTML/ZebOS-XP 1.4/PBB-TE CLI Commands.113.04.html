Carrier Ethernet Command Reference : CHAPTER 11 PBB-TE Provisioning Commands : esp egress pnp
  
esp egress pnp
Use this command to associate a PNP (Provider Network Port) to an egress ESP (Ethernet Switched Path).
Command Syntax
esp egress pnp (add | delete) IFNAME
Parameters
add
Add a PNP
delete
Delete a PNP
IFNAME
Local CBP (Customer Backbone Port) interface name
Command Mode
PBB-TE configure switching mode
Examples
#configure terminal
(config)#interface cbp.1
(config-if)#no shutdown
(config-if)#pbb-te configure esp tesi 20
(pbb-te-esp-if-config)#esp egress pnp add eth3
