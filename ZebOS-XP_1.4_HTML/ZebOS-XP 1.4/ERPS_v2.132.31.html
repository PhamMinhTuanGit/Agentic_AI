Carrier Ethernet Developer Guide : CHAPTER 9 G.8032 (ERPS) Version 2 : Command API : g8032_api_profile_set_timer
  
g8032_api_profile_set_timer
This function sets a timer.
This function implements the timer command.
Syntax
s_int32_t
g8032_api_profile_set_timer (u_int8_t is_conf,
struct g8032_instance_profile *profile,
enum g8032_timer_type type,
u_int32_t timeout_val)
Input Parameters
is_conf
Reserved for future use
profile
Profile
type
Type of timer: one of these constants from the g8032_timer_type enum in onmd/cfm/g8032v2/g8032_profile.h:
G8032_TIMER_TYPE_WTR
 
Wait-to-restore timer in seconds; used to verify that a signal failure is not intermittent
G8032_TIMER_TYPE_WTB
 
Wait-to-block timer in seconds
G8032_TIMER_TYPE_GUARD
 
Guard timer in microseconds; blocks latent outdated messages from causing unnecessary state changes
G8032_TIMER_TYPE_HOLDOFF
 
Hold-off timer in microseconds; filters intermittent link faults
timeout_val
Timeout value
Output Parameters
None
Return Values
G8032_ERROR_NONE when the function succeeds
G8032_ERROR_PROFILE_NOT_FOUND when the profile is NULL
G8032_ERROR_PROFILE_INVALID_TIMER_TYPE when type is not valid
