trill instance
Use this command to bind the interface to a specified TRILL instance.
Use the no parameter with this command to remove the interface from a specified TRILL instance.
Command Syntax
trill instance (<1-32>|)
no trill instance (<1-31>|)
Parameters
<1-31>
Specify a TRILL instance
Command Mode
Interface mode
Examples
>enable
#configure terminal
(config)#interface eth1
(config-if)#trill instance 1
 
(config-if)#no trill instance 1
