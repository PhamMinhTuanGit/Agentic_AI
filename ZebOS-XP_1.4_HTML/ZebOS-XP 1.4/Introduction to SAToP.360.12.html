nsm_tdm_set_jitter_buffer_size
Use this function to configure the jitter-buffer size.
Syntax
int
nsm_tdm_set_jitter_buffer_size(struct interface *ifp ,u_int8_t buf_size)
Input Parameters
*ifp
Pointer to the interface
*buf_size
Buffer size
Output Parameters
None
Return Values
NSM_ERR_NOT_FOUND
NSM_SUCCESS
