Carrier Ethernet Command Reference : Appendix A CFM Version 1 Commands : ethernet cfm pbb-te ais interval
  
ethernet cfm pbb-te ais interval
Use this command to set the AIS transmission interval. Enter a transmission interval in the range of 1 to 60 seconds.
Command Syntax
ethernet cfm pbb-te ais interval TX_INTERVAL mpid MEPID domain-name DOMAIN_NAME
te-sid TE_SID bridge backbone
Parameters
mpid
Identity of the host MEP ID
domain-name
Name of the maintenance domain
te-sid
TE service instance ID
bridge
 
Identify a bridge group name.
backbone
Specify a backbone bridge
Command Mode
Exec Mode and Privileged Exec Mode
Example
#ethernet cfm pbb-te ais interval 1 mpid 2 domain-name ipi te-sid 4 bridge backbone
