Virtual Routing Command Reference : CHAPTER 3 Logical Switch Router Commands : show lsr membership
  
show lsr membership
Use this command to display the interface membership information for the LSR.
Note: In the default LSR, this command displays a list of all LSRs and their descriptions. In non-default LSRs, this command displays the LSR description for the current LSR only.
Command Syntax
show lsr membership
Example
(config)# show lsr membership
 
lsr_id: 1 lsr_name: switch interfaces:
eth0 eth1 eth3 eth4
eth6 eth8
 
lsr_id: 2 lsr_name: Payroll interfaces:
eth2 eth5
 
lsr_id: 3 lsr_name: MyLSR interfaces:
eth7 eth9
 
 
switch# show LSR membership status
LSR_id: 1 LSR_name: switch interfaces:
Port Status
---- ----------
eth1 OK
eth2 OK
eth3 OK
eth4 OK
