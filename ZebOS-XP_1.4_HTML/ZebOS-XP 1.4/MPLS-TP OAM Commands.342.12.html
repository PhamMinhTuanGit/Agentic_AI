Multi-Protocol Label Switching Command Reference : CHAPTER 8 MPLS-TP OAM Commands : fault-alarm
  
fault-alarm
Use this command to enable the fault-alarm feature for a Maintenance Entity Group End Point (MEP).
Use the no parameter with this command to disable this feature.
Command Syntax
fault-alarm (priority (5|4|3|2|1) alarm-time <1-10> reset-time <1-10>|)
no fault-alarm
Parameters
priority
Priority of a defect:
5
xCONCCM defect
4
errorCCm defect
3
someRMEPCCmdefect
2
someMACstatus defect
1
someRDI defect
alarm-time
Alarm time.
<1-10>
Alarm time value. The default is 2.5 seconds.
reset-time
Reset time.
<1-10>
Reset time value. The default is 10 seconds.
Command Mode
ITUT MP configuration mode
Examples
#configure terminal
(config)#itut meg new12 level 1
(config-itut-meg)#mep-id 12
(config-itut-mp)#fault-alarm priority 1 alarm-time 1 reset-time 1
 
(config-itut-mp)#no fault-alarm
