nsm_sr_api_disable
This function disables segment routing (SR) globally on the device, de-initializing the Segment Routing Global Block (SRGB) and notifying SR-enabled protocols.
The no segment-routing mpls command calls this function.
Syntax
int
nsm_sr_api_disable (u_int32_t vr_id,
u_int8_t *fwd_proto,
u_int8_t *igp_proto)
Input Parameters
vr_id
Virtual router identifier <0-255>
fwd_proto
Protocol used in forwarding plane for SR (“MPLS”)
igp_proto
IGP protocol used for segment signalling (“ospf”)
Output Parameters
None
Return Values
NSM_SUCCESS when the function succeeds
NSM_API_SET_ERR_VR_NOT_EXIST when vr_id does not exist
NSM_ERR_INTERNAL when there is an internal error
NSM_SR_ERR_COMMAND_NOT_CONFIGURED when SR is not enabled
