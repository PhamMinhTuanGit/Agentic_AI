Layer 2 Command Reference : CHAPTER 11 MMRP Commands : show mmrp statistics
  
show mmrp statistics
Use this command to display a statistical summary for a VLAN.
To modify the lines displayed, use the | (output modifier token). To save the output to a file, use the > (output redirection token).
Command Syntax
show mmrp statistics vlanid <1-4094>
show mmrp statistics vlanid <1-4094> (bridge <1-32>|)
Parameters
<1-4094>
Displays the VLAN identifier.
<1-32>
Displays the bridge identifier.
Command Mode
Exec and Privileged Exec mode
Example
The following is an output of this command displaying a statistical summary for MMRP.
#show mmrp statistics vlan 123
