Multi-Protocol Label Switching Command Reference : CHAPTER 10 MPLS-TP RPS Commands : show mpls-tp rps protection-group
  
show mpls-tp rps protection-group
Use this command to display information about all the configured MPLS-TP RPS protection groups.
Command Syntax
show mpls-tp rps protection-group
Parameters
None
Command Mode
Privileged Exec and Exec modes
Examples
#show mpls-tp rps protection-group
