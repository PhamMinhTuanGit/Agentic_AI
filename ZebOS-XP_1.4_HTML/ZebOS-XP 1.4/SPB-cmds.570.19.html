Shortest Path Bridging Command Reference : CHAPTER 2 SPB Configuration Commands : isis-spb configuration bridge
  
isis-spb configuration bridge
Use this command to enter ISIS-SPB mode to configure an ISIS-SPB bridge.
Command Syntax
isis-spb configuration bridge (<1-32> | backbone)
Parameters
<1-32>
Bridge identifier
backbone
Backbone bridge
Command Mode
Configure mode
Example
(config)#isis-spb configuration bridge 16
(isis-spb-config)#
