isis_get_circ_ifindex
This call gets the value of interface index for the interface to which this circuit corresponds.
Syntax
int isis_get_circ_ifindex (u_int32_t vr_id, u_int32_t instance, u_int32_t circindex, u_int32_t *ret);
Input Parameters
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
circindex
IS-IS circuit index.
Output Parameters
ret
Interface index that corresponds to the circuit index.
Return Values
ISIS_API_GET_SUCCESS for supported circuit index found in the specified instance.
ISIS_API_GET_ERROR for supported circuit index not found in the specified instance.
