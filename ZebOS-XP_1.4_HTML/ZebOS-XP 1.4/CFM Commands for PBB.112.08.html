Carrier Ethernet Command Reference : CHAPTER 10 Provider Backbone Bridging CFM Commands : cc unicast
  
cc unicast
Use this command to enable or disable unicast continuity checking (CC).
Syntax
cc unicast rmpid RMEPID state (enable | disable)
Parameters
rmepid
Remote MEP ID.
state
Set the continuity check state
enable
Enable the continuity checking state for unicast.
disable
Disable the continuity checking state for unicast.
Command Mode
Interface Ethernet CFM PBB MEP configuration mode
Examples
#configure terminal
(config)#interface eth1
(config-if)#ethernet cfm pbb mep down mpid 23 domain-name abc bridge 1
(config-if-eth-cfm-pbb-mep)#cc unicast rmpid 3 state enable
