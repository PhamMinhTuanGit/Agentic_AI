ZebOS-XP Install Guide : Appendix A Build Configuration Options : Hardware Integration
  
Hardware Integration
 
Option flag
Description
--enable-broadcom[=bmw|gto]
Build the Broadcom Hardware Services Layer; optional parameters are bmw or gto
--enable-marvell
Build the Marvell Hardware Services Layer
--enable-wintegra
Build the Wintegra Hardware Services Layer
--enable-hal
Build the Hardware Abstraction Layer (HAL)
--enable-user-hsl
Build the User Hardware Services Layer (HSL)
--enable-ccm-hw-offload
Offload CCM to hardware for Wintegra WinPath3
--enable-Y1731-hw-offload
Offload Y1731 to hardware Wintegra WinPath3
