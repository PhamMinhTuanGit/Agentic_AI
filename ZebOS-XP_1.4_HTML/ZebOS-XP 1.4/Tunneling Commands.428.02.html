Network Services Module Command Reference : CHAPTER 9 Tunneling Commands : interface tunnel
  
interface tunnel
Use this command to create a new tunnel interface.
Use the no parameter to destroy the tunnel interface.
Command Syntax
interface tunnel <0-2147483647>
no interface tunnel <0-2147483647>
Parameter
<0-2147483647>
Specify a tunnel interface number.
Default
Disabled
Command Mode
Configure mode
Example
#configure terminal
(config)#interface tunnel 100
(config-if)#
