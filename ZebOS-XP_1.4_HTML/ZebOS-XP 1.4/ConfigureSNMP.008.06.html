SNMP Utilities
This section applies to both the SMUX and AgentX protocols. In the following sections:
-c is an option specifying community string
test is the community string authentication key
10.10.10.50 is the agent machine’s IP address, which can be a localhost
i = is used to set an integer value
a = is used to set an IP address
s = is used to set a string value
TYPE = i|a|s
VALUE = Value of the specified Type. For example, i 20 sets an integer value of 20.
