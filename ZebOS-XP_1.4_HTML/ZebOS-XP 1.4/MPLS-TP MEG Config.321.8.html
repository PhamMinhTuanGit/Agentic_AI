Multi-Protocol Label Switching Configuration Guide : CHAPTER 25 MPLS-TP MEG Configuration : Configuring MEGs Using ITU-T Identifiers : Virtual Circuit Service
  
Virtual Circuit Service
PE1 (OAM)
 
#configure terminal
Enter configure mode.
(config)#itut meg meg-v
Configure the MEG name as meg-v.
(config-itut-meg)#service type vc
Configure the service type as virtual circuit.
(config-itut-meg)#mep-id 1111
Configure the MEP identifier as 1111.
(config-itut-mp)#service vc 101
Associate virtual circuit 101 with the ME.
(config-itut-mp)#rmep-id 4444 cc IN icc AIRTEL umc meg-v
Configure the remote MEP.
