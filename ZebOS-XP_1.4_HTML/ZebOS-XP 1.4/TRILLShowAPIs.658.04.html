trill_cli_show_fdb
This function shows the details of the specified forwarding table: unicast, multicast or detail. It is called by the show trill fdb CLI command and is located in the trill_cli.c file.
Syntax
s_int32_t
trill_cli_show_fdb (struct cli *cli, char *level_str)
Input Parameters
*cli
Specifies the instance of the CLI structure. Values includes 1-31.
*level_str
Specifies the forwarding table, including unicast, multicast or detail.
Output Parameters
None
Return Value
CLI_SUCCESS
CLI_ERROR
