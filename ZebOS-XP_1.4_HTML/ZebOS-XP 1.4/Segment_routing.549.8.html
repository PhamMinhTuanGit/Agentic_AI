Segment Routing Command Reference : CHAPTER 2 Segment Routing Commands : show ip ospf segment-routing prefix-sid
  
show ip ospf segment-routing prefix-sid
Use this command to display the segment routing capabilities of ospf advertisement routers.
The prefix segment identifier (SID) data is displayed for non-connected routes of prefixes only because penultimate hop popping (PHP) is enabled by default.
Command Syntax
show ip ospf (<0-65535>|) segment-routing prefix-sid
Parameters
<0-65535>
Router process identifier.
Command Mode
Privileged Exec mode
Example
#sh ip ospf segment-routing prefix-sid
------------------------------------------
Prefix(or FEC) :10.0.0.0/24
Segment :Global
Advertisement Router :1.1.1.1
SID Value :1024010
Next-Hop Route :20.0.0.30
Next-Hop If_Index :3
PHP Route Prefix :Yes
Loop-back Prefix :No
------------------------------------------
This Segment Node :EDGE
------------------------------------------
