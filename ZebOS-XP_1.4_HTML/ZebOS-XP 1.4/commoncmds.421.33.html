Network Services Module Command Reference : CHAPTER 2 Common Exec Mode Commands : show users
  
show users
Use this command to display information about terminal lines.
Command Syntax
show users
Parameters
None
Command Mode
Exec mode and Privileged Exec mode
Example
This is a sample output of the show users command:
#show users
 
Line User Host(s) Idle Location
130 vty 0 idle 00:45:44 2
#
