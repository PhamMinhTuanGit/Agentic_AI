synce_display_prc
This function displays primary reference clock information.
This function implements the show synce input-sources and show synce details commands.
Syntax
#include "synced/synce_cli.h"
s_int16_t
synce_display_prc (struct cli *cli)
Input Parameters
None
Output Parameters
cli
CLI structure
Return Value
SYNCE_FAILURE when the SyncE master structure cannot be found
SYNCE_SUCCESS when the function succeeds
