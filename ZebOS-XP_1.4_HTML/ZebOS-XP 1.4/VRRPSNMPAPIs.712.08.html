vrrp_get_oper_master_ipaddr
This function retrieves the master IP address of the VRRP virtual router.
Syntax
int vrrp_get_oper_master_ipaddr (int ipi_vrid, u_int8_t aftype, u_int8_t vrid,
u_int32_t ifindex, u_int8_t *ipaddr);
Input Parameters
ipi_vrid
Virtual router ID
aftype
Address family type (AF_INET or AF_INET6)
vrid
VRRP virtual router ID (1 - 255)
ifindex
Interface index
ipaddr
Pointer to the location to store the retrieved master IP address
Output Parameters
ipaddr
Pointer to the location with the retrieved master IP address
Return Values
VRRP_API_GET_SUCCESS when the function succeeds
VRRP_API_GET_ERROR when the function fails
