trill_get_next_rbridge_multifib_port
This call gets the list of ports to which a frame destined to the next multicast distribution tree is flooded
Syntax:
int
trill_get_next_rbridge_multifib_port (u_int32_t vr_id, u_int32_t *instance,
u_int16_t *nickname, int indexlen,
void *portlist)
Input Parameters
vr_id
An integer that contains the TRILL VR identifier.
instance
An integer that contains the TRILL instance ID.
nickname
Nickname of the multicast distribution tree.
indexlen
An Integer variable that contains the length of the index
Output Parameters
portlist
An octet string containing the list of ports.
Return Value
TRILL_API_GET_SUCCESS for valid Instance ID, Nickname.
TRILL_API_GET_ERROR for valid Instance ID, Nickname not found.
