RSVP-TE Command Reference : CHAPTER 7 Point-to-Multipoint Commands : retry-timer
  
retry-timer
Use this command to set a retry timer for a P2MP LSP. If you have CSPF enabled, the retry timer set with this command also becomes the CSPF retry timer, which is the periodicity of subsequent CSPF probes in case of unsuccessful path computation.
Use the no parameter with this command to reset the retry timer to its default value.
Command Syntax
retry-timer <1-600>
no retry-timer
Parameters
<1-600>
Timeout, in seconds, between successive Path message retries.
Command Mode
P2MP LSP mode
Examples
(config-p2mp-lsp)#retry-timer 200
 
(config-p2mp-lsp)#no retry-timer
(config-p2mp-lsp)#
