TRILL RPF Check
RPF Check technique is used by RBridges for avoiding temporary multicast loops during topology changes is the Reverse Path Forwarding Check. It involves checking that a multi-destination frame, based on the tree and the ingress RBridge, arrives from the expected link. RBridges MUST drop multi-destination frames that fail the RPF check.
Use the same topology and configuration as in Chapter 17, Multicast OAM.
Along with above configurations on RBridge1, configure the number of dtrees to use as shown below:
#con terminal
Enter configuration commands, one per line. End with CNTL/Z.
(config)#rbridge trill 1
(config-rb)#number-of-dtrees-to-use 2
(config-rb)#exi
