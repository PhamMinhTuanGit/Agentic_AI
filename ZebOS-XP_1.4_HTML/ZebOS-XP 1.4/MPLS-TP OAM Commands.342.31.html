Multi-Protocol Label Switching Command Reference : CHAPTER 8 MPLS-TP OAM Commands : rmep-id
  
rmep-id
Use this command to configure a Remote Maintenance Entity Group End Point (RMEP).
Command Syntax
rmep-id <1-8191> cc CC-NAME icc ICC-NAME umc UMC (fwd|rev)
no rmep-id <1-8191> cc CC-NAME icc ICC-NAME umc UMC
Parameters
<1-8191>
RMEP identifier.
CC-NAME
Country code: two alphabetic characters, upper case (A-Z).
ICC-NAME
ITU carrier code: 1-6 characters, alphabetic (A-Z) or numeric (0-9).
UMC
Unique MEG code: 1-5 characters, excluding a forward slash (/).
fwd
Forward RMEP.
rev
Reverse RMEP.
Command Mode
ITUT MIP mode
Examples
#configure terminal
(config)#itut meg new12 level 1
(config-itut-meg)#mep-id 12
(config-itut-mp)#rmep-id 1 cc US icc 123456 umc new fwd
 
(config-itut-mp)#no rmep-id 1 cc US icc 123456 umc new
