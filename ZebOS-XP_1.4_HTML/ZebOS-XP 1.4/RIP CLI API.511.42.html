Routing Information Protocol Developer Guide : CHAPTER 3 RIP Command API : RIP APIs : rip_recvbuf_size_set
  
rip_recvbuf_size_set
This function specifies the size of the RIP UDP buffer.
This function is called by the following command:
recv-buffer-size
Syntax
int
rip_recvbuf_size_set (u_int32_t vr_id, int instance, u_int32_t bufsize);
Input Parameters
vr_id
The Virtual Router ID. Its default value is 0. For a non-VR implementation, pass 0 for this parameter.
instance
The number of the instance
bufsize
The size of the receiving buffer <8192–2147483647>
Output Parameters
None
Return Values
RIP_API_SET_ERR_CANT_CHANGE_BUFFER_SIZE when the buffer size cannot be set by the lower layer, i.e., kernel
RIP_API_SET_ERR_PROCESS_NOT_EXIST when the instance cannot be found
RIP_API_SET_ERR_VR_NOT_EXIST when vr_id does not exist
RIP_API_SET_SUCCESS when the call is successful
