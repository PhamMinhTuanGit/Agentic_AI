Data Center Bridging Command Reference : CHAPTER 3 Quantized Congestion Notification Commands : show qcn cp
  
show qcn cp
Use this command to show the configuration of all congestion points on the interface.
Command Syntax
show qcn cp
show qcn cp ((bridge <1-32> )|(interface PORT_ID))
Parameters
bridge
Bridge.
<1-32>
Bridge ID.
interface
Interface.
PORT_ID
Interface name.
Command Mode
Exec mode
Examples
#show qcn cp bridge 2
