Open Shortest Path First Command Reference : CHAPTER 2 OSPFv2 Commands : area multi-area-adjacency
  
area multi-area-adjacency
Use this command to enable multi-area adjacency on the specified interface. Multi-area adjacency establishes adjacency between the Area Border Routers (ABRs). The specified interface of the ABR is associated with multiple areas. Multiple OSPF interfaces must be created for multiple areas.
Use the no parameter to disable multi-area adjacency.
Command Syntax
area (A.B.C.D|<0-4294967295>) multi-area-adjacency IFNAME neighbor A.B.C.D
no area (A.B.C.D|<0-4294967295>) multi-area-adjacency IFNAME (neighbor A.B.C.D|)
Parameters
IFNAME
An alphanumeric string that is the interface name.
neighbor
Set the neighbor.
A.B.C.D
Neighbor’s IP address.
Command Mode
Router mode
Examples
#configure terminal
(config)#router ospf 1
(config)#router-id 10.10.10.10
(config-router)#area 1 multi-area-adjacency eth1 neighbor 20.20.20.10
(config-router)#no area 1 multi-area-adjacency eth1
