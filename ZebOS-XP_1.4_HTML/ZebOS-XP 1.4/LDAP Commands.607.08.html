System Management Command Reference : CHAPTER 6 Lightweight Directory Access Protocol : ldap-server timeout
  
ldap-server timeout
Use this command to set the period to wait for a response from the server before the client declares a timeout failure. The default timeout value is 5 seconds.
You can only give this command when the LDAP feature is enabled. See the feature ldap command.
Use the no form of this command to set the timeout value to its default value (5 seconds).
Command Syntax
ldap-server timeout <1-60>
no ldap-server timeout <1-60>
Parameters
<1-60>
Timeout value in seconds
Command Mode
Configure mode
Examples
#configure terminal
(config)#ldap-server timeout 35
