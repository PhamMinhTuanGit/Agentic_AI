trill_parse_mul_ch_frame
This function parses channel packet and fills the trill_data_packet structure (refer to trill_data_packet). If the hopcount is greater than 1, it calls trill_channel_mul_frame_forward() to forward packet and return (refer to trill_channel_mul_frame_forward). If this is a ping request, it calls trill_process_mul_ping_request() (refer to trill_process_mul_ping_request). If this is a Traceroute request, it calls trill_process_mul_tracert_request() (refer to trill_process_mul_tracert_request).
Syntax
s_int32_t
trill_parse_mul_ch_frame (struct trill_channel_packet *dpkt,
struct trill_interface *isi)
Input Parameters
*dpk
Received channel data packet.
*isi
Pointer to the interface on which a frame was received.
Output Parameters
None
Return value
TRILL_CHANNEL_FAIL
TRILL_CHANNEL_SUCCESS
