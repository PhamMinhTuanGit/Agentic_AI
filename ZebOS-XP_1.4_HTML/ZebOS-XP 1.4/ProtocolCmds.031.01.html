CHAPTER 3 Protocol Commands for BFD
The chapter describes the commands used to manage BFD functionality for the OSPF, IS-IS and BGP protocol modules. It includes the following commands:
• area virtual-link
• bfd all-interfaces
• debug bgp bfd
• debug isis bfd
• debug ospf bfd
• debug rip bfd
• ip ospf bfd
• isis bfd
• neighbor fall-over bfd (BGP)
• neighbor fall-over bfd (RIP)
