Multi-Protocol Label Switching Configuration Guide : CHAPTER 35 MPLS-TP MSPW Configurations : Configuration of Pseudowire : T-PE1
  
T-PE1
 
#configure terminal
Enter configure mode.
(config)#mpls l2-circuit vc1 101 200 2.2.2.2 666 grp1 manual
Configure Pseudowire for Router 1, with VC1 as Pseudowire name and configure the endpoints.
Note: Pseudowire id should be same for both the endpoints.
(config)#bridge 1 protocol ieee vlan-bridge
Configure bridge
(config)#interface eth1
Enter interface mode.
(config-if)#switchport
Make interface switchport.
(config-if)#bridge-group 1
Associate the interface to the bridge.
(config-if)#switchport mode access
Make the interface as access port.
(config-if)#mpls-tp service-interface type layer-2 555
Make interface as MPLS-TP service interface.
(config-if)##mpls l2-circuit vc1 ethernet
Bind the Pseudowire with the access interface of Edge node router.
(config-if)#exit
Exit interface mode.
(config)#mpls l2-circuit-fib-entry 101 100 200 tp-tunnel tn1 eth1
Configure the FIB entry for the configured Pseudowire.
(config)#exit
Exit configure mode.
