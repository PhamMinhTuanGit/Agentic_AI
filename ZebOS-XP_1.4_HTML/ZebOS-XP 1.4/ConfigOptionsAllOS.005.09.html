ZebOS-XP Install Guide : Appendix A Build Configuration Options : IS-IS
  
IS-IS
 
Option flag
Description
--enable-isisd
Build the IS-IS daemon (Default Linux)
--disable-isisd
Do not build the IS-IS daemon
--enable-isis6d
Build the IS-IS6 daemon (Default Linux)
--disable-isis6d
Do not build the IS-IS6 daemon
--enable-multi-topology
Enable IS-IS multi-topology support
--disable-multi-topology
Do not enable IS-IS multi-topology support.(Default)
