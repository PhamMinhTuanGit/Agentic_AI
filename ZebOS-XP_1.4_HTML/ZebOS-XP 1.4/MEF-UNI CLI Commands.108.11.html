Carrier Ethernet Command Reference : CHAPTER 6 MEF User Network Interface Commands : show ethernet uni evc-id
  
show ethernet uni evc-id
Use this command to show the Ethernet virtual connector (EVC) ID.
Command Syntax
show ethernet uni evc-id (uni-id UNI_NAME | interface IF_NAME | (bridge <1-32>|))
Parameters
uni-id
UNI ID on which the status needs to be displayed
UNI_NAME
Specify the UNI ID.
interface
Specify the interface.
IF_NAME
Specify the interface name.
bridge
Specify a bridge.
<1-32>
Specify a bridge ID.
Command Mode
Executive mode
Example
#show ethernet uni evc-id interface eth1
 
Interface-name UNI-ID UNI-EVC_ID
--------------------------------------------------------------------
eth1 unia unia,JCN_pro_vlan
unia, HP_pro_vlan
#show ethernet uni max-evc bridge 1
 
Interface_name UNI-ID MAX-EVC
------------------------------------------------
 
eth1 Customer1 4
eth2 Customer2 2
