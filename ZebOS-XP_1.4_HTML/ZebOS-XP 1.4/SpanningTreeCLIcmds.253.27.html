Layer 2 Command Reference : CHAPTER 4 Spanning Tree Protocol Commands : clear spanning-tree statistics
  
clear spanning-tree statistics
Use this command to clear all STP BPDU statistics.
Command Syntax
clear spanning-tree statistics bridge <1-32>
clear spanning-tree statistics interface IFNAME (instance (<1-63>|spbm)| vlan <1-4094>) bridge <1-32>
clear spanning-tree statistics (interface IFNAME| (instance (<1-63>|spbm)| vlan <2-4094>)) bridge <1-32>
Parameters
<1-32>
Specify the bridge identifier.
IFNAME
Specify the name of the interface on which protocols have to be cleared.
<1-63>
MST instance ID.
spbm
Shortest Path Bridging - MAC instance.
<1-4094>
VLAN identifier where spanning tree is located <2-4094>
Command Mode
Exec mode and Privileged Exec mode
Example
(config-if)#clear spanning-tree statistics bridge 32
