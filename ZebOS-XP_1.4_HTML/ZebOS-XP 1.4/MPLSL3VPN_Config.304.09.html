Create VRF
Each PE router in the MPLS-VPN backbone is attached to a site that receives routes from a specific VPN, so the PE router must have the relevant Virtual Routing and Forwarding (VRF) configuration for that VPN. Use the following command to create the VRF (see the Border Gateway Protocol Command Reference for details):
ip vrf VRF-NAME
VRF-NAME a name used to identify the VRF.
This command creates a VRF RIB (Routing Information Base), assigns a VRF-ID, and switches the command mode to vrf mode. The following example demonstrates the use of the command to create a VRF named ComB.
(config)#ip vrf ComB
(config-vrf)#
