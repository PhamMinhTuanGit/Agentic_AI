System Management Command Reference : CHAPTER 2 Authentication, Authorization, and Accounting : show aaa authentication login
  
show aaa authentication login
Use this command to display AAA authentication configuration for login default and login console.
Command Syntax
show aaa authentication login (error-enable | mschap)
Parameters
error-enable
Display setting for login failure messages
mschap
Display setting for Microsoft Challenge Handshake Authentication Protocol (MS-CHAP) authentication
Command Modes
Executive mode
Examples
#show aaa authentication login error-enable
