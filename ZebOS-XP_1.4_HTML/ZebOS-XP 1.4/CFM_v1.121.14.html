Carrier Ethernet Command Reference : Appendix A CFM Version 1 Commands : ethernet cfm exm
  
ethernet cfm exm
Use this command to configure Ethernet experimental OAM messages functionality between a host and a destination MEP in an administrative domain. ZebOS-XP handles the message part of the frame alone; in other words, ZebOS-XP can identify the frame, but does not handle the payload.
Note: Interoperability of vendor-specific OAM is not expected when using equipment from different vendors.
Command Syntax
ethernet cfm exm tx mepid MEPID unicast rmepid RMEPID domain DOMAIN_NAME (vlan VLAN_ID|) (bridge <1-32>|)
Parameters
tx
Specify frame transmission.
mepid
Specify an integer that identifies the host MEP.
unicast
Specify that unicast frames are to be sent.
rmepid
Specify the ID of the remote MEP.
domain
Specify name of the maintenance domain.
bridge
Specify the ID of the bridge group name used for bridging <1-32>.
vlan
Specify an integer that identifies a VLAN.
Command Mode
Exec mode and Privileged Exec mode
Examples
#ethernet cfm exm tx mepid 3 unicast rmepid 5 domain 3 vlan 3 bridge 1
