rmon_snmp_set_history_status
This function sets the status of an entry in the historyControlTable.
Syntax
s_int32_t
rmon_snmp_set_history_status (struct rmon_master *rm,
struct rmon_HistoryControlGroup *rmon_history, u_int32_t index, u_int32_t status)
Input Parameters
rm
Pointer to RMON master
rmon_history
Pointer to RMON history control group
index
Index of the history control entry
status
The status to set; one of the constants below from rmond/rmon_config.h. See the EntryStatus syntax item in RFC 2819 for valid state transitions:
VALID_STATUS
 
CREATE_REQ_STATUS
 
UNDER_CREATION_STATUS
 
INVALID_STATUS
 
Output Parameters
None
Return Value
RMON_API_SET_SUCCESS or RESULT_OK when the function succeeds
RMON_API_SET_FAILURE or RESULT_ERROR when the function fails
