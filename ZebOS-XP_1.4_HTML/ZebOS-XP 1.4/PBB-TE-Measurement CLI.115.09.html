Carrier Ethernet Command Reference : CHAPTER 13 PBB-TE Measurement Commands : mcc tx
  
mcc tx
Use this command to configure multicast or unicast Maintenance Communication Channel (MCC) frames.
Command Syntax
mcc tx (unicast rmepid RMEPID| multicast)
Parameters
unicast
Specify that unicast MCC frame are to be sent
rmepid
Specify the ID of the remote MEP.
multicast
Specify that multicast MCC frame are to be sent
Command Mode
Ethernet CFM PBB-TE MEP configuration mode
Example
(config-cfm-pbb-te-mep)#mcc tx unicast rmepid 12
