Multi-Protocol Label Switching Configuration Guide : CHAPTER 25 MPLS-TP MEG Configuration : Configuring MEGs Using ITU-T Identifiers : Data Link Service
  
Data Link Service
P1 (OAM)
 
(config)#interface eth3
Enter interface mode for eth1
(config-if)#mpls-tp provider-interface 30.1.1.1
Configure the interface as provider and set the local identifier to 30.1.1.1
#configure terminal
Enter configure mode.
(config)#itut meg meg-d level 5
Configure the MEG name as meg-d at level 5.
(config-itut-meg)#service type datalink
Configure the service type as data link.
(config-itut-meg)#mep-id 2222
Configure the MEP identifier as 2222.
(config-itut-mp)#service datalink eth3
Associate data link eth3 with the ME.
(config-itut-mp)#rmep-id 3333 cc IN icc AIRTEL umc meg-d
Configure the remote MEP.
