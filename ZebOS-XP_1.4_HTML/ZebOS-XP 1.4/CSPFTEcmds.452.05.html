Open Shortest Path First Command Reference : CHAPTER 5 CSPF-TE Commands : debug cspf
  
debug cspf
Use this command to enable the CSPF debugging options in OSPFv2.
Use the no parameter with this command to disable debugging.
Command Syntax
debug cspf events
debug cspf hexdump
 
no debug cspf events
undebug cspf events
no debug cspf hexdump
undebug cspf hexdump
Parameters
events
Debug CSPF event information.
hexdump
Debug CSPF message hex dumps.
Command Mode
Exec and Privileged Exec modes
