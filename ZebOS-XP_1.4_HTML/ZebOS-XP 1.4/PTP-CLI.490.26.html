Precision Time Protocol Command Reference : CHAPTER 2 Precision Time Protocol Commands : slave-only
  
slave-only
Use this command to enable or disable slave-only mode for a clock.
Command Syntax
slave-only (enable|disable)
Parameters
enable
This clock always synchronizes to another clock and is never considered a candidate for master clock by the best master clock algorithm.
disable
This clock is considered a candidate for master clock by the best master clock algorithm
Command Mode
PTP clock configure mode
Examples
>ena
#config term
Enter configuration commands, one per line. End with CNTL/Z.
(config)#ptp-clk ordinary transport-type ethernet
(config-ptp-clk)#slave-only enable
