ZebOS-XP Install Guide : Appendix A Build Configuration Options : Virtual Routing/Forwarding
  
Virtual Routing/Forwarding
 
Option flag
Description
--enable-vr
Enable Virtual Routing
--disable-vr
Disable VR (Default)
--enable-vrf
Enable Virtual Router Forwarding (VRF)
Note: If you have enabled VR, you do not need to enable VRF. Enabling VR automatically enables VRF.
--disable-vrf
Disable VRF (Default)
--enable-vrf-ns
Enable VRF namespace
--disable-vrf-ns
Disable VRF namespace (Default)
