Layer 2 Command Reference : CHAPTER 4 Spanning Tree Protocol Commands : spanning-tree autoedge
  
spanning-tree autoedge
Use this command to assist in automatic identification of the edge port.
Use the no parameter with this command to disable this feature.
Command Syntax
spanning-tree autoedge
no spanning-tree autoedge
Parameters
None
Command Mode
Interface mode
Example
#configure terminal
(config)#interface eth0
(config-if)#spanning-tree autoedge
