Unicast Configuration Guide : CHAPTER 2 RIP : Authentication with a Single Key : R2
  
R2
 
#configure terminal
Enter Configure mode.
(config)#router rip
Define a RIP routing process, and enter Router mode.
(config-router)#network 10.10.10.0/24
Associate network 10.10.10.0/24 with the RIP process.
(config-router)#redistribute connected
Enable redistributing from connected routes.
(config-router)#exit
Quit Router mode, and return to Configure mode.
(config)#interface eth0
Specify the interface (eth0) for authentication.
 
(config-if)#ip rip authentication string IPI
Specify the authentication string (IPI) on this interface.
(config-if)#ip rip authentication mode md5
Specify the authentication mode to be MD5.
