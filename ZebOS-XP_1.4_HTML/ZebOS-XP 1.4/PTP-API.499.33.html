show_transparent_clock_ds
This function gets the data set of a transparent clock.
Syntax

void
show_transparent_clock_ds (struct cli* cli, struct ptp_clock *clock)
Input Parameters
clock
A pointer to the clock
Output Parameters
cli

Return Values
None
