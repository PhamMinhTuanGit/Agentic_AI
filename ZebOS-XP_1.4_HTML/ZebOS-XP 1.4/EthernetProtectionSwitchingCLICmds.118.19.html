Carrier Ethernet Command Reference : CHAPTER 16 Ethernet Protection Switching Commands : show bridge g8031
  
show bridge g8031
Use this command to display summary EPS information for the specified bridge group.
Command Syntax
show bridge <1-32> g8031
show bridge backbone g8031
show bridge (<1-32> | backbone) g8031
Parameters
bridge
Bridge.
<1-32>
Bridge ID.
backbone
Backbone bridge.
Command Mode
Exec mode and Privilege Exec mode
Examples
The example below shows the command and the output of its execution.
#show bridge 2 g8031
Bridge EpsID Working-Path Protection-Path Current-State
-------------------------------------------------------------
2 10 eth1 eth2 No Request
Primary Vid - 3
Active-Path - Working
DFOP State - Not in defect mode
Protected Vlans - 4
