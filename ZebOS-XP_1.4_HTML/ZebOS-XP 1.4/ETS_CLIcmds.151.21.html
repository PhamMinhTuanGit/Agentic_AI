Data Center Bridging Command Reference : CHAPTER 2 Enhanced Transmission Selection Commands : traffic-class-group
  
traffic-class-group
Use this command to add or remove priorities for a traffic class group.
Use the no form of this command to remove all traffic-class-groups.
Command Syntax
traffic-class-group <0-7> add priority <0-7> (<0-7>(<0-7>(<0-7>(<0-7>(<0-7>(<0-7>(<0-7>|)|)|)|)|)|)|)
traffic-class-group <0-7> remove priority <0-7> (<0-7>(<0-7>(<0-7>(<0-7>(<0-7>(<0-7>(<0-7>|)|)|)|)|)|)|)
no traffic-class-groups
Parameters
<0-7>
Specify traffic-class-group ID.
add priority
Specify to add a traffic class group
<0-7>
Traffic-priority value. Up to seven priorities can be added.
remove priority
 
Specify to remove a traffic class group
<0-7>
Traffic-priority value. Up to seven priorities can be removed.
Command Mode
Interface mode
Example
#configure terminal
(config)#interface eth1
(config-if)#traffic-class-group 1 add priority 1 2 3 4 5 6 7
 
(config)#interface eth1
(config-if)#traffic-class-group 1 remove priority 3 6
 
(config)#interface eth1
(config-if)#no traffic-class-group
