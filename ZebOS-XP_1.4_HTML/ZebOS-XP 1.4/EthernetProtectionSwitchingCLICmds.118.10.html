Carrier Ethernet Command Reference : CHAPTER 16 Ethernet Protection Switching Commands : g8031 lockout
  
g8031 lockout
Use this command to lock out switching to the protection path under all circumstances. If the protection path is in use when this command is entered, a switch back to the working path is made regardless of its state. This command overrides any outstanding EPS or manual APS command.
Use the no form of this command to clear the lockout.
Command Syntax
g8031 lockout
no g8031 lockout
Parameters
None
Command Mode
G8031 configure switching mode
Examples
#configure terminal
(config)#g8031 configure switching eps-id 10 bridge 1
(g8031-config-switching)#g8031 lockout
(g8031-config-switching)#no g8031 lockout
