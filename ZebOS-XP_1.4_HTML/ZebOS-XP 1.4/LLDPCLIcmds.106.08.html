Carrier Ethernet Command Reference : CHAPTER 4 Link Layer Discovery Protocol Commands : set lldp locally-assigned
  
set lldp locally-assigned
Use this command to locally assign the LLDP Port ID and the Chassis ID TLV parameters.
Command Syntax
set lldp locally-assigned NAME
Parameters
NAME
Name assigned to the port.
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth 0
(config-if)#set lldp locally-assigned port1
