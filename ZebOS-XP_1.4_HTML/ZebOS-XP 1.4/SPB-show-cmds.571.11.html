show spb service bridge
Use this command to display information for I-SIDs or MTIDs associated to the SPB area.
Command Syntax
show spb service bridge (<1-32> | backbone) (isid <1-16777214>|mtid (0|MTID)| )
Parameters
<1-32>
Bridge identifier.
backbone
Backbone bridge.
<1-16777214>
Instance service identifier. If you do not specify this parameter, the command displays information for all I-SIDs related to the SPB area.
mtid
Multi-topology identifier. If this parameter is not specified, the default is 0.
0
Multi-topology identifier 0.
MTID
Multi-topology identifier <3996-4095>.
Command Mode
Privileged Exec mode
Example
#show spb service bridge backbone
