Forwarding Equivalence Class
A Forwarding Equivalence Class section defines a set of packets that would be forwarded on the same path by the MPLS network. To define FEC, IPv4 routes are advertised by two common methods:
.Host Address
The LSR uses the address of the destination host to create this FEC: all packets going to this destination will take the same LSP.
.Prefix
The LSR uses the destination prefix to create this FEC: all packets take the LSP corresponding to the longest matching prefix.
