RSVP-TE Command Reference : CHAPTER 7 Point-to-Multipoint Commands : class-type
  
class-type
Use this command to set a DiffServ Traffic Engineering (DSTE) class type for a P2MP LSP when DSTE is enabled.
Use the no parameter with this command to remove a DSTE class type.
Command Syntax
class-type CT-NAME
no class-type
Parameters
CT-NAME
Class type name
Command Mode
P2MP LSP mode
Examples
(config-p2mp-lsp)#class-type ct0
(config-p2mp-lsp)#no class-type
