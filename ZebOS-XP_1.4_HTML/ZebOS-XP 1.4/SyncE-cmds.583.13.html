Synchronous Ethernet Command Reference : CHAPTER 2 SyncE Configuration Commands : synce debug
  
synce debug
Use this command to turn on debugging.
Use the no from of this command to turn off debugging
Command Syntax
synce debug (event|recvd|trans)
no synce debug (event|recvd|trans)
Parameters
event
Enable event debugging
recvd
Enable reception debugging
trans
Enable transmission debugging
Command Mode
Privileged Exec mode
Example
#synce debug event
