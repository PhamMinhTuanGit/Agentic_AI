Label Distribution Protocol Command Reference : CHAPTER 3 LDP Show Commands : show ldp downstream
  
show ldp downstream
Use this command to display the status of all downstream sessions and the label information exchanged.
Command Syntax
show ldp downstream
Parameter
None
Command Mode
Exec mode and Privileged Exec mode
Example
