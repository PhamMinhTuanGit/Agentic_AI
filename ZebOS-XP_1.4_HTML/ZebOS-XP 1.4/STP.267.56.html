mstp_api_set_bridge_forceversion
This function sets the force version for a bridge.
Syntax
int
mstp_api_set_bridge_forceversion (char *name, s_int32_t version)
Input Parameters
name
Name of the bridge.
version
The version identifier; one of these constants from mstpd/mstp_config.h:
BR_VERSION_STP
 
STP
BR_VERSION_RSTP
 
RSTP
BR_VERSION_MSTP
 
MSTP
BR_VERSION_SPB
 
Shortest Path Bridging
Output Parameters
None
Return Values
RESULT_OK when function succeeds.
RESULT_ERROR when function fails.
