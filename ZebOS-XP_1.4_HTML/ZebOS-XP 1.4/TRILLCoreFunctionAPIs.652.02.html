trill_systemid_set
This function sets the TRILL system ID for the specified instance. The system ID will be auto-generated by default. This function is called by the systemid CLI command and is contained in the trill_api.c file.
Syntax
s_int32_t
trill_systemid_set (u_int32_t vr_id, char *tag, char *systemid)
Input Parameters
vr_id
Specifies the identification of the virtual router.
*tag
Specifies the tag of the interface.
*systemid
Specifies the system identification for the TRILL instance.
Output Parameters
None
Return Values
TRILL_API_SET_SUCCESS: Indicates the function call executed properly.
TRILL_API_SET_ERR_INSTANCE_NOT_EXIST: Indicates there is no active IS-IS instance for the specified tag.
TRILL_API_SET_ERR_SYSTEM_ID_CANT_CHANGED
TRILL_API_SET_ERR_VR_NOT_EXIST: Indicates there is no active instance of a virtual router.
