Virtual Router Redundancy Protocol Command Reference : CHAPTER 2 VRRP Commands : v2-compatible
  
v2-compatible
Use this command to enable the backward-compatibility feature. When enabled, both VRRPv3 and VRRPv2 inter-operation are supported.
Use the no parameter with this command to disable this feature
Command Syntax
v2-compatible
no v2-compatible
Parameters
None
Default
Enable
Command Mode
Router mode
Examples
#configure terminal
(config)#router vrrp 1 eth0
(config-router)#v2-compatible
