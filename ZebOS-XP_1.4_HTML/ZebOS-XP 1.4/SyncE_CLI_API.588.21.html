synce_display_input_src
This function displays information about all input sources.
This function implements the show synce input-sources command.
Syntax
#include "synced/synce_cli.h"
s_int16_t
synce_display_input_src (struct cli *cli)
Input Parameters
None
Output Parameters
cli
CLI structure
Return Value
SYNCE_FAILURE when the SyncE master structure cannot be found
SYNCE_SUCCESS when the function succeeds
