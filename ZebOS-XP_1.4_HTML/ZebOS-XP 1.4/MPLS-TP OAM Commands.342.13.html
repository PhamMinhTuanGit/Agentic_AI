Multi-Protocol Label Switching Command Reference : CHAPTER 8 MPLS-TP OAM Commands : ietf meg
  
ietf meg
Use this command to configure an IETF Maintenance Entity Group (MEG) to monitor an MPLS-TP path by running OAM functions. This command changes to IETF MEG mode.
Use the no parameter with this command to remove a MEG.
Note: Once you have configured a MEG, you need to configure the service type. Refer to the service type command for more information.
Command Syntax
ietf meg NAME
no ietf meg NAME
Parameters
NAME
MEG name: 1-48 characters
Command Mode
Configure mode
Examples
#configure terminal
(config)#ietf meg MEG
(config-ietf-meg)#
 
(config)#no ietf meg MEG
