show mpls p2mp-tunnel NAME
Use this command to display information about a named tunnel.
Command Syntax
show mpls p2mp-tunnel NAME
Parameters
NAME
Name of the tunnel for which information is desired
Command Mode
Privileged Exec and Exec modes
Examples
#show mpls p2mp-tunnel T2
