Carrier Ethernet Command Reference : CHAPTER 2 Ethernet CFM Commands : ethernet cfm automatic bridge
  
ethernet cfm automatic bridge
Use this command to automatically configure CFM on the given bridge. When you give this command, there is no need to configure a maintenance domain (MD), a maintenance association (MA), and maintenance end points (MEPs) for the VLANs/I-SIDs associated with the bridge.
Use the no form of this command to disable automatic configuration.
Command Syntax
ethernet cfm automatic bridge (<1-32> | backbone)
no ethernet cfm automatic bridge (<1-32> | backbone)
Parameters
bridge
Specify a bridge.
<1-32>
Specify a bridge identifier.
backbone
Backbone bridge.
Command Mode
Configure mode
Example
#configure terminal
(config)#ethernet cfm automatic bridge 1
