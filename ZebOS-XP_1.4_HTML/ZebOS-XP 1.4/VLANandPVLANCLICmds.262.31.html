Layer 2 Command Reference : CHAPTER 13 VLAN and Private VLAN Commands : vlan mtu
  
vlan mtu
Use this command to set the Maximum Transmission Unit (MTU) for a specified VLAN. Any packet with a size greater than the configured MTU is discarded.
Use the no parameter to reset the MTU configuration for the VLAN.
Command Syntax
vlan <2-4094> mtu MTU_VAL
vlan <2-4094> mtu MTU_VAL bridge <1-32>
no vlan <2-4094> mtu
no vlan <2-4094> mtu bridge <1-32>
Parameters
mtu
The value of the Maximum Transmission Unit.
bridge
Specify the bridge group ID.
Command Mode
VLAN Configuration mode
Examples
#configure terminal
(config)#vlan database
(config-database)#vlan 2 mtu 1000 bridge 1
