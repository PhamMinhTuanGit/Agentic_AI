CHAPTER 8 Remote Authentication Dial In User Service
This chapter is a reference for Remote Authentication Dial In User Service (RADIUS) commands, RADIUS provides centralized Authentication, Authorization, and Accounting (AAA) management for users that connect to and use a network service. RADIUS is specified in RFC 2865.
