Multi-Protocol Label Switching Configuration Guide : CHAPTER 25 MPLS-TP MEG Configuration : Configuring MEGs Using IETF Identifiers : Virtual Circuit Service
  
Virtual Circuit Service
PE1 (OAM)
 
#configure terminal
Enter configure mode.
(config)#ietf meg meg-10
Configure the MEG name as meg-10
(config-ietf-meg)#service type vc
Configure the service type as virtual circuit.
(config-ietf-meg)#me me-10 vc
Configure the ME name as me-10
(config-ietf-me)#service vc 101
Associate virtual circuit 101 with the ME.
