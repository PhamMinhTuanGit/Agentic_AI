Platform Integration Developer Guide : CHAPTER 2 Hardware Abstraction Layer : Interface API : hal_if_flags_get
  
hal_if_flags_get
This function gets the flags for an interface.
Syntax
int
hal_if_flags_get (char *ifname, unsigned int ifindex, u_int32_t *flags)
Input Parameters
ifname
Interface name
ifindex
Interface index
Output Parameters
flags
One of the following:
IFF_RUNNING
IFF_UP
IFF_BROADCAST
IFF_LOOPBACK
Return Value
< 0 when function fails
HAL_SUCCESS when function succeeds
