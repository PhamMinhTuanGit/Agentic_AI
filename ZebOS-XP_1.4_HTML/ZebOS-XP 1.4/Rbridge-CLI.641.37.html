rbridge-ping-interval
Use this command to set the ping interval.
Command Syntax
rbridge-ping-interval INTERVAL
no rbridge-ping-interval
Parameters
INTERVAL
Specify the time interval between sending successive ping packets.
<1-65535>
Specify the actual ping interval in seconds.
Command Mode
Exec mode and Privilege Exec mode
Examples
>enable
#rbridge-ping-interval INTERVAL 12345
 
#no rbridge-ping-interval
