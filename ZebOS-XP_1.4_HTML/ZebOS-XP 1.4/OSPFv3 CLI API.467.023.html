ospf6_area_range_set
This function configures an OSPF address range.
This function is called by the following command:
area range
Syntax
int
ospf6_area_range_set (u_int32_t vr_id, char *tag, struct pal_in4_addr area_id,
void *addr, int prefixlen, int status
Input Parameters
vr_id
Virtual router ID; for a non-virtual-router implementation, specify 0
tag
OSPFv3 process tag
area_id
OSPFv3 area ID in an IPv4 address format
addr
IPv6 or IPv4 starting address; this parameter is defined as a void pointer so you can cast it to either the prefix_ipv4 or prefix_ipv6 structure in lib/prefix.h
prefixlen
Area range IPv6 prefix length <0-128>
status
Whether to advertise this range; one of these constants from pal/linux/pal_types.h:
PAL_TRUE
Advertise this range
PAL_FALSE
Do not advertise this range
Output Parameters
None
Return Value
OSPF6_API_SET_ERR_VR_NOT_EXIST when the virtual router does not exist
OSPF6_API_SET_ERR_PREFIXLEN_INVALID when the given prefix length is outside the range
OSPF6_API_SET_ERR_PROCESS_NOT_EXIST when the specified process does not exist
OSPF6_API_SET_SUCCESS when the function succeeds
