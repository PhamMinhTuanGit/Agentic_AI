Platform Integration Developer Guide : CHAPTER 2 Hardware Abstraction Layer : General API : hal_hw_reg_set
  
hal_hw_reg_set
This function sets the value of the hardware register passed as input.
Syntax
int
hal_hw_reg_set (u_int32_t reg_addr, u_int32_t value);
Input Parameters
reg_addr
Address of the hardware register
value
Value to be set on the register
Output Parameters
None
Return Values
HAL_ERROR if unable to set the value of the register
HAL_SUCCESS
