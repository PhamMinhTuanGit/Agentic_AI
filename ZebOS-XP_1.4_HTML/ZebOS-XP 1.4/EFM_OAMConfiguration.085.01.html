CHAPTER 3 Ethernet to the First Mile OAM Configuration
This chapter contains a complete sample Ethernet to the First Mile - Operation Administration and Maintenance (EFM-OAM) configuration.
The main functions of EFM-OAM are link performance monitoring, fault detection, fault signaling and loopback signaling. Slow Protocol frames called OAM Protocol Data Units (OAMPDUs) deliver OAM information. OAMPDUs contain the appropriate control and status information used to monitor, test and troubleshoot OAM-enabled links.
