Virtual Routing Command Reference : CHAPTER 2 Virtual Routing Commands : show nsm virtual-router
  
show nsm virtual-router
Use this command to display NSM information for a virtual router.
Command Syntax
show nsm virtual-router (brief|detail|)
Parameters
brief
Display brief NSM information.
detail
Display connected NSM information.
Command Mode
Privileged Exec mode
Examples
#show nsm virtual-router brief
