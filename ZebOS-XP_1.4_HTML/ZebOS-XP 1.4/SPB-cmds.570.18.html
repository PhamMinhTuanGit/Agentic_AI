Shortest Path Bridging Command Reference : CHAPTER 2 SPB Configuration Commands : ipvpn
  
ipvpn
Use this command to enable or disable IPVPN for SPB. When IPVPN is enabled, a VRF (VPN routing/forwarding instance) is identified by an I-SID (service instance identifier). IPVPN traffic within the SPB network uses the I-SID portion of the service instance tag (I-TAG) without a C-MAC header, called the short I-TAG.
Command syntax
ipvpn enable
ipvpn disable
Parameters
None
Default
By default, IPVPN is disabled.
Command Mode
SPB mode
Examples
#config terminal
#(config)spb configuration
#(config-spb)ipvpn enable
