Layer 2 Configuration Guide : CHAPTER 14 MAC Authentication Configuration : MAC Address Authentication : Validation
  
Validation
• To verify MAC address authentication mechanism when authentication is successful:
DUT#show bridge
bridge VLAN port mac fwd timeout
1 1 eth2 0050.8b01.a349 1 4
When authentication is successful, the source MAC is added to forwarding table as forwarding enabled.
• To verify MAC address authentication mechanism when authentication fails and failure action is configured as drop-traffic:
DUT#show bridge
bridge VLAN port mac fwd timeout
1 1 eth2 0050.8b01.b348 0 295
When authentication fails, the source MAC is added to forwarding table as discarding.
• To verify the MAC address authentication mechanism when authentication fails and failure action is configured restrict-vlan:
DUT#show bridge
bridge VLAN port mac fwd timeout
1 64 eth2 0050.8b01.b349 1 10
When authentication fails, the source MAC is added to a restricted VLAN (VLAN 64).
