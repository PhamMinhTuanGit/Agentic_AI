Label Distribution Protocol Developer Guide : CHAPTER 9 LDP API : ldp_api_set_loop_detect_hop_limit
  
ldp_api_set_loop_detect_hop_limit
This call sets the LDP loop-detect hop limit for all LDP entities.
Syntax
int
ldp_api_set_loop_detect_hop_limit (struct ldp *ldp,
u_int32_t val, u_char count)
Input Parameters
ldp
LDP instance
val
LDP hop-count limit
count
LDP loop-detection count flag. The allowed values include the following:
LDP_LOOP_DETECTION_COUNT_SET(1)
LDP_LOOP_DETECTION_COUNT_UNSET(0)
Output Parameters
None
Return Values
LDP_SUCCESS
LDP_ERROR
