isis_get_man_area_addr_state
This call gets the state of the manually configured area address.
Syntax
int isis_get_man_area_addr_state (u_int32_t vr_id, u_int32_t instance, struct isis_area_addr addr, u_int32_t *ret);
Input Parameters
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
indexlen
Length of the index.
Output Parameters
ret
State of the manually configured area address:
1
Active (default)
2
Not in service
3
Not ready
4
Create and go
5
Create and wait
6
Destroy
Return Values
ISIS_API_GET_SUCCESS for area address found in the specified instance.
ISIS_API_GET_ERROR for area address not found in the specified instance.
