Label Distribution Protocol Developer Guide : CHAPTER 11 LDP MIBs API : ldp_snmp_api_get_adjacency
  
ldp_snmp_api_get_adjacency
This call gets the adjacency.
Syntax
static int
ldp_snmp_api_get_adjacency_node (struct ldp *ldp,
struct ldp_id *peer_id,
u_int32_t indx,
struct listnode **ses_node,
struct listnode **adj_node)
Input Parameters
ldp
LDP instance
*peer_id
LDP peer ID
indx
LDP index
Output Parameters
ses_node
LDP session
adj_type
Adjacent session type; it can be either Leaf_mplsLdpHelloAdjType_link or Leaf_mplsLdpHelloAdjType_targeted
Return Values
LDP_SUCCESS
LDP_FALSE
