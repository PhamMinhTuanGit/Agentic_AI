System Management Command Reference : CHAPTER 6 Lightweight Directory Access Protocol : clear ldap-server statistics
  
clear ldap-server statistics
Use this command to reset the LDAP server statistics.
Command Syntax
clear ldap-server statistics (|HOST)
Parameters
HOST
Server host name, IPv4 address, or IPv6 address; if not specified, all hosts are displayed
Command Mode
Exec mode
Examples
#clear ldap-server statistics
