System Management Command Reference : CHAPTER 15 User Management : vlan policy deny
  
vlan policy deny
Use this command to deny all access to VLANs unless explicitly permitted. This command enters role VLAN mode.
Use the no form of this command to permit all access to VLANs.
Command Syntax
vlan policy deny
no vlan policy deny
Parameters
None
Command Mode
Role mode
Example
#configure terminal
(config)#role name Dearborn
(config-role)#vlan policy deny
(config-role-vlan)#
