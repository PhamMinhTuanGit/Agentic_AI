Multi-Protocol Label Switching Command Reference : CHAPTER 6 Unified L2VPN commands : vc-id
  
vc-id
Use this command to configure the VC Identifier for MPLS layer 2 virtual circuit.
Command Syntax
vc-id <1-4294967295>
Parameters
<1-4294967295>
Specify VC ID for MPLS Layer-2 Virtual Circuit
Command Mode
VPWS mode
Example
(config)#l2vpn-vpws vpws1
(config-vpws)#protocol ldp
(config-vpws)#vc-id 10
