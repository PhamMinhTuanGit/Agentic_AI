Network Services Module Command Reference : CHAPTER 5 Interface Commands : show interface switchport brief
  
show interface switchport brief
Use this command to display status of only L2 or switchport interfaces.
Command Syntax
show interface switchport brief
 
Parameters
brief
Brief summary of IP status and configuration.
Command Mode
Exec mode
Example
tr3-1#show interface switchport brief
-----------------------------------------------------------------------------
Ethernet VLAN Type Mode Status Reason Speed Port
Interface Ch #
-----------------------------------------------------------------------------
