g8032_api_erp_inst_admin_cmd
This function configures administrative commands.
This function implements the force-switch|manual-switch command.
Syntax
s_int32_t
g8032_api_erp_inst_admin_cmd (struct g8032_erps_instance *inst,
enum g8032_admin_cmd cmd,
u_int32_t is_east)
Input Parameters
inst
ERP instance
cmd
Role; one of these constants from the g8032_admin_cmd enum in onmd/cfm/g8032v2/g8032_api.h:
G8032_ADMIN_CMD_FS
 
Forcefully block a ring port
G8032_ADMIN_CMD_MS
 
Manually block a ring port
G8032_ADMIN_CMD_CLEAR
 
Cancel a command
is_east
Whether to apply the command to the east or west interface:
PAL_TRUE
Apply command to east interface
PAL_FALSE
Apply command to west interface
Output Parameters
None
Return Values
G8032_ERROR_NONE when the function succeeds
G8032_ERROR_ERPS_INST_NOT_FOUND when inst is NULL
