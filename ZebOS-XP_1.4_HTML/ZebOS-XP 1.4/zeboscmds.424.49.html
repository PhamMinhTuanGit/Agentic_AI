Network Services Module Command Reference : CHAPTER 5 Interface Commands : show ip vrf
  
show ip vrf
This command shows the routing information of the VRF.
Command Syntax
show ip vrf
show ip vrf WORD
Parameter
WORD
Displays a name used to identify a VRF.
Command Mode
Exec mode and Privileged Exec mode
Example
#show ip vrf IPI
VRF IPI; (id=1); default RD 1:2
Interfaces:
eth2
Export VPN route-target communities
RT:100:1
Import VPN route-target communities
RT:100:1
No import route-map
