bridge loop-prevention
Use this command to enable or disable loop prevention.
Command Syntax
bridge (<1-32> | backbone) loop-prevention (enable|disable)
Parameters
<1-32>
Bridge identifier.
backbone
Backbone bridge.
enable
Enable loop prevention.
disable
Disable loop prevention.
Default
The default is that loop prevention is disabled.
Command Mode
SPB mode
Example
(spb-config)#bridge 1 loop-prevention enable
