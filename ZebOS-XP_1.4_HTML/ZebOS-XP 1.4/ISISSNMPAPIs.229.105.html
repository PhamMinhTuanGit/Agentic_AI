isis_set_circ_3way_enabled
This call gets the status of this circuit enabled 3Way handshake.
Syntax
int isis_set_circ_3way_enabled (u_int32_t vr_id, u_int32_t instance, u_int32_t circindex, u_int32_t val);
Input Parameter
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
circindex
IS-IS circuit index.
val
Status of the circuit enabled 3Way handshake.
1
isisTruthValueTrue
2
isisTruthValueFalse (default)
Output Parameters
None
Return Value
ISIS_API_SET_SUCCESS for set complete.
ISIS_API_SET_ERROR for set not complete; e.g., supported circuit index not found in the specified instance.
