show ipv6 isis route
Use this command to display the IS-IS routing table for IPv6.
Command Syntax
show ipv6 isis (WORD|) route
Parameters
WORD
Display information for specified instance.
Command Mode
Exec mode, Privileged exec mode
Example
#show ipv6 isis route
Codes: C - connected, L1 - IS-IS level-1, L2 - IS-IS level-2
ia - IS-IS inter area, D - discard, E - external metric
Area ipi:
C 3ffe:1234:1::/48 [10]
via ::, eth0
C 3ffe:1234:2::/48 [10]
via ::, eth0
C 3ffe:1234:3::/48 [10]
via ::, eth0
L1 3ffe:5678:3::/48 [20]
via fe80::203:47ff:fe4c:776e, eth0
L1 3ffe:5678:101::/48 [20]
