nsm_mpls_rib_if_down_process
This function is called when an interface goes down.
Syntax
void
nsm_mpls_rib_if_down_process (struct interface *ifp)
Input Parameters
ifp
Pointer to the interface
Output Parameters
None
Return Value
PAL_TRUE when the function succeeds
PAL_FALSE when the function fails
