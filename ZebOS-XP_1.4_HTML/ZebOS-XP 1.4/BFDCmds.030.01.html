CHAPTER 2 Bidirectional Forwarding Commands
This chapter includes the commands used to configure and manage the BFD base module in a network. It includes the following commands:
• bfd auth type
• bfd disable
• bfd echo
• bfd echo interval
• bfd gtsm
• bfd gtsm ttl
• bfd interval
• bfd multihop-peer
• bfd multihop-peer A.B.C.D
• bfd multihop-peer X:X::X:X
• bfd notification
• bfd session
• bfd slow-timer
• debug bfd
• key
• key chain
• send-lifetime
• show bfd
• show bfd interface
• show bfd session
• show bfd session A.B.C.D
• show bfd session ipv6
• show debugging bfd
• snmp restart bfd
