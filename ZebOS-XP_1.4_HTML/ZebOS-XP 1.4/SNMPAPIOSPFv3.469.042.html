Open Shortest Path First Developer Guide : CHAPTER 15 OSPFv3 SNMP API : Functions : ospf6_get_if_type
  
ospf6_get_if_type
This function gets the interface type of the given OSPFv3 interface.
Syntax
int
ospf6_get_if_type (char *tag, int ifindex, int instid, int *ret);
Input Parameters
tag
OSPFv3 process tag
ifindex
Interface index
instid
Instance identifier
Output Parameters
ret
Interface types:
1
Broadcast
2
Non-broadcast multi-access (NBMA)
3
Point-to-Point
5
Point-to-Multipoint
Return Values
OSPF6_API_GET_ERROR when the function fails
OSPF6_API_GET_SUCCESS when the function succeeds
