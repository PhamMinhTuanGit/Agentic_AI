Open Shortest Path First Command Reference : CHAPTER 3 OSPFv3 Commands : auto-cost reference bandwidth
  
auto-cost reference bandwidth
Use this command to control how OSPFv3 calculates default metrics for the interface.
By default, OSPFv3 calculates the OSPFv3 metric for an interface by dividing the reference bandwidth by the interface bandwidth. The default value for the reference bandwidth is 100Mbps. The auto-cost command is used to differentiate high bandwidth links. For multiple links with high bandwidth, specify a larger reference bandwidth value to differentiate cost on those links.
Use the no form of this command to assign cost based only on the interface bandwidth.
Command Syntax
auto-cost reference-bandwidth <1-4294967>
no auto-cost reference-bandwidth
Parameters
<1-4294967>
The reference bandwidth in Mbps per second. The default is 100 Mbps.
Command Mode
Router mode
Default
100 Mbps
Examples
This example changes the reference bandwidth to 1Gbps to change the Fast Ethernet interface cost from 1 to 10.
#configure terminal
(config)#router ipv6 ospf 1
(config-router)#auto-cost reference-bandwidth 1000
 
(config)#router ipv6 ospf 1
(config-router)#no auto-cost reference-bandwidth
