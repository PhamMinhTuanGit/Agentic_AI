Carrier Ethernet Command Reference : CHAPTER 8 Provider Bridging Commands : vlan state
  
vlan state
Use this command enables or disables a VLAN on the default bridge.
Note: Provider Backbone Bridging is not supported for ZebIC releases.
Command Syntax
vlan <2-4094> state (enable|disable)
Parameters
vlan
The VLAN
<2-4094>
The VLAN ID
state
Operational state of the VLAN
enable
Forward frames on the bridge
disable
Do not forward frames on the bridge
Command Mode
VLAN configuration mode
Examples
#configure terminal
(config)#vlan database
(config-vlan)#vlan 12 state disable
