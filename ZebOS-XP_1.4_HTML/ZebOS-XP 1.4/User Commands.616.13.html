System Management Command Reference : CHAPTER 15 User Management : role name
  
role name
Use this command to create a role and enter role mode.
For each user role, you give the rule command to define the operations allowed for a user who is assigned the role. Each user role can contain multiple rules and each user can have multiple roles.
Use the no form of this command to remove a role.
Command Syntax
role name WORD
no role name WORD
Parameters
WORD
Role name; maximum length 16 characters
Command Mode
Configure mode
Examples
#configure terminal
(config)#role name Dearborn
(config-role)#
