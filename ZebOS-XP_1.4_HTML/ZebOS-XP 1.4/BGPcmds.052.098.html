Border Gateway Protocol Command Reference : CHAPTER 2 BGP Commands : neighbor peer-group
  
neighbor peer-group
Use this command to add a neighbor to an existing peer group. Neighbors with the same update policies are grouped into peer groups. This facilitates the updates of various policies, such as distribute and filter lists. The peer group is then configured easily with any of the neighbor commands. Any changes made to the peer group affect all members. To create a peer group, use the neighbor WORD peer-group command, and then use this command to add neighbors to the group.
Use the no parameter with this command to remove a neighbor from a named peer group.
Command Syntax
neighbor (A.B.C.D|X:X::X:X|WORD) peer-group WORD
no neighbor (A.B.C.D|X:X::X:X|WORD) peer-group WORD
Parameters
A.B.C.D
Address of the BGP neighbor in an IPv4 format
X:X::X:X
Address of the BGP neighbor in an IPv6 format
WORD
Name of the BGP peer group
WORD
Peer group name
Command Mode
Router mode
Example
#configure terminal
(config)#router bgp 10
(config-router)#neighbor group1 peer-group
