Bidirectional Forwarding Detection Command Reference : CHAPTER 3 Protocol Commands for BFD : debug ospf bfd
  
debug ospf bfd
Use this command to debug BFD processes in OSPF.
Use the no form of the command to stop debugging.
Command Syntax
debug ospf bfd
no debug ospf bfd
undebug ospf bfd
Parameters
None
Command Mode
Configure mode
Example
#configure terminal
(config)#debug ospf bfd
