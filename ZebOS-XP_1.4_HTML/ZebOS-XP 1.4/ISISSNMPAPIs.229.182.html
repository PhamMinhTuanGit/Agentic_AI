isis_get_circ_num_adj
This call gets the number of adjacencies on this circuit.
Syntax
int isis_get_circ_adj_changes (u_int32_t vr_id, u_int32_t instance, u_int32_t circindex, u_int32_t circtype, u_int32_t *ret);
Input Parameter
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
circindex
IS-IS circuit index.
circtype
IS-IS circuit type.
Output Parameters
ret
Number of adjacencies.
Return Value
ISIS_API_GET_SUCCESS for supported circuit type found in the specified circuit index.
ISIS_API_GET_ERROR for supported circuit type not found in the specified circuit index.
