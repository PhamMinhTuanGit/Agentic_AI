Carrier Ethernet Developer Guide : CHAPTER 13 User Network Interface : Command API
  
Command API
The functions in this section are called by the commands in the Carrier Ethernet Command Reference.
 
Function
Description
nsm_bridge_api_port_proto_process
Configures the protocol handling on a customer edge/customer network port
nsm_bridge_uni_set_name
Deletes the name of an UNI
nsm_bridge_uni_type_detect
Enables or disables the UNI type mode for an interface
nsm_bridge_uni_unset_name
Removes the name of an UNI
