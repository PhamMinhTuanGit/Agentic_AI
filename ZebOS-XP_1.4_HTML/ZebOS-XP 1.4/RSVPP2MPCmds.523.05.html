RSVP-TE Command Reference : CHAPTER 7 Point-to-Multipoint Commands : clear rsvp p2mp-session
  
clear rsvp p2mp-session
Use this command to clear a P2MP RSVP session.
Command Syntax
clear rsvp p2mp-session P2MP-ID TUNNEL-ID EXT-ID LSP-ID INGRESS EGRES
Parameters
P2MP-ID
P2MP ID of the session
TUNNEL-ID
Tunnel ID of the session
EXT-ID
Extended tunnel ID of the session
LSP-ID
LSP ID of the session
INGRESS
Ingress of the session
EGRESS
Egress of the session
Command Mode
Privileged Exec and Exec modes
Example
#clear rsvp p2mp-session 101 101 1.1.1.1 102 1.1.1.1 4.4.4.4
#
