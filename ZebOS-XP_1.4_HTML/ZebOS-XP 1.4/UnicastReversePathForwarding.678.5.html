Strict uRPF for IPv4
When administrators use Unicast RPF in strict mode, the packet must be received on the interface that the router would use to forward the return packet. Unicast RPF configured in strict mode may drop legitimate traffic that is received on an interface that was not the router's choice for sending return traffic.
Figure 15-128: Strict uRPF for IPv4

# configure terminal
Enter Configure mode.
(config)# interface eth1
Specify the interface (eth1) to configure.
(config-if)# ip address 10.10.12.1/24
Set the IP address of the eth1 interface.
(config-if)# ip verify unicast source reachable-via rx
Configure strict uRPF on eth1 of R1.
(config-if)# interface eth2
Specify the interface (eth2) to configure.
(config-if)# ip address 10.11.12.1/24
Set the IP address of the eth2 interface.
(config-if)# ip verify unicast source reachable-via rx
Configure strict uRPF on eth2 of R1.
(config-if)# interface lo
Specify the interface (loopback) to configure.
(config-if)# ip address 1.1.1.1/24
Set the IP address of the loopback interface.
(config-if)# exit
Exit Interface mode, and enter Configure mode.
(config)# ip route 2.2.2.0 255.255.255.0 10.10.12.2
Configure static route to reach loopback interface of R2 with next-hop as eth1 of R2.
