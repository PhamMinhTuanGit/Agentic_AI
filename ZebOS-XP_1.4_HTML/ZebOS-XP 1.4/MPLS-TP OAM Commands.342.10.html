Multi-Protocol Label Switching Command Reference : CHAPTER 8 MPLS-TP OAM Commands : exit-mp
  
exit-mp
Use this command to exit ITUT MP mode and return to ITUT MEG mode.
Command Syntax
exit-mp
Parameters
None
Command Mode
ITUT MP mode
Examples
#configure terminal
(config)#itut meg new12 level 1
(config-itut-meg)#mip-id 12
(config-itut-mp)#rmep-id 1 cc US icc 123456 umc new fwd
(config-itut-mp)#exit-mp
(config-itut-meg)#
