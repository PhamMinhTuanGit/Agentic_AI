Integrated Management Interface Command Reference : CHAPTER 2 Common IMI Commands : line console
  
line console
Use the line console command to move or change to the line console mode.
Use the no parameter to disable this command.
Command Syntax
line console <0-0>
Parameters
<0-0>
Specify the first line number.
Command Mode
Configure mode
Example
The following example shows the use of the line command to enter the Line command mode (note the change in the prompt).
#configure terminal
(config)#line console 0
(config-line)#
