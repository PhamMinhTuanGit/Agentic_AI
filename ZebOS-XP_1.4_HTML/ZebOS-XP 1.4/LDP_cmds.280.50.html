Label Distribution Protocol Command Reference : CHAPTER 2 LDP Commands : neighbor
  
neighbor
Use this command to configure neighbors of LDP.
Use the no parameter with this command to unconfigure the LDP neighbor
Command Syntax
neigh bor (A.B.C.D | WORD | X:X::X:X) auth md5 password <0-7> WORD
no multicast-hellos
Parameters
A.B.C.D
Neighbor address
WORD
Neighbor tag
X:X::X:X
Neighbor IPv6 address
<0-7>
Password Type
WORD
Password
Command Mode
Router mode
Example
#configure terminal
(config)#router ldp
(config-router)#neighbor 1.1.1.1 auth md5 password 0 ipi
