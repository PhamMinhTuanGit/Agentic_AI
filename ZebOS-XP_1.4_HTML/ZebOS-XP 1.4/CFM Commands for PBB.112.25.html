Carrier Ethernet Command Reference : CHAPTER 10 Provider Backbone Bridging CFM Commands : out-of-service
  
out-of-service
Use this command to enable out-of-service testing.
Command Syntax
out-of-service lck-level <0-7> testing
Parameters
lck-level
The level at which LCK frames should be sent.
Command Mode
Ethernet CFM PBB MEP configuration mode
Examples
(config-cfm-pbb-mep)#out-of-service lck-level 4 testing
(config-cfm-pbb-mep)#out-of-service lck-level 2 testing
