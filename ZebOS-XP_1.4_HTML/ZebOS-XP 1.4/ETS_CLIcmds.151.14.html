Data Center Bridging Command Reference : CHAPTER 2 Enhanced Transmission Selection Commands : max-traffic-class-group
  
max-traffic-class-group
Use this command to configure the maximum number of traffic classes that you can enable on ETS.
Use the no form of this command to set the maximum number of traffic classes to 0 which is the default.
If the value is 0, you can add priorities for all 8 traffic classes with the traffic-class-group command. When the number of traffic classes is not 0, you can add priorities with the traffic-class-group command until the maximum is reached.
Command Syntax
max-traffic-class-group <0-7>
For ZebIC:
max-traffic-class-group <0-2>
no max-traffic-class-group
Parameters
<0-7>
The maximum number of traffic class groups.
For ZebIC:
<0-2>
The maximum number of traffic class groups.
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth1
(config-if)#max-traffic-class-group 2
(config-if)#
