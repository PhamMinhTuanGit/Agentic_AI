Carrier Ethernet Command Reference : CHAPTER 2 Ethernet CFM Commands : clear ethernet cfm traceroute-cache
  
clear ethernet cfm traceroute-cache
Use this command to clear the CFM errors logged in a named domain or on a targeted device.
Command Syntax
clear ethernet cfm traceroute-cache (bridge <1-32>|)
Parameter
bridge
 
Bridge.
<1-32>
Bridge ID.
Command Mode
Exec Mode and Privileged Exec Mode
Example
>clear ethernet cfm traceroute-cache bridge 1
