Layer 2 Command Reference : CHAPTER 13 VLAN and Private VLAN Commands : show vlan brief
  
show vlan brief
Use this command to display brief VLAN information for all bridges, either static or dynamic.
Command Syntax
show vlan (brief | <2-4094>)
Parameters
None
Command Mode
Exec mode and Privileged Exec mode
Example
The following is a sample output from this command when using the all parameter.
#show vlan brief
Bridge Group : 1
 
Bridge VLAN ID Name State Member ports
(u)-Untagged, (t)-Tagged
=============== ======= ================ ======= ===============================
1 1 default ACTIVE eth2(u)
 
Bridge Group : 0
 
0 1 default ACTIVE
0 2 new ACTIVE
