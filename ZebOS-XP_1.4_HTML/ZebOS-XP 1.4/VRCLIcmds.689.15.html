Virtual Routing Command Reference : CHAPTER 2 Virtual Routing Commands : virtual-router
  
virtual-router
The Global administrator executes this command to create a new virtual router and to configure VR parameters.
Commands that appear in VR mode set startup parameters for the virtual router prior. Only some of these commands can be executed once the VR has been loaded.
Use the no parameter with this command to disable the specified virtual router.
Command Syntax
virtual-router WORD
no virtual-router WORD
Parameters
WORD
Specify the name of the VR.
Command Mode
Configure mode
Example
#router
(config)#virtual-router VR1
(config-vr)#
