ipsec_match_address
This function sets the access list ID to Cryptographic Map.
Syntax
s_int32_t
ipsec_match_address (struct cli *cli, struct ipsec_crypto_map *crypto_map,
char *access_list_id, afi_t afi,
u_char type)
Input Parameters
cli
CLI tree.
crypto_map
Cryptographic map, used to setup IPsec SA.
access_list_id
Access list ID.
afi
Address family.
type
Security Association Database (SADB) type.
Output Parameters
None
Return Values
IPSEC_API_SUCCESS when the function is successful.
IPSEC_API_ERROR when there is an error.
