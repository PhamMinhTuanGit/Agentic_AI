Layer 2 Command Reference : CHAPTER 6 802.1x Commands : radius-server key
  
radius-server key
Use this command to set the shared secret key between a Radius server and a client.
Use the no form of the command to undo this configuration.
Command Syntax
radius-server key KEY
no radius-server key
Parameter
KEY
Specify the secret key shared among the radius server and the 802.1x client.
Command Mode
Configure mode
Examples
#configure terminal
(config)#radius-server key ipi
 
#configure terminal
(config)#no radius-server key
