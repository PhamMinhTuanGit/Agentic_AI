send_announce
This function sends a PTP announce message.
Syntax
#include "ptpd/ptp_utils.h"
void
send_announce (struct ptp_clock *clock, struct ptp_port_clock *port_data,
int send)
Input Parameters
clock
A pointer to the clock
port_data
Pointer to PTP clock port
send
Whether to send the message immediately
Output Parameters
None
Return Values
None
