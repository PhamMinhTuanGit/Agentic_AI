Layer 2 Command Reference : CHAPTER 8 Multi-Chassis Link Aggregation Commands : mlag
  
mlag
Use this command to assign an MC-LAG identifier to an interface. Only one interface can be bound to an MC-LAG instance.
Note: The interface must be a dynamic port channel.
Use the no form of this command to unassign an MC-LAG identifier from an interface.
Command Syntax
mlag <1-65535>
no mlag
Parameters
<1-65535>
MC-LAG identifier
Command Mode
Interface mode
Example
#config terminal
(config)#interface po1
(config-if)#mlag 1
