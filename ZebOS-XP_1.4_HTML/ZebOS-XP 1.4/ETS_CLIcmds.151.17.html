Data Center Bridging Command Reference : CHAPTER 2 Enhanced Transmission Selection Commands : show data-center-bridging
  
show data-center-bridging
Use this command to display administrative, operational, and remote parameters for DCBX.
Command Syntax
show data-center-bridging (admin-details | operational-details | remote-details) interface IFNAME
Parameter
admin-details
Administrative details.
operational-details
 
Operational details.
remote-details
Remote details.
interface
Interface.
IFNAME
Name of the interface.
Command Mode
Exec mode
Example 1
#show data-center-bridging operational-details interface eth1
