Hybrid Switch Router Configurations
With only Layer 2 protocols configured, the ZebOS-XP Hybrid Switch Router can become an absolute Layer 2 switch.
Figure 1-1: Layer 2 Switch
With Layer 2 and Layer 3 protocols configured, the ZebOS-XP Hybrid Switch Router can become a Switch or/and a Router.
Figure 1-2: Working as a Router or a Switch
With only Layer 3 protocols enabled, the ZebOS-XP Hybrid Switch Router can become an absolute router.
Figure 1-3: Working as Layer 3 Router
On switch ports, VLANs can be created for different broadcast domains.
Figure 1-4: Port- or Policy-based VLANs
For routing between VLANs, the ZebOS-XP routing protocols or static routing via NSM can be utilized.
Figure 1-5: Routing Between VLANs
For routing between VLANs and other routing ports, ZebOS-XP routing protocols or static routing via NSM can be utilized.
Figure 1-6: Routing Between VLANs and Routing Ports
