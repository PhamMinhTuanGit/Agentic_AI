Layer 2 Command Reference : CHAPTER 6 802.1x Commands : auth-mac enable
  
auth-mac enable
Use this command to enable MAC authentication on an interface. See the auth-mac disable command to disable MAC authentication on an interface.
Command Syntax
auth-mac enable
auth-mac enable mode (filter|shutdown)
Parameters
mode
Use this parameter to enable the MAC authentication mode on an interface.
filter
Filter the frames for the MAC when in an unauthorized state.
shutdown
Shut down the interface when the MAC is unauthenticated.
Command Mode
Interface mode
Example
#configure terminal
(config)#interface eth0
(config-if)#auth-mac enable
 
#configure terminal
(config)#interface eth0
(config-if)#auth-mac enable mode filter
 
(config)#interface eth0
(config-if)#auth-mac enable mode shutdown
