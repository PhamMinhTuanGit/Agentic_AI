Carrier Ethernet Command Reference : CHAPTER 5 Link Layer Discovery Protocol v2 Commands : show lldp debugging
  
show lldp debugging
Use this command to display LLDP debugging information.
Command Syntax
show debugging lldp
Parameters
None
Command Mode
Exec mode and Privileged Exec mode
Example
The following sample output displays information about an LLDP debugging.
#show debugging lldp
LLDP debugging status:
LLDP message debugging is on
