trill_get_rbridge_unifib_macaddress
This call gets the MAC address of the next-hop RBridge for the path towards the RBridge, whose nickname is specified by the next entry.
Syntax
int
trill_get_rbridge_unifib_macaddress (u_int32_t vr_id, u_int32_t instance,
u_int16_t nickname, u_int32_t port,
u_char **ret)
Input Parameters
vr_id
An integer that contains the TRILL VR identifier.
instance
An integer that contains the TRILL instance ID.
nickname
An RBridge nickname for which this RBridge has forwarding information.
port
Port number of the port attached to the next-hop bridge.
indexlen
An Integer variable that contains the length of the index
Output Parameters
ret
MAC address of the next-hop RBridge for the path towards the next RBridge.
Return Value
TRILL_API_GET_SUCCESS for valid Instance ID, Nickname and Port.
TRILL_API_GET_ERROR for valid Instance ID, Nickname and Port not found.
