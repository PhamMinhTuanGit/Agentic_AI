Carrier Ethernet Command Reference : CHAPTER 9 Provider Backbone Bridging Commands : switchport beb customer-network svlan
  
switchport beb customer-network svlan
These commands set the switching characteristics of a Layer 2 customer-facing interface to an SVLAN-aware interface.
BEB identifies the interface as a BEB (Backbone Edge Bridge). Single, bundled, and all S-VLAN modes are supported by these commands. The port being configured is a customer-network port, so the VLAN ID must be a service VLAN (I-SID).
Use the no form of this command to delete an S-VLAN to service instance mapping on this interface.
Note: The configuration information for this command is kept in NSM internally. Dispatch to forwarding plane hardware via PAL only takes place when you give the switchport dispatch instance command.
Command Syntax
switchport beb customer-network svlan all (instance <1-16777214>| name INSTANCE_NAME)
switchport beb customer-network svlan all (instance <1-16777214>| name INSTANCE_NAME) egress-port IFNAME
switchport beb customer-network svlan add (range <2-4094> <2-4094> | <2-4094>) (instance <1-1677214> |name INSTANCE_NAME)
switchport beb customer-network svlan add (range <2-4094> <2-4094> | <2-4094>) (instance <1-16777214>| name INSTANCE_NAME) egress-port IFNAME
switchport beb customer-network svlan remove (range <2-4094> <2-4094> | <2-4094>) (instance <1-1677214>| name INSTANCE_NAME)
no switchport beb customer-network svlan (instance <1-16777214>|name INSTANCE_NAME)
Parameters
all
Allow all VLANs to transmit and receive through the Layer 2 Interface
add
Add a specific VLAN to the member set or a range of VLANs.
remove
Remove a specific VLAN from the member set or a range of VLANs.
instance
Service instance ID.
<1-16777214>
 
The service instance ID.
name
The service instance name.
INSTANCE_NAME
 
The service instance name.
egress-port
The egress PIP (Provider Instance Port).
IFNAME
Specify the name of the physical Provider Instance Port for this service instance.
range
Specify a range of VLAN IDs in a contiguous block.
<2-4094> <2-4094>
 
The beginning and end of a range of VLAN IDs.
<2-4094>
A specific VLAN ID.
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth0
(config-if)#switchport beb customer-network svlan add 2 instance 1
(config-if)#switchport beb customer-network svlan all instance 1
(config-if)#switchport beb customer-network svlan remove 2 instance 1
(config-if)#no switchport beb customer-network svlan instance 1
