Multi-Protocol Label Switching Command Reference : CHAPTER 8 MPLS-TP OAM Commands : 1dm
  
1dm
Use this command to enable one-way delay measurement for a Maintenance Entity Group End Point (MEP).
Use the no parameter with this command to disable one-way delay measurement.
Command Syntax
1dm ({interval <1-4> | test <0-4294967295>|data <1-1400>}|)
no 1dm
Parameters
<1-4>
Interval between delay measurement frames. The default is 1s.
1
1 second
2
10 seconds
3
1 minute
4
10 minutes
<0-4294967295>
 
Test identifier
<1-1400>
Number of characters to send.
Command Mode
ITUT MP configuration mode
Examples
#configure terminal
(config)#itut meg new12 level 1
(config-itut-meg)#mep-id 12
(config-itut-mp)#1dm interval 1 data 123
 
(config-itut-mp)#no 1dm
