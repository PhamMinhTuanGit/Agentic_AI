show mmrp machine
Use this command to display the state machine for MMRP, for the default bridge.
Command Syntax
show mmrp machine bridge BRIDGE_NAME
Parameters
BRIDGE_NAME
Bridge identifier.
Mode
Exec and Privileged Exec mode
Examples
The following sample output from this command displays the MMRP state machine information.
#show mmrp machine bridge 1
port = eth 2 VLAN = 1
applicant state[0] = LO registrar state[0] = MT
applicant state[1] = LO registrar state[1] = MT
