RSVP-TE Command Reference : CHAPTER 3 Fast Reroute Commands : from A.B.C.D
  
from A.B.C.D
Use this command to specify a “from” IPv4 address for tunnel ingress.
Use the no parameter with this command to remove an IPv4 address for tunnel egress.
Command Syntax
from A.B.C.D
no from A.B.C.D
no from
Parameters
None
Command Mode
Bypass mode
Examples
#configure terminal
(config)#rsvp-bypass b1
(config-bypass)#from 10.10.0.5
