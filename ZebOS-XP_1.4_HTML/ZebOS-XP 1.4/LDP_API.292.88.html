ldp_api_nsm_redistribute
This call selectively redistributes or flushes routes.
Syntax
void
ldp_api_nsm_redistribute (u_char type, u_char add)
Input Parameters
type
Route type:
IPI_ROUTE_DEFAULT
IPI_ROUTE_KERNEL
IPI_ROUTE_CONNECT
IPI_ROUTE_STATIC
IPI_ROUTE_RIP
IPI_ROUTE_RIPNG
IPI_ROUTE_OSPF
IPI_ROUTE_OSPF6
IPI_ROUTE_BGP
IPI_ROUTE_ISIS
add
Redistributes or flushes
Output Parameters
None
Return Values
None
