trill inhibition-time
Use this command to configure the inhibition time for the database port.
Use the no parameter with this command to reset this configuration to the default setting.
Command Syntax
trill inhibition-time <1-30>
no trill inhibition-time
Parameters
<1–30>
Specify the inhibition time in seconds.
Command Mode
Interface mode
Default
30 seconds
Examples
>enable
#configure terminal
(config)#interface eth1
(config-if)#trill inhibition-time 22
 
(config-if)#no trill inhibition-time
