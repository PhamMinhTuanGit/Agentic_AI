Carrier Ethernet Command Reference : CHAPTER 15 PBB-TE Force Commands : pbb-te manual-to-working
  
pbb-te manual-to-working
Use this command to switch to the working path.
Use the no form of the command to return the TESI to its original state.
Command Syntax
pbb-te manual-to-working
no pbb-te manual-to-working
Parameters
None
Command Mode
PBB-TE Configure switching mode
Example
#configure terminal
(config)#pbb-te configure switching cbp cbp1 eps-group 1
(pbb-te-config-switching)#pbb-te manual-to-working
(pbb-te-config-switching)#no pbb-te manual-to-working
