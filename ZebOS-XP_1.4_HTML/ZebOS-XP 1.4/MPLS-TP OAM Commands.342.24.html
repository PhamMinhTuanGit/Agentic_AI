Multi-Protocol Label Switching Command Reference : CHAPTER 8 MPLS-TP OAM Commands : mpls-tp bfd
  
mpls-tp bfd
Use this command to configure a BFD session for an MPLS transport path. The Maintenance Entity Group (MEG) name and Maintenance Entity (ME) name correspond to an MPLS transport path which can be a label-switched path (LSP) or pseudowire (PW).
Use the no parameter with this command to remove a BFD session for an LSP or PW.
Command Syntax
mpls-tp bfd (meg-name NAME me-name NAME) ({min-tx (0 | <50-4294967>)|min-rx (0 | <50-4294967>)| multiplier <2-255>}|)
no mpls-tp bfd (meg-name NAME me-name NAME)
Parameters
meg-name
MEG
NAME
MEG name: 1-48 characters
me-name
ME
NAME
ME name: 1-48 characters
min-tx
Minimum transmit interval
0
No transmission
<50-4294967>
 
Minimum transmit interval in milliseconds
min-rx
Minimum reception interval
0
No reception
<50-4294967>
 
Minimum reception interval in milliseconds
multiplier
Multiplier
<2-255>
Multiplier value
Defaults
The default minimum transmit interval is 1 second.
The default minimum reception interval is 1 second.
The default multiplier value is 5.
Command Mode
Configure mode
Examples
#configure terminal
(config)#mpls-tp bfd meg-name new me-name ne min-rx 50 min-tx 100 multiplier 2
 
(config)#no mpls-tp bfd
