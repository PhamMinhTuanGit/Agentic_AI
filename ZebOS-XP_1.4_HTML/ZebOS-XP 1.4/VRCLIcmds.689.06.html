Virtual Routing Command Reference : CHAPTER 2 Virtual Routing Commands : load IPv6
  
load IPv6
Use this command to load IPv6 protocol modules to a virtual router.
Use the no parameter with this command to remove the specified protocol module from the VR.
Command Syntax
load ipv6 (ospf|rip)
Parameters
ospf
Loads the OSPFv3 module to this VR for the IPv6 protocol module.
rip
Loads the RIPng module to this VR for the IPv6 protocol module.
Command Mode
VR mode
Examples
(config)#virtual-router VR1
(config-vr)#load ipv6 ospf
