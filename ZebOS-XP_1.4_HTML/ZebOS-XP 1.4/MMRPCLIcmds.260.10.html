Layer 2 Command Reference : CHAPTER 11 MMRP Commands : set port mmrp
  
set port mmrp
Use this command to enable or disable MMRP on a selected port, on all ports on a bridge, or on a particular VLAN of a port.
Command Syntax
set port mmrp disable (IF_NAME|all)
set port mmrp enable (IF_NAME|all)
set port mmrp disable IF_NAME vlan VLANID
set port mmrp enable IF_NAME vlan VLANID
Parameters
enable
Enables MMRP on a switch.
disable
Disables MMRP on a switch.
all
All ports added to recently configured bridge.
IF_NAME
Specify the name of the interface.
VLANID
VLAN identifier <1-4094>.
Default
This setting is disabled by default.
Command Mode
Configure mode
Examples
To disable MMRP on a selected interface on a bridge, use this command structure:
#configure terminal
(config)#set port mmrp disable eth1
To disable MMRP on all interfaces on a bridge, use this command structure:
#configure terminal
(config)#set port mmrp disable all
 
#configure terminal
(config)#set port mmrp disable eth1 vlan 4
