Segment Routing Command Reference : CHAPTER 2 Segment Routing Commands : prefix-sid value
  
prefix-sid value
Use this command to add a prefix segment identifier (SID) to the primary address of an interface. A SID corresponds to an MPLS label.
Note: You must configure a SID for each prefix on the interface manually the same as for configuring IP addresses.
Use the no form of this command to remove a SID.
Command Syntax
prefix-sid value <1024000-1048319>
no prefix-sid value <1024000-1048319>
Parameters
<1024000-1048319>
 
Segment identifier
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth0
(config-if)#prefix-sid value 1035555
