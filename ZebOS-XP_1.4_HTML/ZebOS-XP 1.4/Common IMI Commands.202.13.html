Integrated Management Interface Command Reference : CHAPTER 2 Common IMI Commands : service advanced-vty
  
service advanced-vty
Use this command to set multiple options to be listed when the Tab key is pressed after completing a command. This feature applies to commands with more than one option.
Use the no parameter to set no options to be listed when the Tab key is pressed, after completing a command.
Command Syntax
service advanced-vty
no service advanced-vty
Parameters
None
Command Mode
Configure mode
Examples
#configure terminal
(config)#service advanced-vty
