hal_dcb_enable_pfc_priority
This HAL API sends a HAL_MSG_DCB_PFC_ADD_PRI message to HSL to enable DCB-PFC in the hardware on a given interface. The message passes the Interface index, priority, and status.
Syntax
s_int32_t hal_dcb_enable_pfc_priority (char *bridge_name, s_int32_t ifindex, u_int8_t priority, bool_t status)
Input Parameters
ifindex
Interface index
bridge_name
Bridge name
Output Parameters
None
Return
HAL_SUCCESS
