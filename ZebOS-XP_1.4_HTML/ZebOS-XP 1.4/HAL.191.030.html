hal_arp_entry_refresh
This function refreshes ARP entries.
Syntax
int
hal_arp_entry_refresh (struct pal_in4_addr *ipaddr,
unsigned char *mac_addr,
u_int32_t ifindex)
Input Parameters
ipaddr
IP address.
mac_addr
MAC address.
ifindex
Interface index.
Output Parameters
None
Return Value
< 0 when function fails
HAL_SUCCESS when function succeeds.
