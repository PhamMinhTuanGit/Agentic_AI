onm_client_read_msg
This API is used to read message from ONM sever.
API
int
onm_client_read_msg (struct message_handler *mc,
struct message_entry *me,
pal_sock_handle_t sock);
Input Parameters
mc
Pointer to the NSM multicast structure.
me
Pointer to the NSM multicast-enabled structure.
Output Parameters
None
