SNMP APIs
This section contains the functions in SNMP APIs.
 
Function
Description
nsm_get_sys_desc
Gets the full name and version identification of the system
nsm_get_sys_location
Gets the physical location of the node
nsm_get_sys_name
gets the fully-qualified domain name of the nod
nsm_get_sys_oid
Gets the object identifier
nsm_get_sys_services
Gets the set of services that the system offers
nsm_get_sys_up_time
Returns the time since the network management portion of the system was initialized
