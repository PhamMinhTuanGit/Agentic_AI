Multi-Protocol Label Switching Configuration Guide : CHAPTER 5 RSVP-TE Point-to-Multipoint LSP : Establish Trunk Using Explicitly-Defined Path : R1 (Ingress Node)
  
R1 (Ingress Node)
RSVP-TE
 
#configure terminal
Enter configure mode.
(config)#rsvp-path P1
Create an RSVP Path P1 and enter the Path mode.
(config-path)#10.1.1.2 strict
Configure the explicit route path eth1 of R2 as a strict hop.
(config-path)#20.1.1.2 loose
Configure the explicit route path eth1 of R4 as a loose hop.
(config-path)#exit
Exit Path Mode.
(config)#rsvp-trunk T1 ipv4 p2mp
Create an RSVP trunk T1 and enter the Trunk mode.
(config-p2mp-trunk)#primary-lsp
Create a Primary P2MP LSP and enter the LSP mode.
(config-p2mp-lsp)#destination 4.4.4.4 path P1 no-cspf
Configure a P2MP destination for R4 (Bud) with specifying path P1 and no-cspf since CSPF is enabled by default.
(config-p2mp-lsp)#destination 5.5.5.5 path P1 cspf
Configure a P2MP destination for R5 (Egress1) and specify path P1 and cspf.
(config-p2mp-lsp)#exit
Exit P2MP LSP mode.
(config-p2mp-trunk)#exit
Exit P2MP Trunk mode.
