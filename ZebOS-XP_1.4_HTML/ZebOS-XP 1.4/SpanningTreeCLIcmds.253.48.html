spanning-tree acquire
Use this command to enable the default bridge to learn station location information for an instance. This helps in making forwarding decisions.
Use the no parameter with this command to disable learning.
Command Syntax
spanning-tree acquire
no spanning-tree acquire
Parameters
None
Default
Learning is enabled by default for all instances.
Command Mode
Configure mode
Examples
#configure terminal
(config)#spanning-tree acquire
