hal_ipv6_mc_vif_delete
This function deletes a VIF.
Syntax
int
hal_ipv6_mc_vif_delete (u_int32_t vif_index);
Input Parameters
index
VIF index
Output Parameters
None
Return Value
HAL_IPV6_MC_VIF_NOTEXISTS
HAL_IPV6_MC_VIF_MAX_EXCEEDED
< 0 when function fails
HAL_SUCCESS when function succeeds
