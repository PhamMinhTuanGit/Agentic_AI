CHAPTER 11 PBB-TE Configurations
The configurations in the chapter illustrate how to set up Provider Backbone Bridging Traffic Engineering with different network topologies. Examples are provided for Ethernet Switched Path, Automated Protection Switching, Unicast Connectivity Fault Management, and Multicast Connectivity Fault Management.
Note: Provider Backbone Bridging is not supported for ZebIC releases.
