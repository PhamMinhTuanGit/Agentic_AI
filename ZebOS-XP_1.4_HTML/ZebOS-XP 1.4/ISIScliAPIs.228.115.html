isis_spf_interval_set
This call implements the spf-interval-exp command to configure the minimum and maximum interval between SPF calculations.
Syntax
int isis_spf_interval_set (u_int32_t vr_id, char *tag, int level, u_int32_t min_delay, u_int32_t max_delay);
Input Parameters
vr_id
Virtual Router ID. Default value is 0. For non-VR implementation, pass 0 for vr_id.
tag
IS-IS instance tag
level
IS-IS instance level:
1
Level-1
2
Level-2
3
Both Level-1, Level-2
min_delay
Minimum delay between receiving a change to SPF calculation in milliseconds <0-2147483647>
max_delay
Maximum delay between receiving a change to SPF calculation in milliseconds <0-2147483647>
Output Parameters
None
Return Value
ISIS_API_SET_ERR_VR_NOT_EXIST if the VR does not exist.
ISIS_API_SET_ERR_INSTANCE_NOT_EXIST if IS-IS instance does not exist with given tag.
ISIS_API_SET_ERR_INVALID_IS_TYPE when given level is outside of the range.
ISIS_API_SET_ERR_INVALID_VALUE when given interval is outside of the range.
ISIS_API_SET_SUCCESS when the call is successful.
