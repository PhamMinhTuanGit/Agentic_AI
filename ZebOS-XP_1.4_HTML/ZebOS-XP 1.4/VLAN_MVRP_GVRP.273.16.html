Layer 2 Developer Guide : CHAPTER 8 VLAN Registration Protocol : API : gvrp_disable
  
gvrp_disable
This function disables GVRP.
Syntax
int
gvrp_disable (struct nsm_bridge_master *master,
char* bridge_name);
Input Parameters
master
Pointer to the NSM master.
bridge_name
Name of the bridge.
Output Parameters
None
Return Values
RESULT_OK when function succeeds.
RESULT_ERROR when function fails.
