Integrated Management Interface Command Reference : CHAPTER 3 IMI Shell Commands : ping
  
ping
Use the ping utility to query another host (send echo messages).
Command Syntax
ping WORD
ping ip WORD
ping ipv6 WORD (|IFNAME)
ping ipv6 WORD (|IFNAME) (vrf NAME|)
ping WORD (vrf NAME|)
Parameters
WORD
Specify the destination address or hostname. Use the A.B.C.D form for an IPv4 address. Use the x:x::x:x for an IPv6 address.
vrf
Specify the VPN routing/forwarding instance.
NAME
Specify the name if the VPN routing/forwarding instance.
ip
Specify the IP echo.
WORD
Specify the destination address or hostname. Use the A.B.C.D form to specify an IPv4 address.
ipv6
Specify the IP echo.
WORD
Specify the destination address or hostname. Use the x:x::x:x form to specify an IPv6 address.
IFNAME
Specify the name of the interface.
vrf
Specify the VPN routing/forwarding instance.
NAME
Specify the VPN routing/forwarding instance.
Command Mode
Privileged Exec mode
Examples
>enable
