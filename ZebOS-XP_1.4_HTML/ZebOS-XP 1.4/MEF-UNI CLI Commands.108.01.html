CHAPTER 6 MEF User Network Interface Commands
This chapter contains the commands used for the Metro Ethernet Forum User Network Interface (MEF UNI). It includes the following commands:
Note: MEF-UNNI is not supported for ZebIC releases.

• ethernet max-uni
• ethernet svlan evc-id
• ethernet uni
• ethernet uni id
• ethernet uni type
• l2protocol
• show ethernet uni bundling
• show ethernet uni evc
• show ethernet uni evc-id
• show ethernet uni list
• show ethernet uni max-evc
• show ethernet uni type
