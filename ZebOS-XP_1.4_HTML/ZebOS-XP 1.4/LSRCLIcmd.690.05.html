Virtual Routing Command Reference : CHAPTER 3 Logical Switch Router Commands : lsr-move
  
lsr-move
Used this command to specifies whether an interface can be moved from the default LSR to a non-default LSR.
Every interface by default can be moved.
Command Syntax
lsr-move (enable|disable)
Command Mode
Interface mode
Examples
(config)#interface p2p3
(config-if)#lsr-move enable
