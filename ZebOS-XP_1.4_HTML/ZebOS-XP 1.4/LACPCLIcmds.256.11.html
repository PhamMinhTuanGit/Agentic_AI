Layer 2 Command Reference : CHAPTER 7 Link Aggregation Control Protocol Commands : show debugging lacp
  
show debugging lacp
Use this command to display the status of the debugging of the LACP system.
Command Syntax
show debugging lacp
Parameters
None
Command Mode
Exec and Privileged Exec mode
Example
#show debugging lacp
 
LACP debugging status:
LACP timer debugging is on
