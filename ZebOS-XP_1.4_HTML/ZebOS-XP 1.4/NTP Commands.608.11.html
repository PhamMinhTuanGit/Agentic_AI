System Management Command Reference : CHAPTER 7 Network Time Protocol : ntp trusted-key
  
ntp trusted-key
Use this command to define a “trusted” authentication key. If a key is trusted, the device will synchronize with a system that specifies this key in its NTP packets.
Use the no option with this command to remove a trusted key.
Command Syntax
ntp trusted-key <1-65534>
no ntp trusted-key <1-65534>
Parameter
<1-65534>
Authentication key number
Command Mode
Configure mode
Example
#configure terminal
(config)#ntp trusted-key 234676
