Layer 2 Command Reference : CHAPTER 4 Spanning Tree Protocol Commands : show traffic-class-table
  
show traffic-class-table
Use this command to display the data in the traffic class table.
Command Syntax
show traffic-class-table interface IFNAME
Parameters
interface
Displays the interface name.
Command Mode
Exec mode and Privilege Exec mode
Example
The following is a sample output of this command displaying the traffic class table for interface eth1.
#show traffic-class-table interface eth1
