Carrier Ethernet Configuration Guide : CHAPTER 4 Link Layer Discovery Protocol Configuration : LLDP-MED : Validation
  
Validation
1. Verify the LLDP configurations on Machine A
#show running-config lldp
!
interface lo
lldp-agent
!
interface eth0
lldp-agent
!
interface eth1
set lldp med-devtype net-connect
lldp-agent
set lldp enable txrx
lldp tlv-select med media-capabilities
lldp tlv-select med network-policy
lldp tlv-select med location
lldp tlv-select med extended-power-via-mdi
lldp-agent non-TPMR-bridge
set lldp enable txrx
lldp tlv-select med media-capabilities
lldp tlv-select med network-policy
lldp tlv-select med location
lldp tlv-select med extended-power-via-mdi
lldp-agent customer-bridge
set lldp enable txrx
lldp tlv-select med media-capabilities
lldp tlv-select med network-policy
lldp tlv-select med location
