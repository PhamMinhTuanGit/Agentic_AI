Carrier Ethernet Command Reference : CHAPTER 6 MEF User Network Interface Commands : show ethernet uni list
  
show ethernet uni list
Use this command to show the UNIs associated with an EVC or SVLAN.
Command Syntax
show ethernet uni list (svlan SVLAN_ID | evc EVC_ID |) (bridge <1-32>|)
Parameters
svlan
Display the SVLAN for which the UNI list need to be displayed
SVLAN_ID
Specify the SVLAN ID.
evc
Display the EVC for which the UNI list need to be displayed
EVC_ID
Specify the EVC ID.
bridge
Specify a bridge.
<1-32>
Specify a bridge ID.
Command Mode
Executive mode
Example
#show ethernet uni list svlan SVLAN_ID bridge 1
