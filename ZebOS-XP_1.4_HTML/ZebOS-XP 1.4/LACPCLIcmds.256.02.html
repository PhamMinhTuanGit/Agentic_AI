Layer 2 Command Reference : CHAPTER 7 Link Aggregation Control Protocol Commands : channel-group mode
  
channel-group mode
Use this command to create a link aggregation group or to add an interface to an link aggregation group.
Use the no parameter with this command to remove an interface from a link aggregation group.
Command Syntax
channel-group <1-65535> mode (active|passive)
channel-group <1-16383> mode (active|passive)
no channel-group
Parameters
<1-65535>
Specify a channel group number (without DRNI).
<1-16383>
Specify a channel group number (with DRNI).
mode
Specify a channel mode.
active
Enable LACP negotiation.
passive
Disable LACP negotiation.
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth0
(config-if)#channel-group 4 mode active
 
#configure terminal
(config)#interface eht0
(config-if)#no channel-group
