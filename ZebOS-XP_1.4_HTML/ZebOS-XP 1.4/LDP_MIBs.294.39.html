Label Distribution Protocol Developer Guide : CHAPTER 11 LDP MIBs API : ldp_snmp_api_get_fec
  
ldp_snmp_api_get_fec
This call gets the FEC for the given index.
Syntax
int
ldp_snmp_api_get_fec (struct ldp *ldp, s_int32_t indx, struct ldp_fec **fec,
struct prefix *prefix, int *fec_type,
struct prefix **prefixptr)
Input Parameters
ldp
LDP instance
indx
FEC index
Output Parameters
fec
LDP FEC structure
fec_type
FEC type; the permitted values are 1 and 2.
prefix
IP address in prefix format
prefixptr
FEC prefix pointer
Return Values
LDP_SUCCESS
LDP_FALSE
