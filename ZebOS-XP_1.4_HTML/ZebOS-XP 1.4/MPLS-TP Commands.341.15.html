Multi-Protocol Label Switching Command Reference : CHAPTER 7 MPLS-TP Commands : tunnel-mode unidirectional
  
tunnel-mode unidirectional
Use this command to configure a unidirectional MPLS-TP tunnel.
Command Syntax
tunnel-mode unidirectional
Parameters
None
Command Mode
Tunnel mode
Examples
#configure terminal
(config)#mpls-tp tunnel 1 source 100 1.1.1.1 destination 100 3.3.3.3
(config-tnl)#tunnel-mode unidirectional
