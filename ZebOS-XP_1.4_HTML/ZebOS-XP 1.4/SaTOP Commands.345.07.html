Multi-Protocol Label Switching Command Reference : CHAPTER 11 SAToP Commands : show tdm interface
  
show tdm interface
Use this command to display TDM-related details.
Command Syntax
show tdm interface IFNAME
Parameters
IFNAME
Display the interface name.
Command Mode
Exec mode and Privileged Exec mode
Example
#show tdm interface tdm
tdm_name status type bitrate payload_bytes PW_id Control-word Buffer-size
tdm1 UP E1 1.544m 256 10 0x04544554 5 ms
