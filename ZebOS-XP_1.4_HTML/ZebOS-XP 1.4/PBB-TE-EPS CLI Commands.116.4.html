Carrier Ethernet Command Reference : CHAPTER 14 PBB-TE APS Commands : pbb-te aps-group
  
pbb-te aps-group
Use this command to create or delete a PBB-TE protection group with an Automatic Protection Switching (APS) ID. If the named APS ID does not already exist, it is created and associated with a working and a protection Traffic Engineering Service Instance (TESI). Once created, TESI protection group members cannot be changed. Rather, the APS group must be deleted and then re-created with new TESI member associations.
Use the no form of this command to remove an APS protection group.
Command Syntax
pbb-te aps-group APSID working-tesi TESID protection-tesi TESID
no pbb-te aps-group APSID
Parameters
aps-group
Automatic protection group
APS-ID
Automatic protection group ID <1-4094>. The APS group ID must to be unique per IB-BEB.
working-tesi
Specify the service instance ID.
TESID
Specify the service instance ID <1-42949675>.
Command Mode
Configure mode
Examples
#configure terminal
(config)#pbb-te aps-group 1 cbp cbp001 working-tesi 1 protection-tesi 2
(config)#no pbb-te aps-group 1
