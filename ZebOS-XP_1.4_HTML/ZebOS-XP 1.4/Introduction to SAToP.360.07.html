nsm_server_send_mpls_l2_circuit_add
Use this function to send the values of payload_bytes, bit_rate, tdm_options and other virtual circuit parameters. NSM sends these parameters to LDP using this function to help set up the pseudowire feature.
Syntax
s_int32_t
nsm_server_send_mpls_l2_circuit_add (struct nsm_master *nm,
struct nsm_server_entry *nse,
struct nsm_mpls_circuit *vc,
u_int16_t vc_type)
Input Parameters
*nm
A pointer to NSM master structure
*nse
Set the NSE pointer and size.
*vc
VC name
vc_type
Port used for a VC type
Output Parameters
None
Return Values
0
