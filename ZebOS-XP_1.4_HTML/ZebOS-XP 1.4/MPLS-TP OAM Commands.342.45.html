Multi-Protocol Label Switching Command Reference : CHAPTER 8 MPLS-TP OAM Commands : show mpls-tp cc meg
  
show mpls-tp cc meg
Use this command to display a continuity-check summary.
Command Syntax
show mpls-tp cc meg NAME (mp-id <1-8191>|)
Parameters
NAME
Maintenance Entity Group (MEG) name.
<1-8191>
Maintenance Entity Group End Point (MEP) identifier.
Command Mode
Exec mode and Privilege Exec mode
Examples
Output on x86 platform
#show mpls-tp cc meg NEW mp-id 123
MEG-Name : INAIRTEL/meg
MP-Id : 1
Oper status : Up
CCM-Interval : 4
Lowest alarm priority : 1
FNG alarm time : 2.5 seconds
FNG reset time : 10 seconds
All RMEPs are dead : True
RDI present : True
Fault identified : True
Fault : DefRemoteCCM
Diagnostic message : Not receiving CCM PDUs from at least
one of the configured RMEPs.
RMEP-Id : 2
RMEG-Name : INAIRTEL/meg
RMEP CCM defect : True
RMEP last RDI : Not Applicable

#show mpls-tp cc meg NEW mp-id 123
