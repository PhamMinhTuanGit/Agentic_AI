Shortest Path Bridging Command Reference : CHAPTER 3 SPB Show Commands : show isis-spb interface
  
show isis-spb interface
Use this command to display the ISIS-SPB interface status and configuration.
Command Syntax
show isis-spb interface (IFNAME | )
Parameters
IFNAME
Interface name.
Command Mode
Privileged Exec mode
Example
#show isis-spb interface eth1
 
interface: eth1
hello-multiplier: 3
hello-interval(sec): 10
lsp-interval(millisec): 33
retransmit-interval(sec): 5
