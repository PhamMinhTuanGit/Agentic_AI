Carrier Ethernet Command Reference : CHAPTER 12 PBB-TE CFM Commands : dmm
  
dmm
Use this command to configure two-way delay measurement (DMM) on a MEP.
Command Syntax
dmm (unicast (rmpid MEPID) | multicast) duration DURATION ((interval (1 | 2 | 3 | 4))|)
Parameters
unicast
Specify that unicast frames should be sent
rmpid
ID of the remote MEP for unicast frames
multicast
Specify that multicast frames should be sent
duration
Duration for which DMM should be observed in seconds <5-60>
interval
Set the transmission interval:
1
100 milliseconds
2
10 milliseconds
3
1 second
4
10 seconds
Command Mode
Ethernet CFM PBB-TE MEP configuration mode
Examples
(config-cfm-pbb-te-mep)#dmm multicast duration 5
