Enabling BFD Authentication for Single-hop for IPv4, Using Key-ID
In this example, the BFD session is configured between R1 and R2 using single key (using key-ID). Once the BFD session is up, the authentication is enabled on both the routers, with the authentication type as keyed-MD5. We can enable the authentication on BFD session using any one of the above mentioned authentication type, with the Identical authentication type on both side.
