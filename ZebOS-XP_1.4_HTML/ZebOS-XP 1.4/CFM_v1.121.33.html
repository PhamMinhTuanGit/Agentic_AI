Carrier Ethernet Command Reference : Appendix A CFM Version 1 Commands : ethernet cfm pbb mep
  
ethernet cfm pbb mep
Use this command to create a MEP on a PBB by identifying a VLAN or service instance ID within a selected domain.
Use the no form of this command to delete a MEP for a PBB in a specific domain.
Note: To create and configure a link-level MEP, or to remove one, do not enter a VLAN number in the command line.
Command Syntax
ethernet cfm pbb mep (down|up) mpid MEPID domain-name NAME
(((vlan VLAN_ID (local-vid VID|))| isid ISID) (cbp-service-domain isid ISID |)|) (bridge <1-32> | backbone)
no ethernet cfm pbb mep (down|up) mpid MEPID domain-name NAME
(((vlan VLAN_ID (local-vid VID|))| isid ISID) (cbp-service-domain isid ISID |)|) (bridge <1-32> | backbone)
Parameters
down
Set the MEP’s direction of flow to DOWN.
up
Set the MEP’s direction of flow to UP.
mpid
Identity of the source MEP.
domain-name
The name of the maintenance domain.
isid
An integer that identifies an associated service instance <1-16777214>.
cbp-service-domain
 
ISID for MEP at the CBP in a service domain
isid
Set how MEP handles the CBP ISIDs on the interface for the domain
vlan
An integer that identifies a VLAN
local-vid
Set the local vid for the mep, should be a secondary vid for the MA
VID
Enter the local-vid for the mep
cbp-service-domain
 
ISID for MEP at the CBP in a service domain
backbone
Identifies the bridge as a backbone.
bridge
An integer in this range that identifies a bridge <1-32>.
Command Mode
Interface mode
Examples
(config)#interface eth1
(config-if)#ethernet cfm pbb mep down mpid 23 domain-name abc bridge 1
 
(config-if)#ethernet cfm pbb mep down mpid 23 domain-name abc vlan 3 backbone
 
(config-if)#ethernet cfm pbb mep up mpid 2 domain-name ab isid 3 bridge 1
