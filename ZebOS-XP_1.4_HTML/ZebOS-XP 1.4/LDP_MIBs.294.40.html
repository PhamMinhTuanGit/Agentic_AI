Label Distribution Protocol Developer Guide : CHAPTER 11 LDP MIBs API : ldp_snmp_api_getnext_fec
  
ldp_snmp_api_getnext_fec
This call gets the next FEC structure in the route table.
Syntax
struct ldp_fec *
ldp_snmp_api_getnext_fec (struct ldp *ldp, s_int32_t* indx,
struct prefix* prefix, int *fec_type)
Input Parameters
ldp
LDP instance
indx
FEC index
Output Parameters
indx
Next FEC index
prefix
IP address in prefix format
fec_type
FEC type; the permitted values are 1 and 2
Return Values
LDP FEC
NULL
