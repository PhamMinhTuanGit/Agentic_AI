Platform Integration Developer Guide : CHAPTER 2 Hardware Abstraction Layer : IPv6 API : hal_ipv6_mc_vif_add
  
hal_ipv6_mc_vif_add
This function creates a VIF.
Syntax
int
hal_ipv6_mc_vif_add (u_int32_t vif_index, u_int32_t phy_ifindex,
u_int16_t flags)
Input Parameters
vif_index
VIF index
phy_index
Physical Interface index
flags
VIF type
Output Parameters
None
Return Value
HAL_IPV6_MC_VIF_EXISTS
< 0 when function fails
HAL_SUCCESS when function succeeds
