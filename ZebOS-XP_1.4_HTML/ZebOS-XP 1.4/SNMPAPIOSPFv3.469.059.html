ospf6_get_nbr_state
This function gets the state of the relationship of the given router with the neighbor.
Syntax
int
ospf6_get_nbr_state (char *tag, int ifindex, int instid,
struct pal_in4_addr router_id, int *ret);
Input Parameters
tag
OSPFv3 process tag
ifindex
Interface index
instid
Instance identifier
router_id
Router identifier of the originating router
Output Parameters
ret
State of the relationship with this neighbor:
1
down
2
attempt
3
init
4
TwoWay
5
exchangeStart
6
exchange
7
loading
8
full
Return Values
OSPF6_API_GET_ERROR when the function fails
OSPF6_API_GET_SUCCESS when the function succeeds
