pim6_api_df_offer_interval_set
This function configures the interval for a Designated Forwarder (DF) Offer Message.
Syntax
int
pim6_api_df_offer_interval_set (u_int32_t vr_id, vrf_id_t vrf_id,
u_int32_t val);
Input Parameters
vr_id
Virtual router ID (0-255)
vrf_id
VPN Routing/Forwarding Instance ID
val
Value of the DF offer interval
Output Parameters
None
Return Values
PIM_API_SET_ERR_WRONG_VR when PIM Master is not found
PIM_API_SET_ERR_WRONG_VRF when PIM VRF interface is not found
PIM_API_SUCCESS when the function executes properly
