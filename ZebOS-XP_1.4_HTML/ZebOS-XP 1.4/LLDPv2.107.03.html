Carrier Ethernet Command Reference : CHAPTER 5 Link Layer Discovery Protocol v2 Commands : lldp agent
  
lldp agent
Use this command to create an LLDP agent mode.
Use the no parameter to revert to default settings.
Command Syntax
lldp-agent (non-tmpr-bridge |customer-bridge| )
no lldp-agent (non-tmpr-bridge |customer-bridge| )
Parameters
non-tmpr-bridge
 
non-tpmr-bridge
customer-bridge
 
customer-bridge
Default
By default LLDP agent is disabled.
Command Mode
Interface Mode
Examples
#configure terminal
(config)#int eth0
(config-if)#lldp-agent customer-bridge
 
(config-if)#no lldp-agent customer-bridge
(config-if)#exit
