Unicast Configuration Guide : CHAPTER 4 OSPF : Loop-Free Alternate Fast Reroute : Overview
  
Overview
The goal of (LFA-FRR) is to reduce failure reaction time to 10s of milliseconds by using a pre-computed alternate next-hop in the event that the currently selected primary next-hop fails, so that the alternate can be rapidly used when the failure is detected. A network with this feature experiences less traffic loss and less micro-looping of packets than a network without LFA-FRR.
After enabling LFA-FRR on routers, routers calculate a backup path for each primary path to reach the destination.The backup path is calculated based on the attributes such as node protecting, link protecting, and broadcast link protecting. If there is an ECMP route to a primary link, no backup is calculated.
