Protocol Independent Multicasting Developer Guide : CHAPTER 5 PIM6 Command API : pim6_api_router_id_unset
  
pim6_api_router_id_unset
This function deletes the router-id.
Syntax
int
pim6_api_router_id_unset (u_int32_t vr_id, vrf_id_t vrf_id,
struct pal_in6_addr router_id)
Input Parameters
vr_id
Virtual router ID (0-255)
vrf_id
VPN Routing/Forwarding Instance ID
router_id
Router-ID
Output Parameters
None
Return Values
PIM_API_SET_ERR_WRONG_VALUE when the interface name does not exists
PIM_API_SET_ERR_WRONG_VRF when PIM VRF interface is not found
PIM_API_SET_ERR_ROUTER_ID_INVALID when the router-id cannot be configured with the value
PIM_API_SET_SUCCESS when the function executes properly
