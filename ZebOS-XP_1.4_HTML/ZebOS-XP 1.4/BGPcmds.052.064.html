Border Gateway Protocol Command Reference : CHAPTER 2 BGP Commands : ip extcommunity-list <100-199>
  
ip extcommunity-list <100-199>
Use this command to create an expanded extended community list.
Use the no parameter with this command to delete the community-list entry.
Command Syntax
ip extcommunity-list <100-199> (deny|permit) LINE
no ip extcommunity-list <100-199> (deny|permit) LINE
Parameters
<100-199>
Extended community list number (expanded)
deny
Reject the community
permit
Accept the community
LINE
An ordered list as a regular expression
Command Mode
Configure mode
Examples
#configure terminal
(config)#ip extcommunity-list 125 permit 4567335
