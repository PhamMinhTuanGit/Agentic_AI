Unicast Configuration Guide : CHAPTER 6 IS-IS IPv4 : L1-L2 Area Routing with Multiple Instances : R4
  
R4
 
(config)# interface eth0
Specify the interface (eth0)to configure, and enter Interface mode.
(config-if)# ip router isis aa
Enable IS-IS routing on interface eth0 for area aa.
(config-if)# exit
Exit Interface mode, and return to Configure mode.
(config)# router isis aa
Create an IS-IS routing instance for area aa.
(config-router)# is-type level-1
Establish the IS level for this area (aa) as level-1.
(config-router)# net 52.0000.0000.0004.00
Establish a Network Entity Title for this instance, specifying the area address and the system ID.
