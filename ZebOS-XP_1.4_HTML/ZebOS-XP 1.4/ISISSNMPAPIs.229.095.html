isis_get_circ_level
This call gets the type of packets that will be sent and accepted on this circuit.
Syntax
int isis_get_circ_level (u_int32_t vr_id, u_int32_t instance, u_int32_t circindex, u_int32_t *ret);
Input Parameters
vr_id
Virtual Router ID. The default value is 0. For non-VR implementation, pass 0 for vr_id.
instance
IS-IS instance ID.
circindex
An IS-IS circuit index.
Output Parameters
ret
Level of the circuit:
1
Level1
2
Level2
3
Level1 and Level 2
Return Values
ISIS_API_GET_SUCCESS for supported circuit index found in the specified instance.
ISIS_API_GET_ERROR for supported circuit index not found in the specified instance.
