Layer 2 Command Reference : CHAPTER 4 Spanning Tree Protocol Commands : spanning-tree enable
  
spanning-tree enable
Use this command to enable spanning tree on an interface for the default bridge.
Note: If switchport is not configured on the given interface, this command has no effect.
Command Syntax
spanning-tree enable
Parameters
None
Default
Spanning-tree is enabled if the switchport command is configured.
Command Mode
Interface mode
Example
#configure terminal
(config)#interface eth0
(config-if)#spanning-tree enable
