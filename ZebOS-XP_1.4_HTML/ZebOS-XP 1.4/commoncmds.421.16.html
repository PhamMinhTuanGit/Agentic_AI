Network Services Module Command Reference : CHAPTER 2 Common Exec Mode Commands : logout
  
logout
Use this command to exit from the IMI shell from any of the exec modes.
Command Syntax
logout
Parameters
None
Command Mode
Exec mode and Privilege Exec mode
Examples
The following examples show the use of logout command.
>logout
[root@TSUP-123 sbin]#
 
>enable
#logout
[root@TSUP-123 sbin]#
