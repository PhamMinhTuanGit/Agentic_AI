Carrier Ethernet Command Reference : CHAPTER 8 Provider Bridging Commands : switchport customer-network vlan
  
switchport customer-network vlan
Use this command to set the Layer2 interface as a Customer Network which behaves as specified by the 802.1 AD standard.
Command Syntax
switchport customer-network vlan <2-4094>
no switchport customer-network vlan
Parameters
<2-4094>
Set the default VLAN ID for the interface.
Default
The default action is to tunnel.
Command Mode
Interface mode
Examples
#configure terminal
(config)#interface eth0
(config-if)#switchport customer-network vlan 2
