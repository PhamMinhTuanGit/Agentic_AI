show running-config rbridge
Use this command to show the current running RBridge system configuration.
Command Syntax
show running-config rbridge trill
Parameters
None
Command Mode
Privileged Exec mode, Interface Mode, and Configure Mode
Example
(config-rb)#show running-config rbridge trill
!
rbridge trill 1
max-nickname 123
originating-dtree 00ee
!
(config-rb)#
