MPLS Virtual Circuit Opcodes
The following MPLS opcodes are part the MPLS forwarder and handle packets transported on virtual circuits.
OPCODES
Description
PUSH_AND_LOOKUP_FOR_VC
Push a VC label to encapsulate an incoming Layer 2 PDU and lookup the MPLS FTN table to get an LSP to reach the tunnel end-point. This opcode is used for non-directly-connected VC PE routers
PUSH_FOR_VC
Push a VC label to encapsulate an incoming Layer 2 PDU. This opcode is used when the VC PE routers are adjacent
POP_FOR_VC
POP the specified label from the labeled packet and transmit the de-encapsulated Layer-2 PDU on the outgoing interface. This opcode is used for VC labels only.
