Layer 2 Command Reference : CHAPTER 12 MVRP Commands : show mvrp timer
  
show mvrp timer
Use this command to display MVRP timer values associated with a specific interface.
Command Syntax
show mvrp timer IF_NAME
Parameter
IFNAME
Displays the name of the interface.
Command Mode
Exec and Privileged Exec mode
Command Mode
Configure mode
Example
The following sample output from this command displays all MVRP timer values associated with interface eth2.
#show mvrp timer eth2
Timer Timer Value (centiseconds)
