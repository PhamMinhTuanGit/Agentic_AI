Carrier Ethernet Command Reference : CHAPTER 2 Ethernet CFM Commands : mep mpid
  
mep mpid
Use this command to enter Ethernet CFM MEP configuration mode where you can configure the given MEP.
Command Syntax
mep mpid MPID (vlan VLANID|)
Parameters
mpid
MEP.
MPID
MEP ID <1-8191>.
vlan
VLAN.
VLANID
VLAN ID <1-4094>.
Command Mode
Ethernet CFM configuration mode
Example
(config-ether-cfm)#mep mpid 5 vlan 4
(config-cfm-mep)#
