isis-spb max-lsp-lifetime
Use this command to set the maximum LSP lifetime. You must set the max-lsp-lifetime greater than lsp-refresh-interval. The max-lsp-lifetime should be same across the topology.
Use the no form of this command to set the lifetime to its default (1200 seconds).
Command Syntax
isis-spb max-lsp-lifetime <350-65535>
no isis-spb max-lsp-lifetime
Parameters
<350-65535>
Specify an maximum LSP lifetime in seconds.
Default
By default, max-lsp-lifetime is set to 1200 seconds.
Command Mode
ISIS-SPB mode
Examples
(isis-spb-config)#isis-spb max-lsp-lifetime 1500
 
(isis-spb-config)#no isis-spb max-lsp-lifetime
