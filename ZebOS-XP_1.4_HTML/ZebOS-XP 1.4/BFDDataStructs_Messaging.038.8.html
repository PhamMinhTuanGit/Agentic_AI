bfd_storage_type
The bfd_storage_type enumeration defines all the BFD storage types.
Constant
Description
ST_OTHER
When storage is other
ST_VOLATILE
When storage type is volatile
ST_NONVOLATILE
When storage type is nonvolatile
ST_PERMANENT
When storage is permanent
ST_READONLY
When storage is read only
Definition
enum bfd_storage_type
{
ST_OTHER = 1,
ST_VOLATILE,
ST_NONVOLATILE,
ST_PERMANENT,
ST_READONLY
};
