dtree-nickname-to-compute
Use this command to set the d-trees nickname to be used by all RBridges.
Use the no parameter with this command to reset the configuration to the default value.
Command Syntax
dtree-nickname-to-compute NAME
no dtree-nickname-to-compute (NAME|all)
Parameters
NAME
Specify the d-tree name in Hexadecimal range <0x0001 - 0xFFC0>.
all
Specify to remove all d-tree names.
Command Mode
RBridge mode
Examples
Set one d-tree:
>enable
#configure terminal
(config)#bridge 1 protocol trill
(config)#rbridge trill 1
(config-br)#dtree-nickname-to-compute dd
Set one d-tree:
>enable
#configure terminal
(config)#bridge 1 protocol trill
(config)#rbridge trill 1
(config-br)#dtree-nickname-to-compute all
Reset d-trees:
(config-br)#dtree-nickname-to-compute dd
(config-br)#dtree-nickname-to-compute all
