Integrated Management Interface Command Reference : CHAPTER 3 IMI Shell Commands : do
  
do
Use this command to run any Exec mode or Privileged Exec mode command from the Configure mode.
Command Syntax
do LINE
Parameters
LINE
Specify the command and its parameters.
Command Mode
Configure mode
