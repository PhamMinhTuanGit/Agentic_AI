Integrated Management Interface Command Reference : CHAPTER 3 IMI Shell Commands : start-shell
  
start-shell
Use this command to execute commands on the underlying kernel. For example, after using this command, you can use Linux commands, if Linux is the underlying operating system.
Use the exit command to get back to the IMISH.
Command Syntax
start-shell
Parameters
None
Command Mode
Privileged Exec mode
Example
#start-shell
[root@TSUP40 sbin]#exit
exit
#
