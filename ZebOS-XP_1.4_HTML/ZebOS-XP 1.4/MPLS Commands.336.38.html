Multi-Protocol Label Switching Command Reference : CHAPTER 2 MPLS Commands : mpls traffic-eng router-id
  
mpls traffic-eng router-id
Use this command to configure a routing ID for MPLS Traffic Engineering (MPLS-TE).
Use the no parameter with this command to remove this configuration.
Command Syntax
mpls traffic-eng router-id A.B.C.D
no mpls traffic-eng router-id
Parameters
A.B.C.D
An IS-IS router ID in IPv4 address format
Command Mode
IS-IS Router mode
Examples
#configure terminal
(config)#router isis
(config-router)#mpls traffic-eng router-id 1.2.3.4
 
(config-router)#no mpls traffic-eng router-id
