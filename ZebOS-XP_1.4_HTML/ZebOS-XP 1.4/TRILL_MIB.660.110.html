trill_get_next_rbridge_dtree_nick
This call gets the nickname of the next entry of the distribution tree.
Syntax
int
trill_get_next_rbridge_dtree_nick (u_int32_t vr_id, u_int32_t *instance,
u_int32_t *nicknumber, int indexlen,
u_int32_t *ret)
Input Parameters
vr_id
An integer that contains the TRILL VR identifier.
instance
An integer that contains the TRILL instance ID.
nicknumber
An Integer containing the Dtree Number.
indexlen
An integer containing the length of the index.
Output Parameters
ret
An integer containing the Nickname of the Dtree.
Return Value
TRILL_API_GET_SUCCESS for valid Instance ID, NickNumber.
TRILL_API_GET_ERROR for valid Instance ID, NickNumber not found.
