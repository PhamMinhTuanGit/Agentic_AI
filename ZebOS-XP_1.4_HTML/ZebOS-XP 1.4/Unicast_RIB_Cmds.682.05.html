Unicast Routing Information Base Command Reference : CHAPTER 2 Unicast RIB Commands : description
  
description
Use this command to assign a description to a Virtual Router instance.
Use the no parameter to remove a description.
Command Syntax
description LINE
no description
Parameters
LINE
Virtual Router description
Command Mode
VR mode
Examples
#configure terminal
(config)#virtual-router VR1
(config-vr)#description VR1 has been created for CLI testing
(config-vr)#exit
 
(config)#virtual-router VR1
(config-vr)#no description
(config-vr)#exit
