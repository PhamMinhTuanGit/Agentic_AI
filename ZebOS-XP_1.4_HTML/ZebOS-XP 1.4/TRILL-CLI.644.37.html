trill access-port
Use this command to configure a TRILL port as an access port.
Use the no parameter with this command to reset the configuration to the default setting.
Command Syntax
trill access-port enable
no trill access-port
Parameter
enable
Specify to enable an access port.
Command Mode
Interface mode
Default
Disabled
Examples
>enable
#configure terminal
(config)#interface eth1
(config-if)#trill access-port enable
 
(config-if)#no trill access-port enable
