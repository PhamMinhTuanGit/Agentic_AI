System Management Command Reference : CHAPTER 4 Dynamic Host Configuration Protocol Relay : ipv6 dhcp relay
  
ipv6 dhcp relay
Use this command to enable the DHCP relay agent.
Use the no form of this command to disable the DHCP relay agent.
Command Syntax
ipv6 dhcp relay
no ipv6 dhcp relay
Parameters
None
Command Mode
Configure mode
Examples
#configure terminal
(config)#ipv6 dhcp relay
 
#configure terminal
(config)#no ipv6 dhcp relay
