Edge Virtual Bridging Command Reference : CHAPTER 2 Edge Virtual Bridging Commands : evb bridge vdp-keep-alive
  
evb bridge vdp-keep-alive
Use this command to set the VDP (VSI Discovery and Configuration Protocol) keep-alive time.
Command Syntax
evb bridge <1-32> vdp-keep-alive <0-31>
Parameters
<1-32>
Bridge identifier
<0-31>
Keep-alive time
Command Mode
Configure mode
Examples
#configure terminal
(config)#evb bridge 14 vdp-keep-alive 16
