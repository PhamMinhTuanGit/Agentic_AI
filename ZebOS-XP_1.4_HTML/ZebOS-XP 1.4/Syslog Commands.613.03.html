System Management Command Reference : CHAPTER 12 Syslog : logging server
  
logging server
Use this command to set a syslog server.
Use the no form of this command to remove a syslog server.
Command Syntax
logging server (A.B.C.D|X:X::X:X|HOSTNAME) (|((<0-7>) (|facility (local0| local1 | local2 | local3| local4 |local5 | local6 | local7 |user))))
no logging server (A.B.C.D | X:X::X:X | HOSTNAME )
Parameters
A.B.C.D
IPv4 address
X:X::X:X
IPv6 address
HOSTNAME
Host name; specify localhost to log locally
<0-7>
Severity at which messages are logged. The severity levels are shown in Table 12-1. If not specified, the default is 3.
facility
Entity logging the message (user defined); if not specified, the default is local7
local0
Local0 entity
local1
Local1 entity
local2
Local2 entity
local3
Local3 entity
local4
Local4 entity
local5
Local5 entity
local6
Local6 entity
local7
Local7 entity (default)
user
User entity
Command Mode
Configure mode
Examples
#configure terminal
(config)#logging server MyLogHost
