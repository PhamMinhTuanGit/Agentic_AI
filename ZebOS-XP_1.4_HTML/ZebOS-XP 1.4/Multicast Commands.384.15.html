Multicast Routing Information Base Command Reference : CHAPTER 2 Multicast Commands : show ipv6 mif
  
show ipv6 mif
Use this command to display the MRIB VIF table.
Command Syntax
show ipv6 mif
show ipv6 mif IFNAME
show ipv6 mif (vrf NAME|)
show ipv6 mif (vrf NAME|) IFNAME
Parameters
IFNAME
Interface name.
vrf
Specify the VRF name.
Command Mode
Exec and Privileged Exec mode
Example
The following are sample outputs of this command displaying the MRIB VIF table, with and without the interface parameter:
#show ipv6 mif
Interface Mif Owner Uptime
Idx Module
wm0 0 PIM-SMv6 00:17:18
Register 1 00:17:18
wm1 2 PIM-SMv6 00:17:18
 
#show ipv6 mif wm0
Interface Mif Owner Uptime
Idx Module
wm0 0 PIM-SMv6 00:19:06
