cfm_find_mep
This function finds a specific maintenance end point.
Syntax
#include "cfm_api.h"
struct cfm_mep *
cfm_find_mep (struct cfm_ma *ma, u_int32_t mep_id)
Input Parameters
ma
Pointer to the MA
mep_id
ID of the MEP
Output Parameters
None
Return Values
Pointer to the cfm_mep structure when the function succeeds
NULL when not found
